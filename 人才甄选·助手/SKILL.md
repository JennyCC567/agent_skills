# 智能甄选引擎

## 技能定位
从简历到面试的全流程智能甄选，确保"选对人"。

## 触发判断

当用户意图匹配以下场景时触发：
- 简历解析、简历评估、批量筛选
- 候选人匹配度打分
- 面试方案设计、面试题库生成
- 面试评分标准、评分Rubric
- 评估中心设计（群面/无领导小组）
- 面试官手册

关键词：简历解析、简历评估、批量筛选、面试方案、面试题库、评分标准、面试评估、评估中心、面试官手册、候选人评估

## 核心模块

### M1 简历智能解析与评估

**输入**：批量简历(PDF/Word/图片) + 目标岗位JD + 胜任力模型(来自⑪-M2)

**5步标准流程**：

**Step 1: OCR+结构化解析**
- 调用已安装的"简历解析器"技能
- 提取：姓名/联系方式/教育/工作经历/项目/技能

**Step 2: 去重（同人多渠道）**
```
去重规则：姓名+手机号 / 姓名+邮箱
同一候选人在Boss/猎聘/内推多份简历 → 合并为一份
```

**Step 3: 自动标签**
| 标签类型 | 示例 |
|---------|------|
| 技能标签 | Python/制冷/CAD/SolidWorks/嵌入式C |
| 经验标签 | 5年/白电/家电/汽车热管理 |
| 学历标签 | 985/硕士/制冷专业/西安交大 |
| 薪资标签 | 当前20K/期望25K |

**Step 4: JD匹配度打分**
基于⑪-M2胜任力模型的各维度评分：
```
技术匹配度(30%) + 经验匹配度(25%) + 学历匹配度(15%) 
+ 薪资可行性(15%) + 文化契合度(15%)
= 加权总分
```

**Step 5: 优先级排序**
| 级别 | 匹配度 | 建议动作 |
|------|--------|---------|
| A | >85% | 直接推荐面试 |
| B | 70-85% | 推荐面试，关注短板 |
| C | 55-70% | 备选池 |
| D | <55% | 不推荐 |

**输出**：候选人池Excel + 匹配度排名 + 批量评估报告(Word)

---

### M2 面试评估中心

**输入**：岗位JD + 候选人简历(M1评估结果) + 面试轮次

**M1→M2联动逻辑**：
M1评估中"缺什么" → M2面试中"考什么"
- 例：M1显示"技术匹配度高但管理经验不明确"
- M2增加"团队管理行为面试题"+"管理情景模拟"

**差异化面试方案**：

| 面试类型 | 适用轮次 | 题目类型 | 时长 | 面试官 |
|---------|---------|---------|------|--------|
| 行为面试(BEI) | 所有轮次 | STAR类问题 | 30-45min | HR+业务 |
| 技术深挖 | 复试 | 专业深度问题 | 45-60min | 技术专家 |
| 案例分析 | 复试/终面 | 真实业务场景 | 60min | 业务主管 |
| 情景模拟 | 终面 | 角色扮演/压力测试 | 30min | 高管 |
| 无领导小组 | 校招群面 | 开放性讨论题 | 40min | HR+业务 |

**按岗位分类的题库框架**：

| 岗位类别 | 专业题方向 | 行为题方向 | 案例题方向 |
|---------|-----------|-----------|-----------|
| 制冷研发 | 制冷循环/换热器 | 项目攻坚/技术选型 | 噪音振动诊断 |
| 嵌入式 | C/RTOS/中断 | Bug修复/架构设计 | 资源受限优化 |
| AI算法 | ML/DL/部署 | 模型上线经验 | 家电AI应用 |
| 工业设计 | 设计思维/手绘 | 从0到1经验 | 白电趋势判断 |
| 产品经理 | 市场/用户研究 | 需求管理/跨部门 | 新品策划全案 |

**评分Rubric标准**：
```
每个维度采用BARS行为锚定评分：
1分 = 不合格（无相关经验/回答偏离）
3分 = 合格（有基本经验/回答完整）
5分 = 优秀（经验丰富/回答深入有洞察）
7分 = 卓越（行业领先/有创新性思考）
```

**输出**：面试题库(Excel) + 评分表(Rubric) + 面试官手册(Word)

## 协作关系

| 方向 | 技能 | 交互内容 |
|------|------|---------|
| 调用 | ⑪人才规划引擎-M2 | 胜任力模型（评估标准） |
| 接收 | ⑭人才猎聘引擎 | 候选人简历与证据链 |
| 接收 | ⑮校园招聘引擎 | 校招候选人 |
| 输出到 | ⑰经营分析引擎 | 面试通过率、质量数据 |

## 输出规范

- 简历评估需附匹配度打分依据
- 面试题库按岗位+轮次分类
- 评分Rubric每个维度需有行为锚定描述
- 面试官手册包含法律红线提醒（不询问婚育/政治/疾病等）
