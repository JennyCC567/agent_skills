# 咨询级专业版式规范说明

## 1. 文档结构规范

### 1.1 页面布局
- **纸张大小**: A4 (210mm × 297mm)
- **页边距**: 上下25.4mm，左右25.4mm
- **页眉**: 高度60px，深蓝色背景(#1e3a5f)，包含Logo和报告标题
- **页脚**: 高度40px，浅灰色背景(#f7fafc)，包含页码和版权信息
- **页码**: 右下角，Times New Roman，12pt，加粗

### 1.2 文档组成部分
1. **封面** - 深蓝色渐变背景，大标题居中
2. **扉页** - 报告标题、副标题、版本信息
3. **目录** - 三级目录结构，自动生成
4. **执行摘要** - 蓝色背景框，关键结论高亮
5. **正文** - 按章节组织，页眉显示当前章节
6. **附录** - 补充材料、数据源说明
7. **参考文献** - 标准格式引用列表

## 2. 字体规范

### 2.2 英文字体

- **等宽字体**: Consolas

### 2.3 字号标准

- **章节标题**: 26pt，加粗，深蓝色(#1e3a5f)
- **节标题**: 20pt，加粗，中蓝色(#2c5282)
- **小节标题**: 17pt，加粗
- **正文**: 14pt，常规
- **图表标题**: 16pt，加粗
- **表格内容**: 13pt

- **页眉**: 16pt，加粗
- **页脚**: 12pt

## 9. 版式控制

### 9.1 分页控制
- **章节前**: 强制分页
- **图表后**: 避免分页
- **表格后**: 避免分页
- **重点框后**: 避免分页

### 9.2 孤行控制
- **避免孤行**: 段落最后至少保留2行
- **避免寡行**: 段落开头至少保留2行
