# 数据处理流程与输出规则

## 概览

本文档详细说明AI人才Mapping智能体的数据处理流程和输出规则，特别是关于原始JSON数据的处理方式。

## 数据处理流程

### 1. 输入数据阶段

```
原始数据收集
    ↓
数据脱敏处理
    ↓
数据标准化与验证
    ↓
生成JSON输入文件（内部使用）
    ↓
数据存储（临时）
```

### 2. 报告生成阶段

```
加载JSON输入文件
    ↓
数据解析与处理
    ↓
生成HTML报告
    ↓
生成PDF报告
    ↓
（可选）生成其他格式报告
```

### 3. 输出交付阶段

```
输出文件列表
    ├── report.html (默认)
    └── report.pdf (默认)

原始JSON数据文件：
    ✗ 不输出
    ✗ 不显示
    ✗ 不可下载
    ✗ 用户端不可见
```

## 原始JSON数据说明

### 数据来源
- 政府官方网站
- 企业官方公开披露信息
- 招聘平台公开信息
- 行业白皮书
- 新闻媒体报道

### 数据脱敏
- 个人姓名：脱敏处理（如：张**）
- 联系方式：加密处理（如：138****1234）
- 身份证号：部分隐藏（如：110***********1234）
- 家庭住址：隐藏具体地址
- 敏感信息：完全移除

### JSON文件特点
- **格式**：JSON格式，UTF-8编码
- **用途**：仅作为报告生成的输入数据
- **生命周期**：临时存储，生成报告后可删除
- **访问权限**：仅脚本内部可访问

## 输出规则

### 默认输出格式

当用户未指定输出格式时，系统自动生成以下文件：

1. **HTML报告**
   - 文件名：`{报告名称}.html`
   - 特性：在线查看 + 一键下载
   - 内容：完整报告内容 + 样式

2. **PDF报告**
   - 文件名：`{报告名称}.pdf`
   - 特性：可下载，便于打印存档
   - 内容：完整报告内容，格式一致

### 输出文件列表

```
✅ report.html (默认 - 在线查看+一键下载)
✅ report.pdf (默认 - 可下载)
✗ report.json (不输出、不显示、不可下载、用户端不可见)
✗ report.xlsx (仅在用户明确要求或--all-formats时生成)
✗ report.docx (仅在用户指定时生成)
✗ report.pptx (仅在用户指定时生成)
```

## 安全保障

### 数据安全
1. **脱敏处理**：所有敏感信息已脱敏
2. **不输出原始数据**：JSON文件不提供给用户
3. **临时清理**：临时文件自动清理
4. **权限控制**：仅脚本可访问原始数据

### 隐私保护
1. **个人信息保护**：遵循《个人信息保护法》
2. **数据最小化**：仅收集必要信息
3. **用途限制**：仅用于报告生成
4. **删除机制**：临时文件及时删除

## 技术实现

### batch_generator.py脚本

```python
def main():
    # 加载JSON数据（仅用于输入）
    report_data = load_json(args.data)

    # 生成报告
    if args.all_formats:
        generate_all_formats(report_data, ...)
    elif args.formats:
        # 生成用户指定的格式
        for fmt in args.formats:
            generate_format(report_data, fmt)
    else:
        # 默认生成HTML和PDF
        generate_html_report(report_data, ...)
        generate_pdf_report(report_data, ...)

    # 输出文件列表（不包含JSON）
    print(f"  - {output}.html (默认)")
    print(f"  - {output}.pdf (默认)")
    # 不显示JSON文件
```

### 不输出JSON的保证

1. **格式选择限制**：`--formats`选项不包含`json`
2. **输出列表控制**：main()函数不输出JSON文件名
3. **文件不生成**：没有任何代码生成JSON输出文件

## 常见问题

### Q1: 为什么不提供原始JSON数据？
**A:** 原始JSON数据仅用于报告生成，包含脱敏后的个人信息，不单独提供给用户是出于数据安全和隐私保护的考虑。

### Q2: 用户可以下载原始数据吗？
**A:** 不可以。原始JSON数据文件不提供给用户，用户无法下载，用户端也看不见这个文件。

### Q3: 如何获取数据详情？
**A:** 所有数据详情都已包含在HTML和PDF报告中，报告以可视化的方式展示数据和分析结果。

### Q4: 如果需要原始数据怎么办？
**A:** 当前设计不支持提供原始JSON数据。如需数据访问，需要通过其他合规渠道申请。

## 总结

- **输入**：JSON文件（临时，内部使用）
- **输出**：HTML和PDF（默认）
- **原始数据**：不输出、不显示、不可下载、用户端不可见
- **数据安全**：脱敏处理，符合隐私保护法规
