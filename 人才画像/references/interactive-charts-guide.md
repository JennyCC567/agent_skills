# 动态可视化图表使用指南

## 功能说明
AI人才Mapping智能体支持生成交互式HTML报告，包含动态可视化图表功能。

## 支持的图表类型

### 1. 匹配度分布图（环形图）
- 显示候选人匹配度分布
- 四个区间：80-100%（绿色）、60-79%（蓝色）、40-59%（黄色）、0-39%（红色）
- 悬停显示详细数量

### 2. 技能频率图（横向柱状图）
- 显示Top 10最频繁技能
- 悬停显示出现次数
- Y轴显示技能名称，X轴显示次数

### 3. 公司分布图（饼图）
- 显示Top 10公司分布
- 多彩配色方案
- 悬停显示公司名称和人数

## 使用方法

### 生成动态可视化报告
```bash
python scripts/report_generator.py --data report_data.json --format interactive --output report.html
```

### 打开报告
在浏览器中打开生成的HTML文件即可查看交互式图表。

## 故障排除

### 图表无法显示
1. **检查网络连接**：图表库从CDN加载，需要网络连接
2. **检查浏览器兼容性**：支持Chrome、Firefox、Safari、Edge等现代浏览器
3. **查看控制台错误**：按F12打开开发者工具，查看Console标签

### 数据为空
如果候选人数据为空，图表会显示"暂无数据"提示。

### Chart.js加载失败
如果CDN无法访问，报告中会显示错误提示："图表库加载失败，请检查网络连接"

## 技术说明
- 使用Chart.js 4.4.0版本
- 响应式设计，支持移动端
- 包含错误处理和空数据处理
- 支持打印和PDF导出
