## 一、报告结构规范

### 1.1 必含章节

| 章节 | 内容要求 | 学历要求 |
|------|---------|---------|
| 执行摘要 | 核心发现、关键指标 | 必须包含 |
| 人才概况 | 数量、分布、结构 | 必须包含 |
| 教育背景分析 | 学历分布、院校分布、专业分布 | **学历必填** |
| 技能图谱 | 核心技能、稀缺技能 | 必须包含 |
| 薪资分析 | 薪酬区间、影响因素 | 必须包含 |
| 地域分布 | 城市分布、流动趋势 | 必须包含 |
| 结论与建议 | 洞察、策略、行动计划 | 必须包含 |

### 1.2 学历信息完整性要求

根据智能体人设与回复逻辑的**硬性约束**：

**教育背景模块必须包含**：
```
### 教育背景
- 最高学历：博士/硕士/本科/大专/中专/高中（必须明确，不可写"大学""本科及以上"）
- 毕业院校：xxx/未公开
- 所学专业：xxx/不限/未知
```

**禁止出现的情况**：
- 学历字段为空
- 学历写"大学""本科及以上""研究生""硕士及以上"
- 毕业院校为"（空）"或"null"
- 所学专业为"（空）"或"null"

## 三、数据准确性要求

### 3.1 日期字段规范

- **生成时间**：必须使用系统实时时间（datetime.now()）
- **分析周期**：使用用户指定的日期范围
- **禁止**：硬编码日期、虚构日期、占位符日期

### 3.2 数据来源标注

每个图表和数据表格下方必须标注数据来源：

```
数据来源：公开招聘数据、行业报告、预测模型等
更新时间：{{REPORT_GENERATED_TIME}}
```
