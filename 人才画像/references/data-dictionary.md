## 一、候选人主数据字段

### 1.1 基础信息字段

| 字段名 | 标准名称 | 数据类型 | 取值范围 | 说明 | 必填 |
|--------|----------|----------|----------|------|------|
| candidate_id | 候选人ID | STRING | UUID格式 | 唯一标识符 | 是 |
| name | 姓名 | STRING | 2-20字符 | 中文或英文名 | 是 |
| gender | 性别 | STRING | 男/女/未知 | 性别 | 否 |
| age | 年龄 | INTEGER | 18-70 | 周岁 | 否 |
| phone | 手机号 | STRING | 11位数字 | 中国大陆手机号 | 是 |
| email | 邮箱 | STRING | 邮箱格式 | 常用邮箱 | 是 |
| location | 当前位置 | STRING | 省市格式 | 如：北京市朝阳区 | 是 |
| location_type | 地域类型 | STRING | 一线/新一线/二线/三线/其他 | 城市等级 | 是 |

### 1.2 教育背景字段（必填模块）

| 字段名 | 标准名称 | 数据类型 | 取值范围 | 说明 | 必填 |
|--------|----------|----------|----------|------|------|
| education | 最高学历 | STRING | **博士/硕士/本科/大专/中专/高中** | 严格枚举，禁止模糊表述 | **是** |
| education_year | 毕业年份 | INTEGER | 1980-2030 | 毕业年份，缺失填0 | 是 |
| school | 毕业院校 | STRING | 院校名称 | 院校全称，缺失填"未公开" | 是 |
| major | 所学专业 | STRING | 专业名称 | 专业全称，缺失填"不限" | 是 |
| school_level | 院校层次 | STRING | 985/211/一本/二本/专科/未知 | 院校层次 | 否 |
| overseas_exp | 海外经历 | BOOLEAN | true/false | 是否有海外学习经历 | 否 |

### 1.3 工作经历字段

| 字段名 | 标准名称 | 数据类型 | 取值范围 | 说明 | 必填 |
|--------|----------|----------|----------|------|------|
| total_experience | 工作年限 | INTEGER | 0-50 | 总工作年限（年） | 是 |

## 九、数据质量规则

### 9.1 必填字段校验
- 候选人姓名：不能为空，不能超过20字符
- 教育背景：最高学历、毕业院校、所学专业必须填写
- 学历取值：必须是枚举值之一，禁止"大学""本科及以上"等模糊表述

### 9.2 数据格式校验
- 手机号：11位数字，第一位为1
- 邮箱：符合标准邮箱格式
- 年龄：18-70之间
- 工作年限：0-50之间

### 9.3 缺省值处理
| 字段 | 缺失处理 |
|------|----------|
| 毕业年份 | 填充0，查询时视为"未知" |
| 毕业院校 | 填充"未公开" |
| 所学专业 | 填充"不限" |
| 当前薪资 | 填充0 |
| 远程接受 | 默认为false |
