## 指挥 Agent（Master）

### 角色定位
项目经理与流程协调者，负责任务拆解、资源分配、进度控制和结果汇总。

### 核心职责
1. **需求解析**：理解用户自然语言需求，识别任务类型和边界
2. **任务规划**：将复杂任务拆解为可执行的子任务序列
3. **资源调度**：分配任务给合适的 Agent，管理并发执行
4. **进度监控**：跟踪任务状态，处理异常和阻塞
5. **结果汇总**：整合各 Agent 输出，生成最终交付物

### 输入
- 用户需求文本或表单数据
- 任务上下文和历史记录

### 输出
- 任务执行计划
- 子任务分配指令
- 最终结果报告

### 能力要求
- 自然语言理解与任务识别
- 流程编排与依赖管理
- 异常处理与回滚机制
- 结果整合与质量控制

### 协作方式
- 向下游 Agent 发送任务指令
- 接收 Agent 执行结果和状态更新
- 决策分支选择和循环控制

## 采集 Agent（Collector）

### 角色定位
数据入口，负责多源异构数据的采集、解析和初步清洗。

### 核心职责
1. **内部数据拉取**：通过 API 或文件导入获取 HRIS、OA、简历库数据
2. **外部数据采集**：合规爬取招聘平台、社交平台、学术库信息
3. **非结构化数据解析**：PDF/Word/图片简历 OCR + 信息抽取
4. **实时监听**：监控人才异动（离职、晋升、论文发表）
5. **数据标准化**：统一输出为 JSON-LD 格式

### 输入
- 数据源配置（API 端点、文件路径、爬虫规则）
- 采集范围和过滤条件

### 输出
- 标准化的人才数据（JSON-LD 格式）
- 数据质量报告（完整性、准确性）

### 能力要求
- 多协议数据接入（API/SDK/文件/爬虫）
- OCR 和信息抽取
- 数据清洗和格式转换
- 实时流处理

### 协作方式
- 接收指挥 Agent 的采集指令
- 向数据处理 Agent 交付清洗后的数据
- 提供数据质量反馈

## 画像 Agent（Profiler）

### 角色定位
人才分析师，负责生成 360° 人才画像和岗位画像。

### 核心职责
1. **人才画像生成**：
   - 硬技能：技术栈、工具、语言、认证
   - 软技能：领导力、沟通、创新、协作
   - 经验：行业经验、项目经验、管理经验
   - 业绩：成果、KPI、奖项
   - 风格：工作风格、团队偏好
   - 风险：离职倾向、合规风险
   - 潜力：成长性、适应力、学习力

2. **岗位画像生成**：
   - 必备技能、加分技能
   - 经验要求、学历要求
   - 软技能、文化匹配
   - 薪资范围、地域要求

### 输入
- 人才数据（采集 Agent 输出）
- 岗位描述（JD）

### 输出
- 360° 人才画像（JSON 格式）
- 岗位画像（JSON 格式）

### 能力要求
- 语义理解与特征提取
- 经验评估与技能推断
- 风险识别与潜力评估
- 画像标准化与结构化

### 协作方式
- 接收采集 Agent 或用户输入的数据
- 向匹配 Agent 提供画像数据
- 向洞察 Agent 提供分析基础

## 匹配 Agent（Matcher）

### 角色定位
推荐引擎，负责候选人匹配与排序。

### 核心职责
1. **语义匹配**：基于向量相似度计算技能、经验匹配度
2. **硬约束校验**：检查学历、年限、地域、薪资、在职状态
3. **软约束评分**：评估文化匹配、潜力、稳定性
4. **候选人排序**：综合评分并生成推荐列表
5. **匹配理由生成**：解释推荐理由，提供决策依据

### 输入
- 岗位画像（画像 Agent 输出）
- 候选人画像列表（画像 Agent 输出）
- 匹配权重配置

### 输出
- Top-N 候选人推荐列表
- 匹配度分数和理由

### 能力要求
- 语义相似度计算
- 多维度综合评分
- 约束满足求解
- 推荐理由生成

### 协作方式
- 接收画像 Agent 的岗位和候选人画像
- 向指挥 Agent 返回推荐结果
- 向校验 Agent 提供匹配详情

## 洞察 Agent（Insight）

### 角色定位
数据分析师，负责趋势分析、缺口识别和可视化。

### 核心职责
1. **人才分布分析**：
   - 地域分布
   - 部门分布
   - 层级分布
   - 技能分布

2. **梯队缺口识别**：
   - 关键岗位缺口
   - 高潜人才短缺
   - 技能缺口分析

3. **流动趋势分析**：
   - 人才流动桑基图
   - 离职率趋势
   - 晋升率趋势

4. **竞品分析**：
   - 竞品人才分布
   - 竞品薪酬 Benchmark
   - 竞品关键人才清单

5. **薪酬分析**：
   - 薪酬分布
   - 市场对标
   - 薪资差距分析

### 输入
- 人才数据集
- 分析维度和指标定义

### 输出
- 分析报告
- 可视化图表
- 洞察建议

### 能力要求
- 统计分析与数据挖掘
- 趋势识别与异常检测
- 可视化设计
- 洞察提炼与建议生成

### 协作方式
- 接收画像 Agent 的数据
- 向指挥 Agent 提供分析结果
- 向校验 Agent 提供质量指标

## 校验 Agent（Audit）

### 角色定位
质量官，负责结果质量校验、合规审查和偏见检测。

### 核心职责
1. **结果质量校验**：
   - 数据完整性检查
   - 逻辑一致性校验
   - 异常值检测

2. **可信度评分**：
   - 数据源可信度
   - 匹配模型置信度
   - 分析结果可靠度

3. **偏见检测与抑制**：
   - 性别偏见检测
   - 年龄偏见检测
   - 地域偏见检测

4. **合规审查**：
   - 数据采集合规性
   - 隐私保护检查
   - 审计日志完整性

### 输入
- 匹配结果（匹配 Agent 输出）
- 分析结果（洞察 Agent 输出）
- 合规规则和偏见阈值

### 输出
- 质量报告
- 可信度评分
- 偏见检测结果
- 合规审查结论

### 能力要求
- 数据质量评估
- 偏见检测算法
- 合规规则引擎
- 审计日志管理

### 协作方式
- 接收匹配 Agent 和洞察 Agent 的结果
- 向指挥 Agent 返回质量报告
- 向学习 Agent 提供反馈数据

## 学习 Agent（Learner）

### 角色定位
优化引擎，负责从反馈中学习，持续改进模型性能。

### 核心职责
1. **反馈收集**：
   - 人工反馈：推荐准确性、画像准确性、洞察实用性
   - 系统反馈：录用结果、转化率、满意度

2. **模型迭代优化**：
   - 调整匹配权重
   - 优化特征工程
   - 更新相似度阈值

3. **知识库更新**：
   - 新增技能标签
   - 更新行业信息
   - 修正错误映射

### 输入
- 人工反馈数据
- 系统监控数据
- 校验 Agent 质量报告

### 输出
- 优化后的模型参数
- 更新的知识库
- 性能提升报告

### 能力要求
- 反馈数据收集与分析
- 模型性能评估
- 参数调优
- 知识库维护

### 协作方式
- 接收校验 Agent 和人工反馈
- 向匹配 Agent 和画像 Agent 提供优化参数
- 向指挥 Agent 报告性能提升

## 协作模式

### 铁三角模式
- **指挥 Agent**：协调与控制
- **执行 Agent 群**：采集、画像、匹配、洞察
- **校验 Agent**：质量保障

### 消息传递
所有 Agent 之间通过标准消息格式通信：
```json
{
  "message_id": "uuid",
  "sender": "agent_name",
  "receiver": "agent_name",
  "timestamp": "ISO8601",
  "message_type": "task|result|status|error",
  "payload": {},
  "metadata": {}
}
```

### 状态共享
- 任务状态：pending|running|completed|failed
- 中间结果：共享内存或数据库
- 错误信息：统一错误码和描述

### 异常处理
- 超时机制：设置任务超时时间
- 重试策略：失败自动重试（最多3次）
- 降级策略：关键任务失败时启用备用方案
- 回滚机制：任务失败时回滚到上一个稳定状态

---

## 注意事项

1. **单一职责**：每个 Agent 只关注自己的核心职责，避免功能重叠
2. **松耦合**：Agent 之间通过标准接口通信，降低依赖
3. **可扩展**：支持新增 Agent 和功能模块
4. **可观测**：所有操作留有日志，便于调试和审计
5. **容错性**：单个 Agent 失败不应影响整个系统
