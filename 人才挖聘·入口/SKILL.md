# 人才猎聘引擎

基于产业链拆解的系统化人才Mapping + 人才CRM长期关系管理。6步标准SOP已验证于6+个Mapping项目（白电研发/ICT散热/电磁灶算法/冰箱变频/嵌入式结构/白电三巨头），输出标准化Excel(5 Sheet)+Word报告+人才地图。

## 触发判断

本技能处理两类需求：

| 类型 | 关键词 | 说明 |
|------|--------|------|
| **M1 Mapping** | Mapping、人才地图、人才清单、竞品人才摸底、产业链人才调研 | 从零开始系统搜索目标方向人才 |
| **M2 CRM** | 人才池、候选人管理、沉睡人才、触达计划、新岗匹配老候选人 | 管理已有候选人资产 |

用户同时提到两类时，先执行M1，结果自动入M2池。

## 执行模式判断

**如果用户提供了明确的方向关键词+目标企业（或允许自动生成），执行M1。**
**如果用户要求查看/管理/搜索已有候选人池，执行M2。**
**如果用户只是问方法论或框架，输出references/sop/mapping_sop.md中的流程说明，不执行搜索。**

## M1：人才Mapping（6步标准SOP）

详细SOP见 `references/sop/mapping_sop.md`。核心流程：

### Step 1: 产业链拆解 → 目标企业清单

根据用户提供的方向关键词，沿产业链定位目标企业：
- 调用search_web搜索产业链上下游关系
- 如有行业图谱数据，参考 `references/frameworks/industry_graph_template.md`
- 输出：目标企业清单（分上中下游，标注各环节代表企业）

### Step 2: 组织架构推断

对每家目标企业，推断与目标方向相关的组织架构：
- 事业部→部门→团队→关键岗位
- 搜索"XX公司 组织架构"/"XX公司 研发部门"等
- 输出：组织架构推断图+关键团队识别

### Step 3: 关键人才识别

多渠道交叉搜索识别关键人才：
- search_web搜索专利发明人（关键词+专利数据库）
- search_web搜索论文作者（学术方向）
- search_web搜索会议演讲者/行业活动嘉宾
- 搜索竞品在招岗位→反推团队负责人
- 每条信息必须标注来源URL

### Step 4: 证据链采集

每个候选人至少收集2条可溯源证据：
- 专利：专利号+发明人排序+专利名称
- 论文：标题+作者+发表年份+期刊
- 演讲：会议名称+演讲主题+年份
- 项目：项目名称+角色+公开报道链接
- 可信度评级：高(3+独立证据) / 中(2条) / 低(1条)

### Step 5: 优先级排序

多维度打分模型（默认权重，用户可调整）：

| 维度 | 默认权重 | 评分标准 |
|------|---------|---------|
| 技术匹配度 | 30% | 技能与JD要求的吻合程度 |
| 经验相关性 | 25% | 行业/方向/项目的相关性 |
| 薪资可行性 | 20% | 预估薪资是否在预算内 |
| 跳槽意愿 | 15% | 基于公开信号判断 |
| 地域匹配 | 10% | 当前城市与目标城市的匹配 |

分级：A(8+分) → B(6-8分) → C(4-6分) → D(<4分)

### Step 6: 挖猎策略

对A/B级候选人逐一制定策略：
- 薪资差距分析（当前vs目标）
- 吸引力卖点（平台/技术/城市/团队）
- 触达话术（基于技术话题切入）
- 推荐触达渠道

## M1 输出物

所有输出物保存到项目文件目录，格式：

| 输出物 | 格式 | 内容 |
|--------|------|------|
| 全量人才清单 | Excel Sheet1 | 姓名/当前公司/职位/方向/城市/年限/证据数/可信度 |
| 优先级排序 | Excel Sheet2 | 按综合得分排序，含各维度评分 |
| 企业分布分析 | Excel Sheet3 | 按企业/城市/方向的数量分布 |
| 薪资对标 | Excel Sheet4 | 各候选人当前vs目标薪资估算 |
| 证据链明细 | Excel Sheet5 | 每个候选人的证据详情(类型/标题/链接/日期) |
| 深度分析报告 | Word(docx) | 完整Mapping报告（方法论+结果+建议），30-50页 |
| 人才地图 | HTML/图表 | 按企业×方向的可视化热力图 |

生成Excel使用表格处理技能，生成Word使用docx技能，生成图表使用echart技能。

## M2：人才CRM

### 核心功能

1. **候选人入池**：M1产出的候选人自动打上标签入池
2. **标签化管理**：技能标签/意向状态/薪资预期/地域偏好/上次沟通时间
3. **活跃度分层**：
   - S：高意向，随时可聊 → 触达频率：随时
   - A：有意向需培养 → 触达频率：月度
   - B：观望中 → 触达频率：季度
   - C：暂无意向 → 触达频率：半年
4. **新岗位自动匹配**：新JD发布时检索池中候选人，输出匹配排名
5. **沉睡人才激活**：超6个月未联系→触发激活策略

### M2 输入

| 参数 | 说明 |
|------|------|
| 候选人数据 | M1产出或用户提供的候选人列表 |
| 操作类型 | 入池/查询/更新状态/新岗匹配/激活策略 |

### M2 输出

| 输出物 | 内容 |
|--------|------|
| 人才池看板 | 按S/A/B/C分层的候选人统计 |
| 匹配推荐 | 新岗位自动匹配的候选人列表(含匹配度) |
| 触达提醒 | 本周需联系的候选人清单 |
| 激活策略 | 沉睡人才的重新触达方案 |

## 与其他技能的协作

- **调用 ⑩ 数据底座 M2**：获取行业知识图谱作为产业链拆解的起点
- **调用 ⑬ 市场引擎 M2**：获取薪酬对标数据辅助挖猎策略
- **输出给 ⑯ 甄选引擎**：A/B级候选人进入简历评估流程
- **输出给 ⑭ M2 CRM**：所有候选人入池长期经营
