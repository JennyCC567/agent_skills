# Mapping深度报告模板

## 报告结构（Word文档，30-50页）

### 封面
- 项目名称
- Mapping方向
- 完成日期
- 编制人

### 目录

### 第1章 项目概述（2-3页）
- 1.1 项目背景与目标
- 1.2 Mapping方向定义
- 1.3 约束条件（地域/薪资/级别）

### 第2章 产业链分析（5-8页）
- 2.1 产业链全景图（上中下游）
- 2.2 各环节关键企业清单
- 2.3 目标企业相关性评估
- 2.4 技术演进路线与人才需求趋势

### 第3章 目标企业组织架构（5-8页）
- 3.1 各企业组织架构推断
- 3.2 关键部门/团队识别
- 3.3 团队规模与技术方向估算

### 第4章 人才分布与画像（8-12页）
- 4.1 人才总量统计
- 4.2 按企业分布（Top 10企业）
- 4.3 按城市分布
- 4.4 按技术方向分布
- 4.5 人才画像（学历/经验/薪资分布）

### 第5章 优先级排序结果（5-8页）
- 5.1 A级候选人清单（详细）
- 5.2 B级候选人清单（摘要）
- 5.3 评分维度分析
- 5.4 高潜力人才重点推荐（Top 10）

### 第6章 挖猎策略（5-8页）
- 6.1 薪酬竞争力分析
- 6.2 吸引力卖点设计
- 6.3 重点候选人触达策略
- 6.4 风险提示与应对

### 第7章 建议与行动计划（2-3页）
- 7.1 优先行动清单（本周/本月）
- 7.2 中长期人才经营建议
- 7.3 数据局限性说明

### 附录
- 附录A：全量候选人清单（Excel引用）
- 附录B：证据链明细
- 附录C：数据来源说明

---

## 报告写作要求

1. **数据驱动**：每个结论必须有数据支撑，标注来源
2. **可视化**：分布数据用图表展示（柱状图/饼图/热力图）
3. **可操作性**：策略建议必须具体到人名+话术+渠道
4. **诚实标注局限**：明确说明数据获取的局限性
