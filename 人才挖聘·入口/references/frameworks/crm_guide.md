## 活跃度分层规则

| 层级 | 判断标准 | 触达频率 | 触达方式 |
|------|---------|---------|---------|
| S | 明确表达过兴趣/正在看机会/近期有互动 | 随时 | 直接沟通新机会 |
| A | 技术高度匹配/有过接触但未明确意向 | 月度 | 技术话题+机会分享 |
| B | 匹配但无互动记录/在原公司稳定 | 季度 | 行业资讯+轻度触达 |
| C | 匹配度一般/明确拒绝过/暂无意向 | 半年 | 节日问候+重大机会 |

## 新岗位匹配逻辑

当新岗位发布时，按以下步骤检索候选人池：

1. 解析岗位JD → 提取核心技能+经验要求+薪资范围+地域
2. 与池中候选人逐一计算匹配度：
   - 技术匹配度（技能标签重合度）× 40%
   - 经验匹配度（年限+行业）× 30%
   - 薪资可行性（预期vs预算）× 20%
   - 地域匹配（当前城市vs目标城市）× 10%
3. 按匹配度排序，推荐Top 20
4. 标注每个候选人的CRM层级和最后联系时间

## 沉睡人才激活策略

沉睡定义：超过6个月未联系且层级为B/C的候选人

激活触发条件：
- 有新的高匹配岗位出现
- 候选人公司出现负面新闻（裁员/业务调整）
- 行业出现重大变化（政策/技术突破）
- 季度例行激活

激活话术框架：
```
[称呼]你好，我是[名字]，之前我们聊过[方向]的机会。
最近[触发事件]，想到可能对你有价值。
[具体信息]
方便的话可以聊聊，不急。
```

## 定期刷新规则

每月执行一次池内刷新：
1. 检查候选人是否还在原公司（搜索+验证）
2. 更新有变动的候选人状态
3. 重新计算长期未联系候选人的匹配度
4. 清理确认已不可触达的候选人（标注而非删除）
