# 历史数据学习指南

## 一、功能概述

历史数据学习功能通过分析历史 offer 和 reject 数据，优化人岗匹配算法，提升推荐精准度。

## 二、数据要求

### 2.1 数据格式

支持 CSV/Excel 格式，包含以下字段：

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| candidate_id | 字符串 | ✅ | 候选人唯一标识（脱敏） |
| resume_text | 文本 | ✅ | 简历全文（脱敏） |
| job_id | 字符串 | ✅ | 岗位唯一标识 |
| outcome | 枚举 | ✅ | 结果：offer/reject/hire |
| hire_status | 枚举 | 可选 | 入职状态：confirmed/probation/left/stayed |
| hire_months | 数字 | 可选 | 在职月数 |
| performance_score | 数字 | 可选 | 绩效评分（1-5） |
| match_score | 数字 | 可选 | 历史匹配分数 |
| salary_offered | 字符串 | 可选 | Offer薪资 |
| salary_accepted | 字符串 | 可选 | 实际接受薪资 |
| applied_date | 日期 | 可选 | 申请日期 |
| decided_date | 日期 | 可选 | 决定日期 |
| source | 字符串 | 可选 | 简历来源 |

### 2.2 数据量要求

| 场景 | 最少数据量 | 推荐数据量 |
|------|-----------|-----------|
| 冷启动 | 50条 | 200条 |
| 基础优化 | 100条 | 500条 |
| 精准优化 | 300条 | 1000条 |

## 三、学习模式

### 3.1 监督学习

基于历史 outcomes（offer/reject）训练分类模型：

```python
# 训练数据示例
features = extract_features(resume_text, job_description)
label = outcome  # offer=1, reject=0

# 模型输出
prob_offer = model.predict_proba(features)  # 预测offer概率
```

### 3.2 特征提取

| 特征类型 | 提取内容 |
|---------|---------|
| 硬性匹配 | 学历、工作年限、技能匹配度 |
| 软性特征 | 职业稳定性、成长性、薪资预期 |
| 文本特征 | 关键词TF-IDF、工作描述相似度 |
| 行为特征 | 申请频率、面试通过率 |

### 3.3 模型更新

| 更新频率 | 触发条件 | 说明 |
|---------|---------|------|
| 实时更新 | 每次新数据 | 增量学习 |
| 每日更新 | 累积≥10条新数据 | 批量重训练 |
| 每周更新 | 固定时间 | 全量重训练 |
