# 岗位 JD 生成 Prompt 模板

## 行业标准服务指令

### 通用基础规则

所有输出严格遵循国内主流企业人力资源管理行业标准与招聘实践，数据与口径参考《人力资源服务规范》及头部企业通用招聘体系

全程基于客观事实与行业基准，不做主观臆断与夸大表述，所有结论均有明确依据

输出内容兼顾 HR 日常工作效率、ATS 系统兼容性与候选人体验，符合企业招聘全流程使用要求

严格遵守就业促进法相关规定，杜绝任何性别、年龄、地域、婚育状况等歧视性表述

**薪资范围拟定规范**：
- 薪资区间需结合**所在城市、行业、企业性质、工作年限、岗位职级、学历背景**等多维度信息综合拟定
- 数据来源应参照**政府官方及权威机构发布的薪酬公开数据**（如人社部薪酬指导线、智联招聘/BOSS直聘等行业报告）
- 薪资区间应**客观合理**，杜绝虚高或偏低，避免误导
- 详见：[references/assessment-standards.md](references/assessment-standards.md)（薪资评估标准规范章节）

### 岗位 JD 生成 Prompt

```
你是一位资深的 HR 专家和岗位分析师，请根据以下信息生成一份符合行业用人标准的标准岗位 JD：

【岗位基本信息】
- 目标岗位名称：{岗位名称}
- 所属行业：{行业}
- 公司规模：{规模}
- 业务类型：{业务类型}
- 岗位所属部门：{部门}
- 汇报关系：{汇报对象}
- 团队规模：{人数}人
- 核心业务目标：{业务目标}
- 岗位层级：{初级 / 中级 / 高级 / 专家 / 管理岗}
- 薪资范围：{薪资范围}
- 企业特殊要求：{特殊要求}

【生成要求】

1. 岗位概述（100-150 字）
   - 精准概括岗位核心价值
   - 明确核心职责
   - 说明在团队中的定位

2. 核心工作职责（8-12 项）
   - 按优先级排序
   - 采用「动词 + 对象 + 成果」句式
   - 明确工作边界与输出要求
   - 使用行业通用术语

3. 任职资格要求

   硬性要求：
   - 学历要求：{学历}
   - 专业要求：{专业}
   - 工作年限：{年限}
   - 必备证书：{证书}
   - 核心硬技能：{技能}

   优先要求：
   - 相关行业经验：{行业经验}
   - 项目经验：{项目经验}
   - 软技能：{软技能}
   - 综合素质：{素质}

4. 能力素质模型（3-5 项）
   - 提炼该岗位必备的核心能力
   - 每项能力包含具体要求

5. 绩效考核关键指标（KPI）（3-5 项）
   - 列出可量化的核心考核指标
   - 明确指标定义和计算方式

6. 其他说明
   - 工作地点：{地点}
   - 工作时间：{时间}
   - 福利待遇：{福利}
   - 招聘流程：{流程}

【行业标准合规保障】

1. 参考同行业同规模企业同层级岗位的通用职责与要求
2. 专业术语与工作模块使用行业通用叫法
3. 区分 "必须具备" 与 "优先考虑" 要求
4. 所有表述合法合规，无任何就业歧视性内容

【输出格式】

请输出标准岗位 JD（Markdown格式），包含以下模块：
- 岗位概述
- 核心工作职责
- 任职资格要求
- 能力素质模型
- 绩效考核关键指标（KPI）
- 其他说明
```

## 示例

### 输入示例

```
目标岗位名称：Java高级开发工程师
所属行业：互联网
公司规模：100-499人
业务类型：电商平台
岗位所属部门：技术部
汇报关系：技术总监
团队规模：15人
核心业务目标：支撑电商平台的稳定运行和持续迭代
岗位层级：高级
薪资范围：25-35K/月
企业特殊要求：能够接受适度加班
```

### 输出示例

```markdown
# Java高级开发工程师

## 岗位概述

负责公司电商平台核心系统的架构设计与开发，保障系统高可用、高性能、高并发，支撑业务快速发展；带领技术团队完成技术攻坚和项目交付，提升团队整体技术能力。

---

## 核心工作职责

1. 负责公司核心业务系统的架构设计与开发，支撑日均 100 万+ 用户访问
2. 主导技术架构优化升级，提升系统可用性至 99.99%，降低故障率
3. 带领技术团队完成项目开发，确保项目按时交付和质量达标
4. 参与技术选型和架构决策，制定技术方案和开发规范
5. 负责核心算法优化，提升系统性能，降低服务器成本
6. 推动 CI/CD 流程建设，提升团队开发效率和交付质量
7. 指导和培养团队成员，提升团队整体技术能力
8. 搭建监控告警系统，实现故障自动发现和快速响应

---

## 任职资格要求

### 硬性要求

- **学历要求**：本科及以上
- **专业要求**：计算机相关专业
- **工作年限**：5 年以上 Java 开发经验
- **必备证书**：无强制要求
- **核心硬技能**：精通 Java、Spring Boot、Spring Cloud、MyBatis、MySQL、Redis

### 优先要求

- **相关行业经验**：有电商、金融行业经验优先
- **项目经验**：有大型分布式系统架构经验
- **软技能**：良好的沟通协调能力、项目管理能力、技术领导能力
- **综合素质**：持续学习能力、问题解决能力、抗压能力

---

## 能力素质模型

### 核心能力 1：架构设计能力
具备扎实的系统架构设计能力，能够独立完成复杂系统的架构设计，熟悉微服务、分布式、高并发架构。

### 核心能力 2：技术领导能力
具备带领技术团队的能力，能够指导和培养团队成员，推动技术攻坚，提升团队整体技术能力。

### 核心能力 3：问题解决能力
具备快速定位和解决复杂技术问题的能力，能够在高压力下保持冷静，快速响应和解决故障。

---

## 绩效考核关键指标（KPI）

1. **系统可用性**
   - 指标定义：系统正常运行时间占总时间的比例
   - 计算方式：系统正常运行时间 / 总时间 × 100%
   - 目标值：≥ 99.99%

2. **项目交付率**
   - 指标定义：按时交付的项目占比
   - 计算方式：按时交付项目数 / 总项目数 × 100%
   - 目标值：≥ 95%

3. **系统性能**
   - 指标定义：核心接口的平均响应时间
   - 计算方式：所有核心接口响应时间的平均值
   - 目标值：≤ 100ms

---

## 其他说明

- **工作地点**：北京市朝阳区
- **工作时间**：9:00-18:00，周末双休
- **福利待遇**：五险一金、年终奖、带薪年假、节日福利、培训机会
- **招聘流程**：简历初筛 → 技术面试（2轮）→ HR面试 → Offer发放

---

**生成日期**：2024-04-17
```
