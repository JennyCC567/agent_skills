# 行业适配预设模板

> 本文档为 FABM 匹配模型提供行业维度的权重和评分调整预设，确保不同行业的岗位匹配分析更贴合行业特性。使用时根据 JD 所述行业选取对应模板，覆盖默认权重即可。

---

## 1. 互联网行业（技术岗）

### 匹配权重表

| 评估维度 | 权重 | 说明 |
|---------|------|------|
| 硬性条件 | 30% | 学历、工作年限、当前职级/薪资区间 |
| 核心经验 | 35% | 核心业务系统经历、架构规模、流量量级、技术栈匹配度 |
| 专业技能 | 20% | 编程语言/框架深度、系统设计能力、开源贡献、技术影响力 |
| 软性素质 | 15% | 团队协作、沟通表达、自驱力、技术热情 |

### 关键加分项

| 加分项 | 加分幅度 | 判定依据 |
|--------|---------|---------|
| 开源贡献（GitHub Star 500+ 或知名项目 Committer） | +5~10分 | 体现技术深度、社区影响力和自驱力 |
| 大厂核心业务线经历 | +5~8分 | 证明经历过高标准工程实践 |
| 技术博客/演讲/专利 | +3~5分 | 体现技术表达力和行业影响力 |
| 全栈/多语言能力 | +3~5分 | 适应互联网多技术栈并存的灵活性 |
| 开源项目 Maintainer | +8~12分 | 极稀缺，体现技术领导力和社区认可度 |

### 典型 JD 关键词

- 高并发、高可用、分布式、微服务、中间件
- Spring Cloud / Dubbo / Kubernetes / Docker
- 百万级 QPS、99.99% 可用性、全链路压测
- Java / Go / Python / Rust
- 敏捷开发、DevOps、CI/CD
- 开源贡献优先、技术博客优先

### 评分调整说明

1. **技术栈匹配优先**：互联网技术岗对技术栈匹配度敏感，若候选人核心技术与 JD 要求不一致（如 JD 要求 Go 但候选人仅 Java），核心经验维度评分上限下调 20%
2. **系统规模权重高于项目数量**：参与过 1 个百万级 QPS 系统 > 参与 5 个万级 QPS 系统，评分时以系统规模而非项目数量为主要判据
3. **开源贡献突破权重天花板**：若候选人有显著开源贡献（Maintainer 或高 Star 项目作者），专业技能维度可突破权重上限 10%（即从 20% 调至 22%）
4. **学历底线灵活**：互联网技术岗对学历要求相对灵活，若核心经验和专业技能表现突出，硬性条件中学历不达标可仅扣 3~5 分而非直接否决
5. **频繁跳槽惩罚**：3年内跳槽超过 2 次的候选人，软性维度扣 5~8 分；互联网行业 2 年一跳视为正常节奏，不额外扣分

## 2. 跨境电商（外贸）行业

### 匹配权重表

| 评估维度 | 权重 | 说明 |
|---------|------|------|
| 硬性条件 | 20% | 学历、工作年限、语言能力证书 |
| 核心经验 | 30% | 跨境平台操盘经历、品牌出海经验、目标市场经验 |
| 专业技能 | 30% | 语言能力、跨境平台运营技能、供应链协同、海外渠道建设 |
| 软性素质 | 20% | 跨文化沟通、抗压能力、资源整合、自驱力 |

### 关键加分项

| 加分项 | 加分幅度 | 判定依据 |
|--------|---------|---------|
| 跨境平台实操经验（Amazon / Shopify / eBay / Walmart） | +5~10分 | 每多一个主流平台经验叠加，上限 10 分 |
| 目标市场本地化经验（北美/欧洲/东南亚） | +5~8分 | 与 JD 目标市场直接匹配时加分 |
| 海外渠道资源（KOL / Deal 站 / 红人 / 分销商） | +5~10分 | 可即插即用的渠道资源价值极高 |
| 供应链协同能力（对接工厂/物流/仓储） | +5~8分 | 体现全链路理解而非仅前端运营 |
| 多语言能力（英语 + 小语种） | +3~8分 | 英语为基线要求，叠加小语种（德/法/日/西）额外加分 |
| 平台合规经验（封号潮/政策变动应对） | +5~8分 | 跨境行业高风险环节，经验稀缺 |

### 典型 JD 关键词

- Amazon / Shopify / eBay / Walmart / TikTok Shop
- 品牌出海、DTC、独立站
- Listing 优化、PPC 广告、ACOS / ROAS
- KOL 种草、Deal 站引流、海外社媒运营
- 供应链管理、FBA / 海外仓、库存周转
- 跨文化沟通、商务英语、小语种
- 选品、竞品分析、市场调研

### 评分调整说明

1. **语言能力权重提升**：跨境电商对语言能力的要求显著高于国内行业，英语能力（CET-6 / 雅思 6.5+ / 托福 90+）作为硬性门槛；若候选人英语不达标，硬性条件维度直接扣 10 分
2. **跨境平台经验为核心判据**：候选人的跨境平台实操经验（特别是 Amazon 和独立站）在核心经验维度中占比 60% 以上，无跨境经验仅凭国内电商经验，核心经验维度评分上限下调 30%
3. **供应链理解加分**：跨境电商的运营成功高度依赖供应链协同，若候选人仅懂前端运营（广告/Listing）而不了解供应链（备货/物流/仓储），专业技能维度扣 5~8 分
4. **目标市场匹配度加权**：候选人过往经验的市场区域与 JD 目标市场一致时，核心经验维度额外加 5 分；不一致时根据市场相似度酌情加分（如北美经验适配欧洲市场加 2~3 分）
5. **平台合规意识评估**：跨境电商平台政策变动频繁且后果严重（封店/冻结资金），候选人的合规意识和经历是软性素质维度的重要加分项

## 3. 国内电商行业

### 匹配权重表

| 评估维度 | 权重 | 说明 |
|---------|------|------|
| 硬性条件 | 20% | 学历、工作年限、行业年限 |
| 核心经验 | 35% | GMV 量级、品类操盘经历、平台经验、ROI 达成记录 |
| 专业技能 | 25% | 平台运营技能、数据分析能力、活动策划、投放优化 |
| 软性素质 | 20% | 结果导向、抗压能力、跨部门协作、敏捷应变 |

### 关键加分项

| 加分项 | 加分幅度 | 判定依据 |
|--------|---------|---------|
| 高 GMV 操盘经历（年 GMV 5000 万+） | +5~10分 | GMV 量级是电商运营能力的核心证明 |
| ROI / ROAS 达成记录 | +5~8分 | 体现花钱效率和商业化能力 |
| 多平台经验（天猫 + 京东 + 拼多多 + 抖音） | +5~8分 | 每多一个主流平台经验叠加，上限 8 分 |
| 数据分析能力（SQL / BI 工具 / Python） | +5~8分 | 电商运营强依赖数据驱动决策 |
| 大促操盘经历（双11 / 618 / 年货节） | +3~5分 | 证明高压场景下的执行力 |
| 品类深度经验（与 JD 品类一致） | +5~10分 | 品类 know-how 是电商运营的护城河 |

### 典型 JD 关键词

- GMV、ROI、ROAS、CTR、CVR、客单价、复购率
- 天猫 / 京东 / 拼多多 / 抖音 / 快手 / 小红书
- 双11 / 618 大促、聚划算、超级品牌日
- 直通车 / 引力魔方 / 京准通 / 千川
- 选品、定价策略、库存管理
- 数据分析、AB 测试、用户运营
- 品类运营、旗舰店运营、全渠道运营

### 评分调整说明

1. **GMV / ROI 为核心判据**：国内电商高度结果导向，候选人过往 GMV 量级和 ROI 达成记录是核心经验维度的主要评分依据，无法提供量化数据的候选人该维度扣 10~15 分
2. **平台经验权重高**：不同平台的运营逻辑差异大（天猫重品牌、拼多多重性价比、抖音重内容），候选人平台经验与 JD 要求平台不匹配时，核心经验维度扣 5~10 分
3. **数据分析能力加分**：电商运营从经验驱动转向数据驱动，具备 SQL/BI/Python 等数据分析技能的候选人，在专业技能维度额外加 5~8 分
4. **品类经验迁移性评估**：同品类经验可直接加分；跨品类但用户画像相似（如母婴→宠物）可酌情加 3~5 分；跨品类且用户画像差异大（如 3C→美妆）不加分
5. **大促经历为加分项非必选项**：大促操盘经历体现高压执行力，但非所有岗位都涉及大促，根据 JD 要求灵活加分

## 4. 医疗行业

### 匹配权重表

| 评估维度 | 权重 | 说明 |
|---------|------|------|
| 硬性条件 | 35% | 执业资格证书、学历、行业年限、职称 |
| 核心经验 | 30% | 临床/研发/注册经验、项目经历、行业合规经历 |
| 专业技能 | 20% | 专业领域技术能力、GxP 认知、质量管理、文献/数据能力 |
| 软性素质 | 15% | 合规意识、严谨性、跨部门协作、沟通能力 |

### 关键加分项

| 加分项 | 加分幅度 | 判定依据 |
|--------|---------|---------|
| 执业资格证书（执业医师 / 执业药师 / 护士执业证等） | +10~15分 | 多数医疗岗位的硬性准入门槛，无证一票否决 |
| GxP 合规经验（GMP/GCP/GLP/GSP） | +5~10分 | 医疗行业合规是生命线，GxP 经验稀缺且价值高 |
| 行业年限（5年以上） | +5~8分 | 医疗行业经验积累周期长，年限本身是能力证明 |
| 注册/审评经验（NMPA/FDA/CE） | +5~10分 | 产品注册是医疗企业核心能力，相关人才极稀缺 |
| 临床试验经验（I-IV 期） | +5~8分 | 体现对研发全流程的理解 |
| 质量管理经验（QA/QC/内审） | +3~8分 | 质量体系是医疗企业的运营基础 |

### 典型 JD 关键词

- 执业医师 / 执业药师 / 护师 / 检验师
- GMP / GCP / GLP / GSP / ISO 13485
- NMPA / FDA / CE / MDL 注册
- 临床试验 / 伦理审查 / 受试者管理
- 质量体系 / 偏差处理 / CAPA / 变更控制
- 不良事件 / 药物警戒 / 安全性评价
- SOP 编写 / 数据完整性 / 验证与确认

### 评分调整说明

1. **资质证书为硬性门槛**：医疗行业中大量岗位（尤其临床、注册、质量管理）对执业资格证书有硬性要求，无相关证书的候选人在硬性条件维度直接判为不匹配，不再进入后续评分环节
2. **合规意识为核心软性评估**：医疗行业的合规风险极高（涉及患者安全和法规合规底线），候选人的合规意识和合规经历在软性素质维度中占比 40%，无合规经历者该维度扣 8~12 分
3. **行业年限权重高**：医疗行业的知识和技术积累周期显著长于其他行业（临床经验、注册流程、质量体系均需长周期浸淫），行业年限不足 3 年的候选人，核心经验维度评分上限下调 20%
4. **跨行业经验迁移性低**：医疗行业的专业壁垒高，非医疗行业经验（如快消、互联网）的迁移性极低，跨行业候选人核心经验维度评分上限下调 40%，除非其岗位职能与医疗交叉（如医疗行业的数据分析、IT 岗位）
5. **学历门槛严格**：医疗行业对学历要求通常不低于本科，部分岗位（研发、临床医学）要求硕士及以上，学历不达标的候选人硬性条件维度扣 10~15 分
6. **学术成果加分**：发表过 SCI / 核心期刊论文、参与过国家级课题的候选人，在专业技能维度额外加 5~8 分，体现专业深度和行业认可度

## 使用指南

### 如何选用模板

1. **识别行业**：根据 JD 描述的公司行业和岗位属性确定行业分类
2. **选用模板**：匹配上述 4 个行业模板，若 JD 跨行业（如"医疗+互联网"的数字医疗），以主营业务属性为主行业模板，辅行业模板的权重按 30% 折算叠加
3. **微调权重**：根据具体岗位的级别和侧重点微调权重（如管理岗可提升软性维度 3~5 个百分点，技术专精岗可提升专业技能维度 3~5 个百分点）
4. **应用加分项**：逐一核对加分项，累加后计入对应维度的评分
5. **执行评分调整**：按"评分调整说明"中的规则对初步评分进行修正

### 模板扩展

如需新增行业模板，请遵循以下结构：

```markdown
## N. [行业名称]

### 匹配权重表
（硬性条件 / 核心经验 / 专业技能 / 软性素质，合计 100%）

### 关键加分项
（加分项 + 加分幅度 + 判定依据，以表格呈现）

### 典型 JD 关键词
（列出该行业 JD 中高频出现的关键词/短语）

### 评分调整说明
（5~6 条行业特有的评分调整规则，含具体扣分/加分幅度）
```
