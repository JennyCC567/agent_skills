## 功能概述

### 功能定义
支持生成协作评审链接，供多人在线查看候选人报告并提交评审意见，实现团队协作决策。

### 核心价值
- **多人协作**：支持团队成员同时评审
- **实时反馈**：评审意见即时同步
- **决策支持**：汇总多方意见，辅助录用决策

### 使用场景
1. 面试后多人评审候选人
2. 跨部门协作评估人才
3. 团队招聘决策讨论

## 使用流程

### 标准流程

```
1. 生成评审报告
   ↓
2. 生成分享链接
   ↓
3. 发送链接给评审团队
   ↓
4. 团队成员提交评审意见
   ↓
5. 汇总评审意见
   ↓
6. 辅助录用决策
```

### 分步骤说明

#### 步骤1：生成评审报告
根据候选人简历分析结果，生成协作评审HTML报告。

**输入信息**：
- 候选人基本信息
- 匹配度评分
- 详细分析报告

**输出**：协作评审HTML模板

#### 步骤2：配置分享信息
在HTML模板中填写分享信息。

```html
分享时间：2024-01-15
评审链接：https://example.com/review/xxx
```

#### 步骤3：发送评审邀请
将生成的HTML报告或分享链接发送给评审团队。

#### 步骤4：收集评审意见
评审团队成员打开链接，填写评审意见表单。

#### 步骤5：汇总评审数据
智能体收集所有评审意见，生成汇总报告。

## 协作评审模板

### 模板结构

| 区域 | 内容 |
|------|------|
| 头部 | 报告标题、分享信息 |
| 候选人信息 | 基本信息、匹配度 |
| 综合评分 | 多维度评分可视化 |
| 评审意见 | 已提交的评审列表 |
| 添加评审 | 评审意见表单 |

### 模板特性

1. **响应式设计**：适配电脑、平板、手机
2. **打印优化**：支持打印输出
3. **数据输出**：表单数据以JSON格式输出

### 评分维度

| 维度 | 说明 | 满分 |
|------|------|------|
| 硬性条件匹配 | 学历、工作年限等 | 100 |
| 核心经验匹配 | 岗位核心技能匹配度 | 100 |
| 专业技能匹配 | 技术能力、专业证书 | 100 |
| 综合素质评分 | 沟通、协作、学习能力 | 100 |

## 使用示例

### 示例1：技术岗位评审

**场景**：面试后，技术总监和HR共同评审候选人

**Prompt**：
```
请为候选人李明生成协作评审报告：
- 候选人：李明
- 应聘岗位：高级Java工程师
- 匹配度：85%
- 技术评分：88分
- 综合素质：82分
```

**输出**：
- 协作评审HTML报告
- 评审链接

### 示例2：批量评审汇总

**Prompt**：
```
请汇总以下5位候选人的评审意见：
1. 张三 - 评审意见2条
2. 李四 - 评审意见3条
3. 王五 - 评审意见1条
4. 赵六 - 评审意见2条
5. 孙七 - 评审意见1条

生成汇总报告，按综合评分排序。
```

## 注意事项

### 数据安全
- 评审链接建议设置有效期
- 敏感候选人信息需脱敏处理
- 评审意见仅对授权人员可见

### 使用规范
- 评审意见需客观公正
- 避免歧视性言论
- 尊重候选人隐私

### 模板定制
- 可根据企业需求调整评分维度
- 可添加自定义评审字段
- 支持企业Logo定制
