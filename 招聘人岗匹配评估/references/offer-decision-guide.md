# Offer决策建议指南

## 一、功能概述

支持多候选人横向对比分析，提供薪资建议，辅助Offer决策。

## 二、横向对比分析

### 2.1 对比维度

| 维度 | 权重 | 说明 |
|------|------|------|
| 匹配度 | 35% | 人岗匹配综合评分 |
| 薪资预期 | 20% | 与预算的匹配度 |
| 入职意愿 | 15% | 候选人接受Offer的意愿 |
| 发展潜力 | 15% | 成长空间评估 |
| 团队适配 | 15% | 与现有团队的匹配度 |

### 2.2 横向对比表

```markdown
# 多候选人横向对比表

## 对比概览

| 候选人 | 匹配度 | 薪资预期 | 入职意愿 | 潜力 | 适配度 | 综合分 |
|--------|--------|---------|---------|------|--------|--------|
| 张三 | 92分 | 25-30K ✅ | 高 | 高 | 优秀 | 91分 |
| 李四 | 85分 | 28-32K ⚠️ | 中 | 高 | 良好 | 83分 |
| 王五 | 78分 | 30-35K ❌ | 低 | 中 | 一般 | 72分 |

## 推荐优先级

1. **第一推荐：张三**
   - 匹配度最高
   - 薪资预期合理
   - 入职意愿强烈

2. **备选：李四**
   - 技术深度优秀
   - 薪资略高于预算
   - 建议协商

3. **暂缓：王五**
   - 匹配度一般
   - 薪资超出预算
   - 建议继续寻访
```

## 三、薪资建议

### 3.1 薪资结构分析

| 组成部分 | 说明 | 占比 |
|---------|------|------|
| 基本薪资 | 月度固定工资 | 70-85% |
| 绩效奖金 | 季度/年度绩效 | 10-20% |
| 福利补贴 | 餐补、交通补等 | 5-10% |
| 长期激励 | 股票期权（可选） | 0-15% |

### 3.2 薪资制定规则

#### 3.2.1 市场参考

| 参考因素 | 数据来源 |
|---------|---------|
| 行业水平 | 行业薪酬报告 |
| 职位级别 | 职级薪酬表 |
| 地区差异 | 城市薪酬系数 |
| 企业性质 | 外资/民营/国企差异 |

#### 3.2.2 内部平衡

| 平衡因素 | 考虑要点 |
|---------|---------|
| 内部公平 | 同岗不同人薪资差异 |
| 外部竞争 | 市场竞争力 |
| 成本控制 | 预算范围内 |

#### 3.2.3 候选人因素

| 因素 | 影响 |
|------|------|
| 当前薪资 | 涨幅通常15-30% |
| 期望薪资 | 尽量满足或协商 |
| 匹配度 | 高匹配可适当倾斜 |
| 入职紧迫度 | 紧急程度影响决策 |

### 3.3 薪资建议模板

```markdown
# 薪资建议报告

## 候选人基本信息
- 姓名：张三（脱敏）
- 应聘岗位：高级前端工程师
- 当前薪资：20K/月
- 期望薪资：25-30K/月

## 市场参考数据
| 数据来源 | 参考值 |
|---------|--------|
| 行业P50 | 28K/月 |
| 行业P75 | 35K/月 |
| 岗位预算上限 | 32K/月 |

## 薪资方案

### 方案A（推荐）
| 项目 | 金额 | 说明 |
|------|------|------|
| 基本薪资 | 28K/月 | 年薪33.6万 |
| 年终奖金 | 2个月 | 56K |
| 年度总包 | 39.2万 | 涨幅40% |

### 方案B（备选）
| 项目 | 金额 | 说明 |
|------|------|------|
| 基本薪资 | 26K/月 | 年薪31.2万 |
| 绩效奖金 | 20% | 约62K |
| 年度总包 | 37.4万 | 涨幅34% |

### 方案C（底线）
| 项目 | 金额 | 说明 |
|------|------|------|
| 基本薪资 | 25K/月 | 年薪30万 |
| 入职奖金 | 10K | 一次性 |
| 年度总包 | 31万 | 涨幅25% |

## 建议
- **推荐方案A**：匹配度高，候选人接受可能性大
- 如候选人坚持30K，可考虑方案B
- 方案C为底线，不建议低于此标准

## 风险提示
1. 候选人可能还有其他Offer
2. 薪资谈判可能存在不确定性
3. 建议尽快发起Offer
```

## 四、决策支持

### 4.1 决策矩阵

| 决策类型 | 触发条件 | 建议 |
|---------|---------|------|
| 立即发起 | 综合分≥85，薪资合理 | 尽快发Offer |
| 协商后发 | 综合分≥75，薪资需协商 | 积极沟通 |
| 备选等待 | 综合分60-74 | 先发其他人 |
| 继续寻访 | 综合分<60 | 暂不考虑 |

### 4.2 风险提示

| 风险类型 | 表现 | 建议 |
|---------|------|------|
| 薪资风险 | 期望高于市场 | 协商或放弃 |
| 意愿风险 | 入职意愿低 | 深入沟通 |
| 稳定性风险 | 频繁跳槽 | 背景核实 |
| 匹配风险 | 软性不匹配 | 综合评估 |

### 4.3 决策流程

```
候选人分析完成
    ↓
横向对比分析
    ↓
薪资方案建议
    ↓
决策风险提示
    ↓
生成决策报告
    ↓
提交审批流程
```

## 六、使用方式

### 6.1 快速对比

```
请对比[候选人A]和[候选人B]，给出Offer建议
```

### 6.2 完整分析

```
请对以下候选人进行Offer决策分析：
1. [候选人1] - 匹配度92分，期望25-30K
2. [候选人2] - 匹配度85分，期望28-32K
3. [候选人3] - 匹配度78分，期望30-35K
```

### 6.3 薪资查询

```
候选人[姓名]，期望[薪资]，岗位预算[预算]，请给出薪资建议
```

## 七、注意事项

1. **数据支撑**：所有建议基于数据和分析
2. **综合判断**：最终决策应结合实际情况
3. **多方平衡**：平衡候选人、公司、团队利益
4. **及时决策**：避免优秀候选人流失

## 八、免责申明

1. Offer决策建议仅供参考
2. 最终决策由管理人员做出
3. 薪资谈判存在不确定性
4. 遵守公司薪酬制度和流程
5. 遵守相关法律法规
