# 面试题库联动指南

## 一、功能概述

基于候选人特点和岗位要求，智能推荐面试题目，提升面试效率。

## 二、题库分类

### 2.1 按考察维度

| 维度 | 说明 | 题库占比 |
|------|------|---------|
| 技术能力 | 专业知识、工具使用、代码能力 | 30% |
| 项目经验 | 项目理解、问题解决、成果展示 | 25% |
| 综合素质 | 沟通表达、团队协作、学习能力 | 25% |
| 职业素养 | 责任心、抗压、职业规划 | 20% |

### 2.2 按难度等级

| 等级 | 说明 | 适用场景 |
|------|------|---------|
| 基础 | 入门级知识、基础概念 | 校招、初面 |
| 中级 | 实际应用、问题分析 | 社招、二面 |
| 高级 | 系统设计、架构思维 | 高管、终面 |
| 专家 | 前沿技术、管理能力 | CTO、技术VP |

### 2.3 按题型

| 题型 | 特点 | 占比 |
|------|------|------|
| 选择题 | 快速筛选 | 20% |
| 简答题 | 基础认知 | 25% |
| 场景题 | 实际问题解决 | 30% |
| 论述题 | 深度思考 | 25% |

## 三、推荐规则

### 3.1 候选人画像分析

| 分析维度 | 提取内容 |
|---------|---------|
| 技术栈 | 使用的编程语言、框架、工具 |
| 经验深度 | 工作年限、项目复杂度 |
| 职业轨迹 | 跳槽频率、成长路径 |
| 突出成果 | 量化的业绩、排名、奖项 |
| 潜在短板 | 简历中的空白、频繁转岗 |

### 3.2 岗位需求映射

| 需求类型 | 考察重点 |
|---------|---------|
| 硬性要求 | 必须具备的技能、证书、经验 |
| 软性要求 | 沟通、协作、文化匹配 |
| 加分项 | 稀缺技能、相关资源 |
| 淘汰项 | 明确不接受的背景 |

### 3.3 题目推荐算法

```python
# 推荐逻辑
recommended_questions = []

# 1. 必考题：岗位硬性要求相关
for req in hard_requirements:
    questions.append(get_core_questions(req))

# 2. 深入题：候选人经验延伸
for exp in candidate_experiences:
    questions.append(get_deep_questions(exp))

# 3. 考察题：候选人短板验证
for gap in candidate_gaps:
    questions.append(get_verification_questions(gap))

# 4. 适配题：团队文化匹配
for value in team_culture:
    questions.append(get_culture_questions(value))

# 5. 排序：按重要性和深度排序
questions.sort_by_importance()
```

## 四、输出格式

### 4.1 候选人面试提纲

```markdown
# 张三 - 前端工程师面试提纲

## 基础信息
- 面试岗位：高级前端工程师
- 面试时长：60分钟
- 建议面试官：技术负责人

## 必考题目（15分钟）

### 1. Vue/React 深度理解
请详细讲解 Vue 的响应式原理，以及与 React 的核心差异。

### 2. 性能优化实战
请分享一个你负责的性能优化项目，包括优化前后的数据对比。

### 3. 工程化实践
你们团队是如何搭建前端工程化体系的？有哪些核心工具？

## 项目深挖（25分钟）

### 1. 电商项目
在项目中遇到的最大技术挑战是什么？如何解决的？

### 2. 数据可视化
请讲解你实现的一个复杂可视化组件的设计思路。

## 综合素质（15分钟）

### 1. 团队协作
如何处理团队内部的技术争议？请举例说明。

### 2. 学习成长
最近学习了哪些新技术？有什么学习心得？

## 陷阱题（5分钟）

### 1. 离职原因
你为什么离开上家公司？这个问题主要考察...

## 面试建议
- 此候选人技术深度足够，重点考察架构思维
- 建议用场景题验证实战能力
- 注意考察团队协作能力
```

## 七、注意事项

1. **题目仅作参考**：根据实际情况调整
2. **避免机械提问**：根据候选人回答灵活追问
3. **尊重候选人**：避免压力面试、歧视性问题
4. **记录评估**：及时记录候选人回答情况

3. 禁止使用歧视性、侵犯隐私的问题
4. 最终录用决策应综合考虑多方面因素
