# 人岗综合评估标准

## 人岗综合评估（高阶版）

### 输入要求

1. 标准岗位 JD
2. 简历匹配度分析报告
3. 面试记录（含面试官提问、候选人回答、行为表现等）
4. 企业组织文化与团队风格说明

### 输出标准

#### 1. 综合评估结论
给出 "强烈推荐 / 推荐 / 谨慎推荐 / 不推荐" 的最终结论

#### 2. 能力胜任度评估

|------|---------|-----------|---------|
| {能力1} | {要求} | {表现} | {优秀 / 良好 / 合格 / 不合格} |
| {能力2} | {要求} | {表现} | {优秀 / 良好 / 合格 / 不合格} |

#### 3. 职业稳定性评估
基于过往工作经历、离职原因、职业规划等进行分析

**评估维度**：
- 工作稳定性（跳槽频率、在职时长）
- 职业发展路径（是否清晰合理）
- 离职原因（是否合理）
- 职业规划（与岗位匹配度）

**评估结论**：{高稳定 / 中等稳定 / 稳定性较低}

#### 4. 发展潜力评估
评估候选人的学习能力、成长速度与未来发展空间

**评估维度**：
- 学习能力（掌握新技术的速度）
- 成长速度（职业晋升速度）
- 创新能力（提出创新方案的能力）
- 领导潜质（团队管理和带领能力）

**评估结论**：{高潜力 / 中等潜力 / 潜力一般}

#### 5. 组织文化适配度评估
分析候选人的价值观、工作风格与企业及团队的匹配程度

**评估维度**：
- 价值观匹配（个人价值观与企业价值观）
- 工作风格（个人工作方式与团队风格）
- 沟通方式（个人沟通特点与团队沟通风格）
- 团队协作（个人协作能力与团队需求）

**评估结论**：{高度适配 / 基本适配 / 需要适应}

#### 6. 薪资预期匹配度评估
对比候选人薪资预期与企业该岗位薪资范围

### 行业标准合规保障

1. **行为事件访谈法（BEI）**
   - 采用行为事件访谈法进行评估
   - 基于候选人过往行为预测未来表现
   - 关注具体行为案例，而非主观评价

2. **多维度综合评估**
   - 多维度综合评估，避免单一维度判断失误
   - 综合考虑能力、稳定性、潜力、文化适配度等

3. **区分短板类型**
   - 区分 "可以培养的短板" 与 "不可接受的硬伤"
   - 明确哪些是可以通过培养改进的
   - 明确哪些是不可接受的硬伤

4. **事实支撑**
   - 所有评估结论均有具体事实与案例支撑
   - 不做空泛评价
   - 基于面试记录和简历信息进行判断

## 薪资评估标准规范

### 一、薪资结构说明

| 组成部分 | 说明 | 常见比例 |
|---------|------|---------|
| **基本薪资** | 月度固定工资 | 占年薪的 70-85% |
| **绩效奖金** | 与个人/团队绩效挂钩 | 占年薪的 10-20% |
| **年终奖金** | 年度整体绩效奖励 | 1-6 个月基本薪资 |
| **福利补贴** | 餐补、交通补、通讯补等 | 视企业而定 |
| **长期激励** | 股票期权、限制性股票等 | 适用于中高管理层 |

### 二、薪资等级体系

| 等级 | 工作年限 | 基本薪资范围（参考值） |
|------|---------|---------------------|
| **初级** | 0-2 年 | 城市最低工资 ~ 1.5 倍中位数 |
| **中级** | 3-5 年 | 0.8 ~ 1.5 倍中位数 |
| **高级** | 6-10 年 | 1.2 ~ 2.0 倍中位数 |
| **专家级** | 10 年以上 | 2.0 倍以上中位数 |

**说明**：薪资等级需结合城市、行业、企业性质综合确定。

### 三、薪资区间拟定规则

#### 3.1 多维度综合评估要素

| 维度 | 影响因素 | 权重说明 |
|------|---------|---------|
| **所在城市** | 一线/二线/三线城市薪资差异显著 | 非常重要（±30-50%） |
| **行业** | 互联网/金融/制造等薪资水平差异 | 非常重要（±20-40%） |
| **企业性质** | 外资/民营/国企/事业单位差异 | 较重要（±15-30%） |
| **工作年限** | 决定薪资等级的基础因素 | 重要（±10-20%） |
| **岗位职级** | 初级/中级/高级/专家级 | 重要（±15-25%） |
| **学历背景** | 本科/硕士/博士差异 | 一般（±5-15%） |
| **专业技能** | 稀缺技能可获得溢价 | 视情况（±10-30%） |
| **稀缺程度** | 市场供需关系影响 | 视情况（±10-25%） |

#### 3.2 数据来源规范

| 数据类型 | 来源渠道 | 可信度 |
|---------|---------|--------|
| **政府官方数据** | 人社部、行业主管部门发布的薪酬指导线 | ✅✅ 极高 |
| **权威机构报告** | 智联招聘、BOSS直聘、前程无忧等发布的行业报告 | ✅✅ 高 |
| **企业年报数据** | 上市公司薪酬数据披露 | ✅✅ 高 |
| **统计数据** | 国家统计局、地方统计局数据 | ✅ 高 |
| **市场调研数据** | 专业咨询公司报告（麦肯锡、怡安翰威特等） | ✅✅ 高 |

**禁止使用**：未经核实的网络数据、主观估算数据、无来源的市场传言。

#### 3.3 薪资区间拟定流程

```
第一步：确定基准薪资
  → 根据岗位职级和工作年限，确定城市中位数薪资

第二步：多维度调整
  → 城市系数 × 行业系数 × 企业性质系数 × 个人条件系数

第三步：区间拟定
  → 低位值 = 基准值 × 0.85
  → 中位值 = 基准值 × 1.0
  → 高位值 = 基准值 × 1.3

第四步：合理性校验
  → 校验是否虚高或偏低
  → 校验是否与市场数据一致
  → 校验是否与候选人预期匹配
```

### 四、客观合理性保障

#### 4.1 禁止事项

| 禁止事项 | 说明 |
|---------|------|
| **❌ 禁止虚高** | 不得为了吸引候选人故意报高价 |
| **❌ 禁止偏低** | 不得为了控制成本故意压低薪资 |
| **❌ 禁止脱离市场** | 不得严重偏离市场平均水平 |
| **❌ 禁止无依据** | 薪资拟定必须有数据支撑 |
| **❌ 禁止歧视** | 不得因性别、年龄、地域等设定歧视性薪资 |

#### 4.2 合理性校验标准

| 校验项 | 合理区间 | 超标处理 |
|-------|---------|---------|
| **与市场数据偏差** | ±15% 以内 | 超出需特别说明 |
| **与候选人预期偏差** | ±20% 以内 | 超出需协商 |
| **内部公平性** | 同岗差异 ≤ 30% | 需考虑内部平衡 |
| **外部竞争力** | P50-P75 分位 | 核心岗位建议 P75 |

#### 4.3 数据更新要求

| 数据类型 | 更新频率 | 说明 |
|---------|---------|------|
| **政府官方数据** | 年度更新 | 按最新发布数据 |
| **行业报告数据** | 半年度/年度更新 | 按最新报告 |
| **企业内部数据** | 实时更新 | 结合实际招聘情况 |

## 评估方法说明

### 1. 行为事件访谈法（BEI）

**原理**：
通过询问候选人过去在特定情境下的具体行为，预测其未来的工作表现

**实施步骤**：
1. 确定评估的关键能力维度
2. 设计行为面试问题（STAR法则）
3. 收集候选人的具体行为案例
4. 分析行为模式，评估能力水平

**示例问题**：
- "请描述一个你成功解决的技术难题"
- "请描述一次你与团队发生冲突的经历"
- "请描述一个你主导的项目"

### 2. 多维度综合评估

**评估维度**：
- 能力胜任度（30%）
- 职业稳定性（20%）
- 发展潜力（20%）
- 组织文化适配度（15%）
- 薪资预期匹配度（15%）

**评分标准**：
- 优秀：90-100分
- 良好：80-89分
- 合格：70-79分
- 不合格：<70分

### 3. 风险识别与应对

**常见风险类型**：
1. 职业稳定性风险
2. 能力胜任度风险
3. 文化适配风险
4. 薪资预期风险

**风险等级**：
- 高风险：严重影响岗位履职，建议不录用
- 中风险：有一定影响，需要重点关注和培养
- 低风险：影响较小，可以接受

## 评估质量控制

### 1. 评估一致性
- 不同评估者对同一候选人的评估结果应基本一致
- 使用统一的评估标准和评分体系
- 定期进行评估者培训

### 2. 评估客观性
- 基于事实和数据，避免主观臆断
- 所有评估结论必须有具体案例支撑
- 避免受第一印象、偏见等影响

### 3. 评估可追溯性
- 记录评估过程和依据
- 保存面试记录和评估资料
- 便于后续查询和复核

### 4. 评估合规性
- 严格遵守就业促进法等相关法律法规
- 杜绝任何歧视性表述
- 保护候选人隐私

## 薪资数据源透明化规范

### 数据来源声明模板

所有涉及薪资评估的报告，**必须**在报告末尾或薪资评估章节显著位置标注以下声明：

```
本薪资评估参考以下公开数据源：
1. [数据源1名称 + 发布时间]（如：人社部2025年企业薪酬调查信息 + 2025年6月）
2. [数据源2名称 + 发布时间]（如：智联招聘2025年春季雇主需求与白领人才供给报告 + 2025年3月）

以上数据仅供参考，不构成定薪依据。实际薪资应根据企业内部薪酬体系、候选人实际能力及面试表现综合确定。
```

声明要求：
- 必须列出实际参考的数据源名称和发布时间，不得省略
- 每份报告至少标注2个数据源
- 声明位置醒目，不得隐藏在脚注或小字中

### 推荐数据源清单

|-------|---------|---------|---------|--------|
| **人社部工资指导价** | 人力资源和社会保障部 | 全国各城市、各行业 | 年度 | ✅✅✅ 极高 |
| **各城市人社局行业薪酬指导线** | 地方人社局 | 城市级、行业级 | 年度 | ✅✅✅ 极高 |
| **智联招聘年度薪酬报告** | 智联招聘 | 全行业、全城市 | 年度 | ✅✅ 高 |

### 数据时效性要求

| 数据年龄 | 使用要求 | 标注说明 |
|---------|---------|---------|
| **1年以内** | ✅ 优先使用 | 正常使用，无需额外标注 |
| **1-2年** | ⚠️ 可使用 | 需标注"数据发布于X年X月，请注意时效性" |
| **超过2年** | ❌ 不建议使用 | 如必须使用，**必须**标注"数据可能存在滞后，建议以最新市场情况为准" |
| **超过3年** | 🚫 禁止使用 | 不得作为薪资评估依据 |

优先级：1年内数据 > 1-2年数据（附标注）> 其他

### 禁止行为

| 禁止事项 | 说明 | 原因 |
|---------|------|------|
| **❌ 不使用企业内部薪资数据** | 不得引用任何企业的内部薪资体系、薪酬宽带等非公开数据 | 数据保密性及合规性 |
| **❌ 不使用付费报告数据** | 不得引用需要付费购买的薪酬报告数据（如美世、怡安翰威特等付费报告） | 数据获取合规性，用户无法验证 |
| **❌ 不编造薪资数据** | 不得凭主观判断或估算编造任何薪资数据 | 数据真实性及专业性 |
| **❌ 不使用单一数据源** | 薪资评估必须参考至少2个独立数据源 | 避免单一数据源偏差 |
| **❌ 不使用未经核实的网络数据** | 不得使用论坛、社交媒体等非权威来源的薪资信息 | 数据可靠性无法保障 |

### 评估区间规范

薪资评估**必须**给出范围，严禁给出单一数值：

| 规范项 | 要求 | 示例 |
|-------|------|------|
| **范围格式** | 必须给出区间范围 | 25-35K（✅）、30K（❌） |
| **分位值标注** | 必须说明对应的分位值 | P50-P75（✅）、未标注（❌） |
| **单位明确** | 明确月薪/年薪 | 25-35K/月 或 30-42万/年 |
| **条件说明** | 说明范围对应的条件 | 含年终奖3个月 / 不含期权 |

#### 分位值参考标准

| 分位值 | 含义 | 适用场景 |
|-------|------|---------|
| **P25** | 市场低位值，25%的人低于此水平 | 候选人条件基本达标但无突出优势 |
| **P50** | 市场中位值，50%的人低于此水平 | 候选人条件符合岗位要求 |
| **P75** | 市场高位值，75%的人低于此水平 | 候选人条件优于多数竞争者 |
| **P90** | 市场极高值，90%的人低于此水平 | 候选人为稀缺人才或具有突出优势 |

#### 标准输出格式

```
推荐薪资范围：25-35K/月（P50-P75）
对应条件：3-5年经验 | 一线城市 | 互联网行业 | 中级岗位

薪资结构建议：
- 基本薪资：22-28K/月（占年薪75-80%）
- 绩效奖金：3-5K/月（占年薪10-15%）
- 年终奖金：2-4个月基本薪资
- 综合年薪：35-50万
```
