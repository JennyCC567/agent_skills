## 【虚假简历识别增强版Prompt模板】

### 一、三道防线体系

#### 第一道防线-初筛

**检测项目**：
1. **时间线检查**
   - 工作经历时间是否重叠或间断不合理
   - 毕业时间与工作起始时间是否矛盾
   - 职位晋升时间线是否符合常规

2. **逻辑悖论检查**
   - 职位级别与工作年限是否匹配
   - 技能掌握程度与学习/工作时间是否匹配
   - 薪资水平与职位级别是否匹配

3. **细节检查**
   - 公司名称、职位名称是否具体明确
   - 项目描述是否有具体数据支撑
   - 技术栈描述是否合理

**输出格式**：
```json
{
  "第一道防线_初筛": {
    "时间线检查": {
      "状态": "通过/异常",
      "异常项": ["异常描述"]
    },
    "逻辑悖论检查": {
      "状态": "通过/异常",
      "异常项": ["异常描述"]
    },
    "细节检查": {
      "状态": "通过/异常",
      "异常项": ["异常描述"]
    },
    "初筛结论": "通过/待核实/疑似虚假"
  }
}
```

#### 第二道防线-追问

**结构化追问模板**：

1. **时间线追问**
   ```
   您在[公司名称]的工作时间是[时间段]，期间主要负责哪些项目？请详细描述一个您印象最深的项目。
   ```

2. **技术细节追问**
   ```
   您简历中提到熟悉[技术栈]，请问在实际项目中，您是如何应用这项技术的？请举一个具体案例。
   ```

3. **业绩成果追问**
   ```
   您提到取得了[业绩描述]，请问具体的衡量指标是什么？这个成果是如何量化评估的？
   ```

4. **技术专项追问**（针对技术岗位）
   ```
   请描述您在[技术领域]遇到的最大挑战，以及您是如何解决的？
   ```

**追问策略**：
- 针对初筛发现的异常点进行针对性追问
- 追问要具体、可验证
- 技术岗位重点考察实际动手能力

#### 第三道防线-背调

**背调渠道**：

1. **官方渠道**
   - 学历验证：学信网查询
   - 职业资格：人社部证书查询
   - 工作经历：社保缴纳记录（需授权）

2. **人际验证**
   - 前同事/上司访谈
   - 业务合作方访谈

3. **社交网络**
   - LinkedIn等职业社交平台验证
   - 行业会议/活动参与记录

**背调合规要求**：
- ⚠️ **必须书面授权**：背调前必须获得候选人书面授权
- ⚠️ **仅限授权范围**：背调内容仅限候选人授权范围内
- ⚠️ **隐私保护**：背调结果仅用于招聘决策

### 二、异常信号清单

#### 第一类：时间线异常

| 信号类型 | 典型表现 | 风险等级 |
|---------|---------|---------|
| 时间重叠 | 多段工作经历时间重叠 | 高 |
| 时间断层 | 长期空白期无合理解释 | 中 |
| 时间矛盾 | 毕业时间晚于工作起始时间 | 高 |
| 频繁跳槽 | 1年内更换3次以上工作 | 中 |

#### 第二类：业绩异常

| 信号类型 | 典型表现 | 风险等级 |
|---------|---------|---------|
| 夸大业绩 | 描述与职位级别不符 | 高 |
| 模糊表述 | 无具体数据支撑 | 中 |
| 团队成果 | 将团队成果描述为个人成果 | 高 |
| 虚假数据 | 数据明显不合常理 | 高 |

#### 第三类：技术异常

| 信号类型 | 典型表现 | 风险等级 |
|---------|---------|---------|
| 技能罗列 | 技术栈与项目经历不匹配 | 中 |
| 深度不足 | 技术描述停留表面 | 中 |
| 工具堆砌 | 罗列大量工具但无应用场景 | 低 |
| 断层明显 | 技术更新与职业发展不匹配 | 中 |

#### 第四类：行为异常

| 信号类型 | 典型表现 | 风险等级 |
|---------|---------|---------|
| 回避问题 | 追问时回避关键细节 | 高 |
| 前后矛盾 | 回答与简历描述不一致 | 高 |
| 过度包装 | 使用过多修饰词 | 中 |
| 催促上岗 | 异常急切要求尽快入职 | 中 |

### 三、综合判断标准

**判定等级**：
- **A（可信）**：三道防线均通过，无异常信号
- **B（存疑）**：初筛发现1-2项异常，需追问核实
- **C（可疑）**：追问后仍有疑点，建议谨慎录用
- **D（虚假）**：发现明确虚假信息，建议不录用

**综合评估输出**：
```json
{
  "虚假简历识别_综合评估": {
    "第一道防线": "通过/异常",
    "第二道防线": "通过/异常",
    "第三道防线": "通过/需授权/不适用",
    "异常信号": ["信号类型和描述"],
    "风险等级": "A/B/C/D",
    "录用建议": "建议录用/建议谨慎/建议不录用",
    "核实重点": ["需要进一步核实的点"],
    "背调建议": "建议背调/必须背调/暂不需背调"
  }
}
```

### 四、虚假简历识别Prompt模板

```
## 角色设定
你是一位资深HR，擅长识别虚假简历。请对候选人简历进行全面的虚假检测。

## 输入信息
- 候选人姓名：[姓名]
- 简历内容：[简历全文]

## 检测要求

### 第一道防线-初筛（必做）
1. 时间线检查：工作经历时间是否重叠、间断、矛盾
2. 逻辑悖论检查：职位级别、技能掌握、薪资水平是否合理
3. 细节检查：公司名称、职位名称、项目描述是否具体

### 第二道防线-追问（针对异常项）
对初筛发现的异常点，生成3-5个针对性追问问题

### 第三道防线-背调（可选）
根据异常等级，建议是否需要进行背调，以及背调重点

### 异常信号检测
检测以下4类异常信号：
1. 时间线异常
2. 业绩异常
3. 技术异常
4. 行为异常

## 输出格式
请按以下JSON格式输出检测结果：
{
  "第一道防线_初筛": {...},
  "第二道防线_追问": [...],
  "异常信号清单": [...],
  "综合评估": {...},
  "背调建议": {...}
}

## 合规要求
- 背调必须获得候选人书面授权
- 背调内容仅限授权范围
- 保护候选人隐私信息
```
