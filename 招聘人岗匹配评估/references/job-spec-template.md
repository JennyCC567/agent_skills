## 使用示例

# 岗位说明书：机电工程师

## 基本信息

- **岗位名称**：机电工程师
- **所属部门**：工程部
- **汇报对象**：工程部经理
- **下属人数**：3人
- **工作地点**：深圳市南山区

## 岗位职责

1. 负责机电设备的日常维护、保养和故障排除
2. 参与新设备的选型、安装和调试工作
3. 编写设备操作手册和维护保养计划
4. 负责设备改造项目的技术方案设计和实施
5. 指导和培训团队成员，提升团队技术水平

## 任职要求

### 硬性条件
- **学历要求**：本科及以上
- **专业要求**：机电类相关专业
- **工作年限**：3年以上
- **年龄要求**：25-40岁

### 技能要求
- **专业技能**：
  - PLC编程：熟练
  - AutoCAD：熟练
  - SolidWorks：熟练
  - 机电设备维护：熟练
- **通用技能**：
  - 项目管理
  - 团队协作
  - 沟通能力

### 证书要求
- **必须证书**：
  - 电工证
- **可选证书**：
  - 电工高级证书
  - PLC认证证书

### 经验要求
- **行业经验**：制造业或设备维护行业
- **项目经验**：有大型设备改造项目经验优先
- **管理经验**：有带3人以上团队经验

### 其他要求
- 能适应出差和现场工作
- 具备良好的问题分析和解决能力

## 薪资范围
- 15-25K/月

---

## 注意事项

1. **格式一致性**：确保所有岗位说明书使用统一格式，便于智能体解析
2. **信息完整性**：尽可能详细填写各个字段，提高匹配分析的准确性
3. **技能清单**：技能要求尽量具体，避免模糊描述
4. **权重配置**：默认匹配权重为：学历10%、专业10%、工作年限20%、技能30%、证书10%、管理经验10%、项目经验10%，可根据岗位特点调整
5. **存储方式**：建议将岗位说明书存储为 Markdown 或 JSON 格式，便于检索和解析
