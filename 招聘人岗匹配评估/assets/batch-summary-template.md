# 简历批量分析・Excel 汇总模板

## 使用说明

本模板为简历批量分析的 Excel 汇总标准格式，请按以下步骤操作：

### 第一步：复制数据

将 AI 生成的 Markdown 格式汇总表复制到下方表格区域。

### 第二步：应用格式

1. 选择整个数据区域
2. 应用以下格式规范
3. 设置表头样式
4. 开启筛选功能

### 第三步：保存文件

1. 文件 → 另存为 → 选择位置
2. 文件名格式：`简历批量分析_汇总_{日期}_{候选人数量}人.xlsx`
3. 保存类型：Excel 工作簿 (*.xlsx)

## 标准格式规范

### 表头样式（必做）

| 格式要素 | 设置方法 |
|---------|---------|
| **加粗** | 开始 → 字体 → 加粗 |
| **居中** | 开始 → 对齐方式 → 水平居中、垂直居中 |
| **背景色** | 开始 → 字体 → 填充颜色（建议：深蓝色 #4472C4，白色字体） |
| **字体** | 微软雅黑，11号 |
| **行高** | 22pt |

### 内容样式

| 格式要素 | 设置方法 |
|---------|---------|
| **字体** | 微软雅黑，10号 |
| **对齐** | 文本左对齐，数字居中 |
| **行高** | 18-20pt |
| **边框** | 全边框，细线 |

### 筛选功能（必开）

1. 选择数据区域任意单元格
2. 数据 → 筛选
3. 表头出现下拉箭头
4. 支持快速检索、排序、统计

## 批量操作技巧

### 1. 统一设置列宽

1. 选中所有列
2. 列标边缘双击自动适应
3. 或手动拖动调整

### 2. 批量设置对齐

1. Ctrl + A 全选
2. 开始 → 对齐方式 → 选择对齐方式

### 3. 快速应用边框

1. 选择数据区域
2. 开始 → 字体 → 边框 → 所有框线

### 4. 条件格式（可选）

匹配度列可设置颜色标识：
- ≥ 85%：绿色背景
- 70%-84%：黄色背景
- 50%-69%：橙色背景
- < 50%：红色背景

## 常见问题处理

### Q1：数据粘贴后格式混乱？
**A**：粘贴时选择"匹配目标格式"或"只保留文本"

### Q2：长文本无法完整显示？
**A**：选中单元格 → 开始 → 对齐方式 → 自动换行 → 调整行高

### Q3：如何按匹配度排序？
**A**：点击匹配度列下拉箭头 → 排序 → 降序/升序

### Q4：如何筛选特定岗位？
**A**：意向岗位列 → 下拉箭头 → 选择目标岗位

### Q5：WPS 打开格式不同？
**A**：另存为时选择"Excel 97-2003 格式 (*.xls)"提高兼容性
