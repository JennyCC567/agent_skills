## 概览
人才搜寻是猎头工作的核心环节，AI可显著提升搜索效率和质量。

**核心目标**：
- 精准定位目标候选人
- 缩短搜索时间200%
- 提高候选人质量

**关键指标**：
- 搜索效率提升：从2小时降至1小时
- 候选人匹配度：从随机筛选到精准定位
- 覆盖面提升：从单一关键词到多维度组合

## 关键词生成方法

### 关键词类型

#### 1. 技能关键词
- **必备技能**：从JD解析中提取的核心技能
- **同义词扩展**：如"K8s"与"Kubernetes"、"ML"与"Machine Learning"
- **相关技能**：技能的上下游关联技能

**示例**：
```
JD要求：Kubernetes、Docker、微服务

关键词组合：
- Kubernetes AND Docker
- K8s AND 容器
- 微服务 AND (Kubernetes OR K8s)
- Docker AND 微服务架构
```

#### 2. 职位关键词
- **标准职位名称**：如"Java开发工程师"
- **职位别名**：如"后端工程师"、"服务端开发"
- **级别关键词**：如"高级"、"资深"、"架构师"

**示例**：
```
JD职位：高级Java开发工程师

关键词组合：
- Java开发 AND 高级
- 后端工程师 AND Java
- Java架构师
- 资深Java开发
```

#### 3. 行业关键词
- **行业名称**：如"互联网金融"、"电商"
- **业务类型**：如"B2C"、"SaaS"、"To B"
- **公司类型**：如"互联网大厂"、"独角兽"

**示例**：
```
目标行业：互联网金融

关键词组合：
- 互联网金融 AND Java
- 金融科技 AND 后端
- 支付系统 AND 开发
```

### 关键词生成流程

```
步骤1：从JD解析结果中提取技能矩阵
  v
步骤2：识别核心技能与加分技能
  v
步骤3：为每个核心技能生成同义词
  v
步骤4：组合生成关键词组（10-20组）
  v
步骤5：人工审核与微调
  v
步骤6：在平台内执行搜索
```

### 关键词组合原则

**原则1：核心技能优先**
- 每组关键词必须包含至少1个核心技能
- 核心技能使用AND连接

**原则2：适度扩展**
- 使用OR连接同义词和别名
- 避免过度扩展导致噪声

**原则3：排除干扰**
- 使用NOT排除不相关岗位
- 如"Java NOT JavaScript"

**原则4：平台适配**
- 根据主流招聘平台平台的搜索语法调整
- 测试关键词效果后迭代优化

## 人才地图生成

### 什么是人才地图

人才地图是从公开信息中提取的目标公司人才分布图，包括：
- 目标公司名单
- 部门架构
- 关键岗位
- 人才流动趋势

### 人才地图生成流程

```
步骤1：确定目标公司类型
  - 公司规模
  - 行业领域
  - 业务模式
  v
步骤2：AI生成目标公司名单
  - 基于公开财报
  - 行业报告
  - 新闻资讯
  v
步骤3：分析公司架构
  - 相关部门
  - 团队规模
  - 关键岗位
  v
步骤4：整理人才地图
  - 公司名称
  - 部门/团队
  - 目标岗位
  v
步骤5：在平台内定向搜索
```

### 人才地图示例

```
【职位】高级Java开发工程师
【行业】互联网金融

目标公司地图：
1. 蚂蚁集团 | 技术风险部/网商银行 | 后端开发、架构师 | 备注：支付、风控技术领先
2. 腾讯金融 | 微信支付/财付通 | Java开发 | 备注：高并发场景丰富
3. 京东数科 | 京东支付/金融云 | 后端工程师 | 备注：金融云技术栈匹配
4. 美团金融 | 美团支付/金融平台 | Java开发 | 备注：业务快速增长
5. 字节跳动 | 抖音支付/金融业务 | 后端开发 | 备注：技术氛围好
```

### 人才地图使用方法

**方法1：定向搜索**
- 在主流招聘平台平台搜索"蚂蚁集团 AND Java"
- 逐个公司进行定向搜索

**方法2：部门聚焦**
- 优先关注核心部门
- 如蚂蚁集团的"技术风险部"

**方法3：人才流动**
- 关注离职人员
- 关注竞争对手人才

## 布尔检索式构建

### 布尔运算符说明

| 运算符 | 含义 | 示例 | 效果 |
|--------|------|------|------|
| AND | 与 | Java AND Spring | 同时包含Java和Spring |
| OR | 或 | K8s OR Kubernetes | 包含任一关键词 |
| NOT | 非 | Java NOT JavaScript | 包含Java但不包含JavaScript |
| () | 分组 | (Java OR Python) AND 后端 | 组合逻辑 |

### 布尔检索式模板

**模板1：核心技能组合**
```
{核心技能1} AND {核心技能2} AND {核心技能3}
示例：Java AND Spring AND MySQL
```

**模板2：技能别名扩展**
```
({技能标准名} OR {技能别名1} OR {技能别名2})
示例：(Kubernetes OR K8s OR 容器编排)
```

**模板3：职位+技能组合**
```
{职位名称} AND {核心技能}
示例：(后端工程师 OR 服务端开发) AND Java
```

**模板4：排除干扰**
```
{核心关键词} NOT {干扰关键词}
示例：Java NOT (JavaScript OR 前端)
```

**模板5：高级组合**
```
({职位名称} OR {职位别名}) AND ({核心技能1} OR {核心技能2}) NOT {排除项}
示例：(架构师 OR 技术专家) AND (分布式 OR 微服务) NOT 初级
```

### 布尔检索式生成流程

```
步骤1：提取JD核心技能（5-10项）
  v
步骤2：为每个技能生成别名列表
  v
步骤3：确定职位名称及别名
  v
步骤4：识别需要排除的干扰项
  v
步骤5：组合生成5-10组布尔检索式
  v
步骤6：在平台内测试并优化
```

- 稀缺人才定位
- 高端候选人背景调研
- 人才流动趋势分析

**操作方法**：
1. 使用AI生成的布尔检索式
2. 在LinkedIn搜索框输入
3. 浏览公开档案（无需登录）
4. 人工记录关键信息

**合规要求**：
- [是] 浏览公开页面（无需登录）

- [否] 保存联系方式
- [否] 使用需要登录的信息

## 效率优化建议

### 时间分配优化

**传统模式**：
```
关键词思考：30分钟
反复试错：60分钟
简历浏览：30分钟
总计：120分钟
```

**AI辅助模式**：
```
关键词生成：5分钟
平台搜索：25分钟
简历筛选：30分钟
总计：60分钟
效率提升：50%
```

### 质量提升方法

**方法1：多轮迭代**
- 第一轮：广泛搜索
- 第二轮：精准聚焦
- 第三轮：补充遗漏

**方法2：对比验证**
- 使用不同关键词组合
- 对比搜索结果
- 优化关键词策略

**方法3：结果记录**
- 记录有效关键词
- 积累行业经验
- 建立关键词库

### 常见问题与解决

**问题1：搜索结果太少**
- 原因：关键词过于严格
- 解决：放宽条件，使用OR扩展

**问题2：搜索结果太多**
- 原因：关键词过于宽泛
- 解决：增加AND条件，使用NOT排除

**问题3：结果质量不高**
- 原因：关键词不够精准
- 解决：使用核心技能，排除干扰项

**问题4：遗漏优秀候选人**
- 原因：关键词单一
- 解决：使用多种关键词组合，多轮搜索
