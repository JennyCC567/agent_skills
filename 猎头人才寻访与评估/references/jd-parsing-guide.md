## 概览
JD解析是将原始职位描述文本转换为结构化数据的过程，是候选人匹配的基础。

**适用范围**：所有类型的职位JD

**输出目标**：生成包含核心信息的JD摘要

**效率提升**：
- 原人工分析：15-20分钟/份
- AI辅助后：2-3分钟/份
- 时间压缩：80%以上

## 必需字段

### 1. 职位基本信息
| 字段名 | 说明 | 示例 |
|--------|------|------|
| 职位名称 | 招聘岗位的正式名称 | 高级Java开发工程师 |
| 工作地点 | 职位所在城市/区域 | 北京市海淀区 |
| 薪资范围 | 月薪或年薪范围 | 25k-35k/月 |

**提取规则**：
- 职位名称：优先提取"招聘"、"诚聘"等关键词后的职位名
- 工作地点：提取"工作地点"、"地点"、"base"等关键词后的地点信息
- 薪资范围：提取"薪资"、"待遇"、"月薪"等关键词后的范围

### 2. 岗位职责
| 字段名 | 说明 | 示例 |
|--------|------|------|
| 核心职责 | 该岗位的主要工作内容 | 负责后端服务开发与维护 |
| 职责列表 | 具体的工作职责点 | - 参与需求分析与系统设计<br>- 负责核心模块开发 |

**提取规则**：
- 识别"岗位职责"、"工作内容"、"主要职责"等段落
- 提取职责点，每项职责概括为一句话
- 标注职责的优先级（核心职责 vs 辅助职责）

### 3. 任职要求
| 字段名 | 说明 | 示例 |
|--------|------|------|
| 学历要求 | 最低学历要求 | 本科及以上 |
| 经验要求 | 工作年限要求 | 3-5年相关经验 |
| 技能要求 | 必需的专业技能 | Java、Spring、MySQL |
| 软性要求 | 沟通、团队协作等软技能 | 良好的沟通能力、团队协作精神 |

**提取规则**：
- 学历：识别"学历"、"本科"、"硕士"等关键词
- 经验：识别"经验"、"年限"等关键词
- 技能：识别技术名词、工具名称
- 软性要求：识别"沟通"、"团队"、"责任心"等关键词

## 可选字段

### 1. 团队介绍

### 2. 发展空间

- 识别"团队"、"发展"、"福利"等段落
- 提取关键信息，用于候选人沟通

## 解析流程

### 步骤1：分段识别
```
原始JD文本
  v
识别段落标题（岗位职责、任职要求等）
  v
将文本划分为不同段落
```

### 步骤2：信息提取
```
每个段落
  v
识别关键信息点
  v
提取并归类
```

### 步骤3：结构化输出
```
提取的信息
  v
按字段组织
  v
生成JD摘要
```

## 解析示例

### 示例1：技术岗位

**原始JD**：
```

工作地点：北京市海淀区
薪资范围：25k-35k/月

岗位职责：
1. 负责公司核心业务系统的后端开发与维护
2. 参与需求分析、系统设计与技术方案制定
3. 优化系统性能，保障系统稳定性
4. 指导初级开发工程师，参与代码评审

任职要求：
1. 本科及以上学历，计算机相关专业
2. 3-5年Java开发经验，熟悉Spring、SpringBoot、MyBatis
3. 熟练使用MySQL、Redis，有数据库优化经验
4. 良好的沟通能力和团队协作精神

优先条件：
- 有大型互联网公司经验者优先
```

```
【任职要求】

经验要求：3-5年Java开发经验
技能要求：Java、Spring、SpringBoot、MyBatis、MySQL、Redis
软性要求：良好的沟通能力、团队协作精神

- 大型互联网公司经验
```

## Prompt模板使用

### 标准JD解析Prompt

完整的Prompt模板见 [assets/prompt-templates.md](../assets/prompt-templates.md) 的"JD解析Prompt模板"部分。

**模板1：标准JD解析**
```markdown
你是一位资深猎头顾问。请分析以下职位描述，按照指定格式输出结构化信息。

【职位描述】
{粘贴JD原文}

【输出格式】
1. 核心职责（5-8条，简洁明了）
2. 硬性条件（必须满足项，如学历、年限、证书、行业背景）
3. 软性素质（期望的性格或能力）
4. 技能矩阵：
   - 必备技能（列出5-10项核心技能，每项标注权重1-5）
   - 加分技能（列出2-5项，每项标注加分权重1-3）
5. 人才画像（目标公司类型、典型岗位名称、建议年龄范围、期望薪资范围）
```

### 使用方法
1. 从主流招聘平台平台复制JD文本
2. 将JD文本粘贴到Prompt中的`{粘贴JD原文}`位置
3. 在AI工具（如ChatGPT、Claude等）中运行Prompt
4. 获取结构化输出
5. 人工审核和微调结果

### 技能权重说明

**权重定义**：
- **权重5**：核心必备技能，缺失则不匹配
- **权重4**：重要技能，缺失影响较大
- **权重3**：一般技能，缺失可通过学习补充
- **权重2**：辅助技能，有则加分
- **权重1**：可选技能，影响较小

**权重分配原则**：
- 根据职位描述中的表述强度（"必须"、"熟悉"、"了解"）
- 根据技能在岗位中的重要性
- 参考市场稀缺性

### 技能权重Prompt模板

```markdown
你是一位技术专家。请为以下职位分析技能权重：

【职位】{职位名称}
【核心技能】{列出核心技能}

请按以下格式输出：
技能名称 | 重要性(1-5) | 稀缺性(1-5) | 权重建议

说明：
- 重要性：对岗位成功的关键程度
- 稀缺性：市场人才获取难度
- 权重建议：在匹配评分中的权重占比
```

## 效率数据

### 时间对比

| 操作 | 传统方法 | AI辅助 | 提升率 |
|------|---------|--------|--------|
| JD分析 | 15-20分钟 | 2-3分钟 | 80%+ |

### 质量提升

**一致性**：
- 传统方法：不同顾问理解不同，输出格式不一致
- AI辅助：统一的结构化输出，消除理解偏差

**完整性**：
- 传统方法：容易遗漏关键信息
- AI辅助：系统化提取，覆盖全面

**准确性**：
- 传统方法：受顾问经验和主观判断影响
- AI辅助：基于语义理解，客观分析

## 注意事项

### 信息缺失处理
- **规则**：对于关键信息缺失，标注"未明确"
- **示例**：薪资范围未标注 -> 【薪资范围】：未明确
- **后续**：提示用户补充关键信息

### 模糊信息处理
- **规则**：对于模糊信息，提取可识别部分并标注模糊点
- **示例**："薪资优厚" -> 【薪资范围】：优厚（具体未明确）

### 优先级判断
- **核心职责**：职责列表中的前2-3项
- **必需技能**：明确标注"必须"、"要求"的技能
- **优先条件**：标注"优先"、"加分"的条件

### 格式标准化
- 统一使用Markdown格式
- 字段名使用【】标注
- 列表项使用"-"符号

### AI输出审核要点
- 检查核心职责是否准确
- 验证技能权重是否合理
- 确认人才画像是否符合实际
- 补充AI遗漏的关键信息
