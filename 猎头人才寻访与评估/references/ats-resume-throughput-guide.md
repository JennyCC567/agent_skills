# ATS简历通过率分析

## 概述

ATS简历通过率分析用于追踪和分析候选人从简历投放到各阶段的转化情况，帮助猎头优化招聘流程效率。本功能仅用于本地数据记录和分析，不涉及平台API对接。

## 核心指标

### 简历通过率计算

| 指标 | 计算公式 | 优化目标 |
|------|----------|----------|
| 简历初筛通过率 | 初筛通过数 / 简历投递数 | 提升简历质量 |
| 电话沟通率 | 发起沟通数 / 初筛通过数 | 提升候选人意向 |
| 推荐成功率 | 推荐人数 / 电话沟通数 | 提升匹配精准度 |
| Offer接收率 | 接Offer人数 / 发Offer数 | 优化谈判策略 |
| 入职率 | 实际入职数 / 接Offer数 | 提升入职保障 |

### ATS通过率看板指标

```
[指标说明]
- 简历投递数：通过人工录入或本地表格导入
- 各阶段转化数：通过人工录入本地记录

```

### 异常诊断

| 异常现象 | 可能原因 | 改进建议 |
|----------|----------|----------|
| 初筛通过率低 | 简历筛选标准不清晰 | 明确硬性指标 |
| 电话沟通率低 | 候选人意向不足 | 优化开场话术 |
| 推荐成功率高但Offer率低 | 面试辅导不足 | 加强面试培训 |
| Offer率高但入职率低 | 谈薪或入职跟进不足 | 优化入职流程 |
