## 概述

### 什么是候选人库管理

候选人库管理是指对候选人数据进行系统化收集、存储、维护和应用的完整流程。良好的候选人库管理可以帮助猎头顾问：

- 快速查找和匹配合适的候选人
- 追踪候选人的职业发展动态
- 复用历史候选人资源，提升寻访效率
- 建立长期人才关系，实现持续价值

### 候选人库的价值

| 价值维度 | 具体体现 |
|----------|----------|
| 效率提升 | 减少重复寻访，快速找到候选人 |
| 成本节约 | 复用历史资源，降低寻访成本 |
| 关系维护 | 建立长期联系，提升候选人粘性 |
| 数据资产 | 积累人才数据，形成企业无形资产 |

### 导入流程

```
Step 1: 数据准备
   - 收集候选人简历或信息表
   - 按模板整理数据格式
   
Step 2: 数据清洗
   - 检查必填字段完整性
   - 手机号、邮箱脱敏处理
   - 去除重复数据
   
Step 3: 数据导入
   - 选择导入格式
   - 上传文件或粘贴数据
   - 系统自动解析和校验
   
Step 4: 结果确认
   - 查看导入结果报告
   - 处理导入失败记录
   - 补充缺失信息
```

### 导入注意事项

[必填] 所有导入的候选人数据必须完成脱敏处理
[必填] 手机号、邮箱、姓名等敏感信息必须脱敏
[必填] 确保已获得候选人同意存储其信息
[建议] 优先使用标准化模板导入
[建议] 导入后及时补充候选人标签和沟通记录

## 本地人才库建设

### 人才库架构

```
本地人才库
├── 候选人主库
│   ├── 基础信息表
│   ├── 沟通记录表
│   ├── 推荐记录表
│   └── 评分历史表
├── 行业人才库
│   ├── 技术类人才
│   ├── 产品类人才
│   ├── 运营类人才
│   └── 管理类人才
├── 客户人才库
│   ├── 客户A候选人
│   ├── 客户B候选人
│   └── 客户C候选人
└── 被动候选人库
    ├── 高意向候选人
    ├── 中意向候选人
    └── 低意向候选人
```

### 候选人信息完整度评估

**完整度评分标准**：

| 完整度等级 | 要求 | 说明 |
|------------|------|------|
| S级 | 8项以上 | 信息完整，可直接推荐 |
| A级 | 6-7项 | 信息较完整，需补充少量信息 |
| B级 | 4-5项 | 信息基本完整，需重点补充 |
| C级 | 2-3项 | 信息不完整，需大量补充 |
| D级 | 0-1项 | 信息严重缺失 |

**信息完整度提升建议**：

| 当前等级 | 提升建议 | 预期效果 |
|----------|----------|----------|
| C级 -> B级 | 补充工作经历、项目经验 | 可用于初步匹配 |
| B级 -> A级 | 补充薪资期望、学历信息 | 可用于精准推荐 |
| A级 -> S级 | 补充沟通记录、评分结果 | 可用于直接推荐 |

### 人才库维护周期

| 维护类型 | 周期 | 内容 | 负责人 |
|----------|------|------|--------|
| 基础更新 | 实时 | 新候选人入库 | 猎头顾问 |
| 定期跟进 | 每周 | 沟通状态更新 | 猎头顾问 |
| 深度维护 | 每月 | 完整度评估、标签更新 | 团队负责人 |
| 全面盘点 | 每季度 | 数据质量审查、清理 | 管理员 |

## 候选人数据管理规范

### 候选人标签体系

**标签分类标准**：

| 标签类型 | 标签定义 | 示例 |
|----------|----------|------|
| 渠道来源 | 候选人获取渠道 | Boss直聘,猎聘,内推 |
| 意向程度 | 求职意愿强度 | 主动,[高意向],[中意向],[低意向] |
| 质量评级 | 候选人质量等级 | [S级],[A级],[B级],[C级] |
| 跟进状态 | 当前跟进状态 | [待沟通],[已沟通],[待推荐] |
| 特殊标记 | 特殊属性标记 | [985],[211],[海归] |

**标签使用规范**：

[必填] 每个候选人至少有一个意向程度标签
[必填] 每个候选人至少有一个质量评级标签
[建议] 每个候选人最多5个标签
[建议] 标签命名统一使用中文

### 候选人生命周期管理

```
候选人生命周期：
   [入库] -> [沟通] -> [评估] -> [推荐] -> [入职] -> [入职后]
      |        |         |         |         |          |
      v        v         v         v         v          v
   新候选人 意向确认  能力评估  匹配推荐  成功入职  关系维护
      |        |         |         |         |          |
      +--------+---------+---------+---------+----------+
                            |
                            v
                      [已淘汰/待激活]
```

**各阶段管理要点**：

| 阶段 | 时限要求 | 管理要点 |
|------|----------|----------|
| 入库 | 实时 | 快速录入、脱敏处理、标签标记 |
| 沟通 | 3天内 | 确认意向、补充信息、记录要点 |
| 评估 | 1周内 | 完成评分、确定意向度 |
| 推荐 | 2周内 | 整理推荐报告、提交客户 |
| 入职 | 按Offer约定 | 跟进离职、入职准备 |
| 入职后 | 90天 | 定期回访、关系维护 |

### 人才库复用策略

**复用场景分析**：

| 场景 | 复用价值 | 操作建议 |
|------|----------|----------|
| 新职位发布 | 高 | 优先在人才库中搜索匹配候选人 |
| 紧急职位 | 高 | 直接从人才库筛选，快速推荐 |
| 定向寻访 | 中 | 从人才库选择候选人进行定向沟通 |
| 常规寻访 | 低 | 人才库作为补充渠道 |

**复用率提升方法**：

| 方法 | 说明 | 预期效果 |
|------|------|----------|
| 定期盘点 | 每季度盘点人才库质量 | 提升数据可用性 |
| 标签完善 | 持续完善候选人标签 | 提升搜索效率 |
| 状态更新 | 定期更新候选人状态 | 减少无效沟通 |
| 优先级排序 | 按复用价值排序候选人 | 提升复用效率 |

## 数据安全与合规

### 数据安全要求

[必填] 所有候选人数据必须脱敏存储
[必填] 敏感字段（手机号、邮箱）必须加密
[必填] 候选人数据不得未经授权外泄
[必填] 导出数据时需记录操作日志
[必填] 定期进行数据备份

### 合规要求

[必填] 仅存储已获得候选人授权的信息
[必填] 遵守个人信息保护法相关规定
[必填] 候选人数据不得用于非授权用途
[必填] 候选人有权要求删除其个人信息

### 数据备份规范

| 备份类型 | 周期 | 保存周期 | 备份位置 |
|----------|------|----------|----------|
| 全量备份 | 每周 | 3个月 | 本地 + 云端 |
| 增量备份 | 每日 | 1个月 | 本地 |
| 实时备份 | 实时 | 持续 | 云端 |

## 快速入门指南

### 新手三步走

**第一步：导入候选人数据**
1. 下载标准导入模板
2. 按模板整理候选人信息
3. 进行数据脱敏处理
4. 上传并确认导入结果

**第二步：完善候选人标签**
1. 批量添加渠道来源标签
2. 批量添加意向程度标签
3. 批量添加质量评级标签

**第三步：建立定期维护习惯**
1. 每日更新沟通记录
2. 每周更新候选人状态
3. 每月进行数据盘点

| 问题 | 解答 |
|------|------|
| 如何批量导入候选人？ | 使用Excel模板批量导入 |

| 如何更新候选人信息？ | 进入候选人详情页编辑 |
| 如何导出候选人名单？ | 使用导出功能选择格式和字段 |
