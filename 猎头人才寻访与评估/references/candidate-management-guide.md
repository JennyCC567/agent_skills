## 第一部分：候选人识别与沟通

### 一、简历快速识别框架（3分钟读懂简历）

#### 必看的7个细节

| 细节 | 好信号 | 风险信号 |
|------|--------|----------|
| 时间线 | 无缝衔接 | 超过3个月空白期 |
| 晋升轨迹 | 同公司级别清晰提升 | 10年8跳全是平级 |
| 经历长度 | 每段3-5年以上 | 越来越短 |
| 动词选择 | 主导、负责 | 参与、配合 |
| 数据化 | 用数字说话 | 用形容词敷衍 |
| 行业聚焦 | 同行业深耕 | 频繁跨行 |
| 格式细节 | 统一、精准 | 错别字、格式乱 |

#### 快速判断框架

**稳定性判断**（看跳槽频率）：
- 职场前5年：2-3年一跳可接受
- 5-10年：3-5年一跳较好
- 10年以上：稳定性是核心资产

**潜力判断**（看复杂度升级）：
- 每次换工作，复杂度有没有提升？
- 带的人是不是越来越多？
- 解决的问题是不是越来越难？

**风险判断**（看硬伤）：
- 时间线刚好卡在项目结束
- 刻意模糊离职时间
- 满屏"全面负责"但没有团队

### 二、破冰话术库

#### 薪资类问题应对

**Q：你们能给多少？**
```
"薪资范围是XX-XX，主要看您的综合情况定薪。如果您有具体期望，我可以先帮您沟通看看空间。"
```

**Q：加班多吗？**
```
"项目冲刺期会有，但平时基本正常下班。入职前3个月是熟悉期，会相对轻松。"
```

**Q：上一个人为什么走？**
```
"是内部晋升空出来的岗位，这个机会是因为业务扩张新增的，不存在前任留下的坑。"
```

#### 质疑猎头价值类问题

**Q：我自己也能投，为什么用你？**
```
"您说得对，但我的价值是：
①提前知道面试官风格
②帮您谈薪资，有些空间候选人自己拿不到
③全程陪跑，有问题随时协调"
```

**Q：你能保证我入职吗？**
```
"没人能100%保证，但我承诺尽我所能帮您拿到offer，入职后适应期我也会持续跟进。"
```

#### 犹豫不决类问题

**Q：我考虑一下...**
```
"完全理解，这是重要决定。您主要在考虑哪些方面？我帮您分析分析，信息越充分决定越容易做。"
```

**Q：我再看看其他机会**
```
"正常，我们在同时推进几个候选人，如果您流程走完但没反馈，企业可能先考虑其他人了。您的顾虑是什么？"
```

## 第二部分：候选人心理管理

### 一、SCARF模型应用

候选人接了offer又反悔，往往是这5个心理需求没被满足：

| 维度 | 含义 | 候选人担心 | 猎头应对 |
|------|------|-----------|----------|
| **地位感** | 被尊重 | 我是不是备选？ | "面试官特意说希望尽快发offer，您是第一选择" |
| **确定性** | 了解情况 | 这公司靠谱吗？ | "可以安排非正式拜访，跟未来领导先聊聊" |
| **自主性** | 自己选择 | 被催着做决定 | "这个决定完全由您，我们没有时间压力" |
| **归属感** | 被接纳 | 能融入吗？ | "团队氛围open，新人来了大家都会主动邀请" |
| **公平感** | 合理公正 | 我是不是亏了？ | "薪资在同级别里是偏高的，我可以帮您核实" |

#### Offer发放后的维护清单

- **当天**：发企业对他的正面评价，确认情绪状态
- **等待期**：每天轻量关怀，分享团队动态
- **犹豫时**：用SCARF排查卡点，对症下药
- **提离职**：提供话术参考，关注情绪变化
- **入职前**：每周联系，提前介绍未来同事
- **入职后**：主动关心适应，协助解决问题

### 二、薪资谈判艺术

#### 谈判前必须摸清的5个信息

1. **候选人真实底线**：理想价/合理价/底线价
2. **跳槽真正原因**：为了钱/为了发展/为了逃离
3. **企业薪资结构**：基本工资/绩效/股权/福利
4. **企业审批权限**：能不能特批？
5. **竞争offer情况**：有没有其他家在推进？

#### 4大难题破解

**难题1：候选人期望远超预算**
```
先了解他为什么值这个价，帮企业算"替代成本"。
谈打包方案：base低一点，期权补一点。
```

**难题2：企业压价候选人不满**
```
"企业预算原本比这低，我的介入帮您多争取了XX，您怎么看？"
把注意力从"绝对值"转移到"增量"。
```

**难题3：候选人想等年终奖**
```
"这个机会窗口不会太长，您等3个月岗位可能就关了。帮您算算机会成本。"
```

**难题4：用A公司offer压B公司**
```
先搞清楚真实意图：是A更吸引，还是只想让B出到这个价？
```

#### 薪资翻倍怎么谈？

**先帮他算清楚"真实涨幅"**：
- 有的"翻倍"其实是平移（算上股权、福利、灰色收入）
- 有的"30%涨幅"反而更划算

**应对策略**：
- 如果真值翻倍：帮候选人包装价值，说服用人部门
- 如果企业急需：谈打包方案，降低即时成本压力
- 如果漫天要价：诚实沟通，帮他校准市场预期

## 第三部分：入职护航全流程

### 一、离职期防反水

#### 候选人提离职的信号识别

当候选人出现以下信号时，需要高度警惕：
- Offer接受后，突然开始"考虑"或"再想想"
- 询问原公司CounterOffer的可能性
- 对入职时间一拖再拖，理由模糊
- 开始打听其他公司同岗位的机会
- 入职前突然"失联"或回复变慢

#### CounterOffer应对话术

**场景：候选人告诉你"公司给我加了薪，我不想走了"**

```
候选人："老板给我加了30%，让我留下来。"

猎头："恭喜你！这说明你的价值被认可了。
但我想问你3个问题：

1. 【动机】这次加薪，是因为公司之前真的'亏待'了你，还是临时挽留的策略？
2. 【信任】提过离职后，老板对你的信任会不受影响？你以后晋升会不会被'记一笔'？
3. 【未来】如果明年这时候，公司又有人要离职，你猜老板会先加薪挽留，还是直接招新人替代？

新公司给你的不只是月薪，还有新的平台、新的机会、新的可能性。
这些，是原公司加30%买不来的。
你当初为什么开始看机会？那个初心，现在变了吗？"
```

#### 候选人离职工作交接清单

| 交接项目 | 完成标准 | 猎头确认 |
|----------|----------|----------|
| 工作文档整理 | 所有文档已归档，有索引 | [选填] 已确认 |
| 项目进展同步 | 与接任者完成至少2轮交接 | [选填] 已确认 |
| 离职日期确定 | 获得书面离职证明 | [选填] 已确认 |
| 竞业协议审查 | 确认无违规风险 | [选填] 已确认 |
| 背调信息准备 | 准备好前任雇主联系方式 | [选填] 已确认 |

#### 入职前风险预警清单

**红色预警**：
- 候选人连续3天不回复消息
- 突然要求延期入职超过2周
- 原公司发起劳动仲裁

**黄色预警**：
- 候选人开始打听其他机会
- 家属表示强烈反对
- 对薪资福利提出新疑问

**需要沟通**：
- 候选人询问新公司负面消息
- 对直属领导有顾虑
- 担心无法胜任工作

### 二、入职初期强融入

#### 入职第一周：关键陪伴

入职第一天，比候选人还紧张的是谁？——是你，猎头顾问。

**必须在入职第一天完成的事项**：

| 时间 | 动作 | 目的 |
|------|------|------|
| 上午9点 | 发送入职祝福微信，附上候选人新工位的实景照片 | 让候选人感受被关注 |
| 上午10点 | 电话跟进，确认报到流程是否顺利 | 有没有遇到困难 |
| 中午12点 | 询问是否适应新环境的第一顿午餐 | 有没有找到饭搭子 |
| 下午3点 | 联系HR，询问候选人报到情况 | 了解是否有需要协调的问题 |
| 下午5点 | 发送第一天结束关怀 | "第一天感觉怎么样？有什么想聊的吗？" |

#### 入职第一个月：建立信任

第一个月是候选人最需要"导师"的时期。作为猎头，你应该成为候选人的"外部顾问"。

| 时间节点 | 核心任务 | 沟通方式 |
|----------|----------|----------|
| 第1周 | 高频关怀，适应期陪伴 | 微信+电话，每天1次 |
| 第2周 | 了解融入情况，提供支持 | 微信3次/周 |
| 第3周 | 关注工作挑战，提供建议 | 微信或面谈1次/周 |
| 第4周 | 月度复盘，关系强化 | 面谈或电话1次 |

#### 预期管理：避免"期望落差"

很多候选人入职后"后悔"，根源在于预期错位。作为猎头，你需要在入职前就帮助候选人建立合理预期：

- **薪资结构**：明确基本工资、绩效、奖金的构成，避免"到手工资"预期偏差
- **岗位职责**：确保候选人了解真实的岗位职责，不是"JD上的理想"，而是"实际的工作"
- **团队氛围**：客观介绍团队情况，既不美化也不丑化
- **晋升路径**：告知真实的晋升周期和条件，避免"一年升三级"的幻觉
- **企业挑战**：坦诚告知公司面临的挑战，让候选人做好心理准备

### 三、保证期深绑定

#### 保证期的重要性

猎头行业的"保证期"（通常3-6个月），是检验交付质量的"试金石"。

候选人过了保证期，意味着：
- 猎头顾问的佣金可以正式结算
- 候选人在新公司站稳脚跟
- 猎头口碑得到正向积累

所以，保证期的"深绑定"，不仅是为了回款，更是为了建立长期关系。

#### 保证期价值复盘访谈

在候选人入职第30天、第60天、第90天，建议各进行一次"价值复盘访谈"：

| 时间 | 核心话题 | 访谈目标 |
|------|----------|----------|
| 30天 | 适应情况、遇到的挑战、对新公司的评价 | 发现问题，及时介入 |
| 60天 | 工作进展、与团队融合、个人成长 | 强化正向体验 |
| 90天 | 整体满意度、长期规划、新的需求 | 深化关系，挖掘新机会 |

#### 超越职位：终身关系经营

当你帮助一位候选人成功入职并稳定下来，你获得的不仅是一次佣金，更是一个终身的职业伙伴。

**候选人未来可能的路径**：
- 晋升到更高职位，带来新的招聘需求
- 换工作时第一时间想到你
- 向同事朋友推荐你
- 成为你个人的人脉网络中重要节点

所以，把每一次交付，当作建立终身关系的起点。

## 第四部分：完整时间轴

### 从Offer到入职后90天全流程

| 阶段 | 时间 | 核心动作 | 频次 |
|------|------|----------|------|
| 离职前 | Offer接受后 | 确认离职意向、提醒准备离职、预警风险 | 随时 |
| 离职中 | 最后工作日 | 保持沟通、确认离职顺利、发送祝福 | 每天 |
| 入职前 | 入职前1周 | 确认入职准备、解决最后障碍、再次关怀 | 2-3次 |
| 入职第1周 | Day1-Day5 | 高频陪伴、解决报到问题、建立信任 | 每天 |
| 入职第2-4周 | Week2-4 | 跟进适应情况、关注融入状态 | 3次/周 |
| 入职30天 | Month1 | 月度复盘访谈、解决问题、强化关系 | 1次 |
| 入职60天 | Month2 | 追踪工作表现、挖掘新需求 | 1次 |
| 入职90天 | Month3 | 保证期评估、总结交付、开启新合作 | 1次 |
| 入职后 | Ongoing | 终身关系经营、定期关怀 | 季度 |

## 核心心法总结

1. 简历是"精心包装"过的，再包装也藏不住痕迹——读懂他为什么这么写
2. 不要等候选人反悔了再补救——从接offer那一刻就开始维护
3. 薪资谈判的目标不是让任何一方满意——而是让交易发生
4. 入职后30天内，是候选人最脆弱、最容易"反水"的时期
5. 最好的风控是深度参与，最好的留存是创造价值
6. 把每一次交付，当作建立终身关系的起点
