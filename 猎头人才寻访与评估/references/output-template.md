## 文档输出格式要求

### 默认输出格式

**严格输出格式**：若用户未对文档输出格式提出明确要求，默认统一输出HTML版。

| 格式类型 | 功能说明 | 输出方式 |
|----------|----------|----------|
| **交互式HTML** | 在线查看 | 支持浏览器直接打开 |
| **HTML下载** | 本地保存 | 一键下载到本地 |
| **PDF在线查看** | 在线预览 | 浏览器PDF预览 |
| **PDF下载** | 本地保存 | 一键下载到本地 |

### 格式特点

| 特点 | 说明 |
|------|------|
| **交互性** | HTML版本支持交互式元素（折叠、展开、搜索等） |
| **格式稳定** | PDF版本确保格式跨平台一致性 |
| **便捷交付** | 支持一键下载，确保交付便捷 |
| **在线预览** | 支持浏览器直接查看，无需下载 |

### 实现要求

**HTML版本要求**：
```
1. 响应式布局，适配不同屏幕尺寸
2. 支持表格折叠/展开
3. 支持关键词搜索
4. 支持一键复制内容
5. 支持一键下载为HTML文件
```

**PDF版本要求**：
```
1. 格式与HTML版本保持一致
2. 支持浏览器PDF预览
3. 支持一键下载为PDF文件
4. 确保表格、列表等元素的PDF渲染效果
```

### 输出判断规则

```
用户明确要求输出格式？
  +-- 是 -> 按用户要求的格式输出
  |        （Markdown / Word / Excel / PDF 等）
  +-- 否 -> 默认输出HTML版
           （交互式HTML + PDF，支持在线查看+下载）
```

### 输出格式示例

```
文档交付清单：
1. report.html    - 交互式HTML版本（在线查看）
2. report.pdf     - PDF版本（在线查看+下载）
3. report.md      - Markdown源文件（可选）

用户操作：
- 在线查看 -> 直接打开HTML文件
- 下载HTML -> 点击"下载HTML"按钮
- 下载PDF  -> 点击"下载PDF"按钮
```

## 概览
匹配报告是候选人匹配工作流的最终输出，用于呈现JD需求、候选人匹配详情和推荐建议。

**输出格式**：
- 默认：交互式HTML（在线查看+下载）+ PDF（在线查看+下载）
- 可选：Markdown源文件

**使用场景**：招聘决策参考

## 报告结构

### 标准结构
```
1. 报告标题
2. JD需求摘要
3. 候选人匹配总览
4. 候选人详细匹配信息（Top 3-5）
5. 推荐建议
6. 风险提示
7. 下一步行动建议
```

### 各部分内容

#### 1. 报告标题
- 包含职位名称、生成时间

#### 2. JD需求摘要
- 职位基本信息
- 核心要求概述

#### 3. 候选人匹配总览
- 候选人列表
- 匹配度排序
- 推荐级别

#### 4. 候选人详细匹配信息
- 每位候选人的详细评分
- 匹配点与差距点
- 推荐理由

#### 5. 推荐建议
- 首推候选人
- 备选候选人
- 不推荐候选人

#### 6. 风险提示
- 候选人潜在风险
- 市场竞争风险

#### 7. 下一步行动建议
- 面试安排建议
- 薪资谈判建议
- 其他注意事项

## 字段说明

### JD需求摘要字段

| 字段名 | 说明 | 是否必需 | 示例 |
|--------|------|---------|------|
| 职位名称 | 招聘岗位名称 | 必需 | 高级Java开发工程师 |
| 工作地点 | 职位所在地点 | 必需 | 北京市海淀区 |
| 薪资范围 | 月薪或年薪范围 | 必需 | 25k-35k/月 |
| 核心要求 | 学历、经验、技能概述 | 必需 | 本科，3-5年，Java/Spring/MySQL |
| 优先条件 | 加分项 | 可选 | 大型互联网经验、分布式架构 |

### 候选人匹配字段

| 字段名 | 说明 | 是否必需 | 示例 |
|--------|------|---------|------|
| 候选人姓名 | 候选人姓名或代号 | 必需 | 张三 |
| 综合匹配度 | 0-100分 | 必需 | 85分 |
| 推荐级别 | 高/中/低 | 必需 | 高 |
| 硬性指标得分 | 学历/经验/技能评分 | 必需 | 52.5/60分 |
| 软性指标得分 | 行业/能力/稳定性评分 | 必需 | 22.5/30分 |
| 优先条件得分 | 加分项评分 | 必需 | 10/10分 |
| 关键优势 | 主要匹配点 | 必需 | 核心技能扎实 |
| 主要差距 | 主要不匹配点 | 必需 | 缺少Redis经验 |
| 推荐理由 | 推荐或不推荐的理由 | 必需 | 建议优先面试 |

### 推荐级别定义

| 级别 | 匹配度范围 | 说明 |
|------|-----------|------|
| 高 | 80-100分 | 强烈推荐，优先安排面试 |
| 中 | 60-79分 | 可以考虑，作为备选 |
| 低 | <60分 | 不推荐，继续寻找 |
