## 薪资Marketplace概述

### 功能定义

薪资Marketplace是聚合脱敏后的市场薪资数据，为薪酬谈判提供参考依据。

### 核心价值

| 价值点 | 说明 |
|--------|------|
| 市场参考 | 提供各岗位的市场薪资水平 |
| 薪酬建议 | 为Offer定价提供依据 |
| 谈判支持 | 为薪酬谈判提供数据支撑 |
| 公平性保障 | 减少因信息不对称导致的薪酬不公平 |

### 数据使用场景

| 场景 | 数据应用 |
|------|----------|
| 候选人评估 | 结合候选人期望和市场水平评估合理性 |
| Offer定价 | 参考市场水平确定Offer薪资范围 |
| 薪酬谈判 | 用市场数据支撑谈判立场 |
| 客户建议 | 为客户提供市场薪酬建议 |

## 数据来源与分类

### 官方权威数据源

| 来源类型 | 具体来源 | 数据特点 |
|----------|----------|----------|
| 政府官方 | 人社部薪资指导线 | 权威、滞后 |
| 统计局 | 城镇职工平均工资 | 宏观、参考性 |
| 行业协会 | 各行业协会薪酬报告 | 细分、时效性强 |
| 招聘平台 | 各大平台薪资数据 | 详细、更新快 |

### 第三方数据源

| 平台 | 数据特点 |
|------|----------|
| 智联招聘 | 简历期望薪资分布 |
| 前程无忧 | 职位薪资区间统计 |
| 猎聘 | 中高端薪资数据 |
| 脉脉 | 职场薪资讨论数据 |
| Glassdoor | 国际薪资数据参考 |

### 数据分类

| 分类维度 | 类别 |
|----------|------|
| 按职级 | 专员/主管/经理/总监/VP |
| 按行业 | 互联网/金融/医疗/制造等 |
| 按职能 | 技术/销售/运营/职能等 |
| 按城市 | 一线/新一线/二线/三线 |
| 按企业性质 | 外资/合资/民营/国企/上市公司 |

## 薪资数据聚合

### 数据聚合流程

```
Step 1: 数据收集 → 从各渠道收集薪资数据
   ↓
Step 2: 数据清洗 → 剔除异常值、标准化格式
   ↓
Step 3: 数据脱敏 → 聚合处理，不保留个人信息
   ↓
Step 4: 数据分析 → 计算分位数、平均值等指标
   ↓
Step 5: 数据输出 → 生成可查询的薪资报告
```

### 脱敏处理规则

| 数据项 | 脱敏要求 |
|--------|----------|
| 个人信息 | 完全匿名化处理 |
| 单个薪资数据 | 不直接展示，保护隐私 |
| 聚合数据 | 至少3个样本才展示 |
| 异常值 | 剔除明显不合理的数据 |

### 薪资分位数

| 分位数 | 说明 | 应用场景 |
|--------|------|----------|
| P25 | 25%分位，市场较低水平 | 预算紧张时的参考 |
| P50 | 50%分位，市场中位水平 | 常规招聘的参考 |
| P75 | 75%分位，市场较高水平 | 高端人才招聘参考 |
| P90 | 90%分位，市场顶尖水平 | 稀缺人才招聘参考 |

## 薪酬谈判应用

### 薪资建议生成流程

```
输入候选人信息
    ↓
查询市场薪资数据
    ↓
结合候选人期望和匹配度
    ↓
生成薪资建议区间
    ↓
提供谈判策略
```

### 薪资建议Prompt模板

```
【薪酬建议生成】

请根据以下信息，生成薪资建议：

【候选人信息】
- 当前薪资：[X]K
- 期望薪资：[X]K
- 工作年限：[X]年
- 学历：[学历]
- 核心技术：[列表]
- 匹配度评分：[X]分

【职位信息】
- 职位级别：[级别]
- 城市：[城市]
- 行业：[行业]
- 企业性质：[性质]

【市场数据】
- 职位中位薪资：[X]K
- P25薪资：[X]K
- P75薪资：[X]K

【建议要求】
1. 综合匹配度和市场数据，给出建议薪资区间
2. 说明建议的依据
3. 提供薪酬结构建议（固薪/奖金/股权等）
4. 给出薪酬谈判策略

输出格式：
- 建议薪资区间：[X]K - [X]K
- 建议依据：[列表]
- 薪酬结构建议：[列表]
- 谈判策略：[列表]
```

### 薪酬谈判话术

| 场景 | 话术建议 |
|------|----------|
| 候选人期望高于市场 | "根据市场数据，该职位的市场薪资区间在[X]K-[X]K，我们已经提供了具有竞争力的薪酬" |
| 候选人坚持高期望 | "我们可以提供[X]K的固定薪资，加上[X]%的绩效奖金，总包可达[X]K" |
| 需要争取候选人 | "考虑到您的稀缺技能，我们可以提供签约奖金[X]K作为补偿" |

## 合规与隐私保护

### 数据合规要求

| 要求 | 说明 |
|------|------|
| 数据来源合法 | 仅使用公开的、授权的数据 |
| 聚合脱敏 | 不保留可识别个人的信息 |
| 样本量要求 | 至少3个样本才展示聚合数据 |
| 更新透明 | 标注数据更新时间 |

### 隐私保护措施

| 措施 | 说明 |
|------|------|
| 数据匿名化 | 所有原始数据匿名处理 |
| 访问控制 | 仅授权人员可访问详细数据 |
| 审计日志 | 记录所有数据访问操作 |
| 数据加密 | 数据传输和存储加密 |

### 合规检查清单

- [ ] 数据来源已验证合法
- [ ] 聚合数据样本量>=3
- [ ] 无可识别的个人信息
- [ ] 数据更新及时（不超过6个月）
- [ ] 数据使用已获授权
- [ ] 薪资建议仅作为参考，非承诺

### 免责声明模板

```
【数据说明】
本薪资数据仅供参考，实际薪酬由多种因素决定，包括但不限于：
- 候选人个人能力和经验
- 候选人当前薪资水平
- 候选人动机和谈判能力
- 企业预算和薪酬体系
- 市场供需关系

数据来源：[来源列表]
数据更新时间：[填入真实系统时间]
免责声明：本数据不构成任何薪酬承诺，具体薪资以实际Offer为准。
```

## 薪资Marketplace应用示例

### 示例：技术候选人薪资建议

**候选人信息**
- 职位：高级Java工程师
- 城市：上海
- 工作年限：5年
- 当前薪资：35K
- 期望薪资：50K
- 匹配度评分：82分

**市场数据**
- 中位薪资：40K
- P25：35K
- P75：48K

**薪资建议**
- 建议区间：40K-48K
- 固薪建议：42K
- 绩效奖金：8K-12K
- 总包建议：50K-54K

**谈判策略**
- 强调平台发展机会
- 提供股权激励补充
- 提供签约奖金弥补差距
