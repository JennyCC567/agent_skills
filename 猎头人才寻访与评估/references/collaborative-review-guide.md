## 概述

### 什么是协作评审

协作评审是指将候选人评估报告或人才资料生成为可分享的链接，供团队成员或客户在线查看、评论和评价的功能。

### 协作评审的价值

| 价值维度 | 具体体现 |
|----------|----------|
| 决策效率 | 多方同时查看，统一意见 |
| 信息透明 | 团队成员实时了解候选人情况 |
| 客户体验 | 客户可在线查看报告并反馈 |
| 责任明确 | 评审记录可追溯 |

## 协作评审功能

### 支持的评审类型

| 评审类型 | 说明 | 适用场景 |
|----------|------|----------|
| 单候选人评审 | 单个候选人详细评估报告 | 精准推荐、深度评估 |
| 多候选人对比 | 多个候选人横向对比报告 | 批量筛选、决策支持 |
| JD评审 | 职位描述评审 | JD优化、需求确认 |
| 候选人库评审 | 批量候选人列表评审 | 人才盘点、库内筛选 |

### 评审内容

| 内容模块 | 说明 |
|----------|------|
| 候选人概览 | 基本信息、脱敏处理 |
| 评分详情 | 各维度评分、雷达图 |
| 优劣势分析 | 核心优势、潜在风险 |
| 推荐建议 | 推荐级别、跟进建议 |
| 历史记录 | 沟通记录、推荐历史 |
| 评论区域 | 团队成员或客户评论 |

## 链接生成与分享

### 链接生成规则

**链接格式**：
```
https://[域名]/review/[唯一标识]?token=[访问令牌]
```

**链接类型**：

| 链接类型 | 有效期 | 访问权限 |
|----------|--------|----------|
| 查看链接 | 7天/30天/永久 | 仅查看 |
| 评论链接 | 7天/30天 | 查看 + 评论 |
| 编辑链接 | 72小时 | 查看 + 评论 + 编辑 |

### 分享方式

#### 方式一：直接分享链接

**操作步骤**：
1. 生成评审链接
2. 复制链接
3. 通过微信/邮件/钉钉发送给评审人
4. 评审人点击链接直接查看

**适用场景**：
- 快速分享给单个评审人
- 内部团队评审

#### 方式二：邮件邀请评审

**邮件模板**：
```
邮件主题：候选人评审邀请 - [候选人姓名]

[评审人姓名]您好，

现有一份候选人评估报告需要您进行评审，详情如下：

候选人：[候选人姓名]
职位方向：[职位名称]
报告类型：[单候选人评审/多候选人对比]
评审截止：[填入真实系统时间+3天]

请点击以下链接查看报告并留下您的评审意见：
[评审链接]

如有任何问题，请联系[联系人姓名]。

祝好
[发送人姓名]
[填入真实系统时间]
```

#### 方式三：二维码分享

**适用场景**：
- 面对面展示
- 线下会议评审
- 客户现场演示

## 评审流程

### 标准评审流程

```
Step 1: 报告生成
   - 生成候选人评估报告
   - 确认报告内容完整性
   
Step 2: 评审链接生成
   - 选择评审类型
   - 设置访问权限
   - 设置有效期
   
Step 3: 评审邀请
   - 发送评审链接
   - 邀请评审人
   
Step 4: 在线评审
   - 评审人查看报告
   - 评审人填写意见
   - 评审人提交评分
   
Step 5: 评审汇总
   - 收集评审意见
   - 汇总评审评分
   - 生成评审报告
```

### 多级评审流程

```
[提交人] -> [直接上级] -> [业务负责人] -> [最终决策]
    |            |              |             |
    v            v              v             v
  提交报告     一级评审      二级评审      最终确认
                            (可选)
```

**各级评审要点**：

| 评审层级 | 评审重点 | 时效要求 |
|----------|----------|----------|
| 一级评审（直接上级） | 专业能力评估 | 24小时内 |
| 二级评审（业务负责人） | 综合匹配度 | 48小时内 |
| 最终决策（最终决策人） | 录用决策 | 按需求确定 |

## 最佳实践

### 评审效率提升

| 方法 | 说明 | 效果 |
|------|------|------|
| 标准化评审模板 | 统一评审表单 | 提升评审效率 |

| 批量评审 | 多人同时评审 | 缩短评审周期 |
| 自动提醒 | 评审超时提醒 | 减少评审延误 |

### 评审质量保证

| 方法 | 说明 | 效果 |
|------|------|------|
| 评审前briefing | 提前发送候选人资料 | 提升评审准备度 |
| 评审要点提示 | 提供评审关注点 | 提升评审针对性 |
| 评审意见模板 | 提供评语参考 | 提升评语质量 |
| 评审培训 | 定期培训评审标准 | 提升评审一致性 |

| 数据类型 | 沉淀内容 | 应用场景 |
|----------|----------|----------|
| 评审记录 | 评审意见、评分、决策 | 复盘分析 |
