## 概览

FABM模型是猎头行业推荐报告的黄金公式，能够高效呈现人才价值、匹配企业需求。

**核心价值**：
- 结构化呈现候选人价值
- 精准对标企业需求
- 提升推荐说服力
- 缩短决策周期

**应用场景**：
- 候选人推荐报告
- 面试评估报告
- 候选人对比分析

## FABM模型详解

### 模型结构

```
F (Features)      基础信息：精准锚定人才标签
    v
A (Achievements)  关键成就：用结果证明能力
    v
B (Benefits)      客户价值：聚焦企业实际需求
    v
M (Motivation)    跳槽动机：构建合理跳槽逻辑
```

### 核心原则

**原则1：真实性**
- 所有信息必须有据可查
- 避免夸大或虚构成就
- 数据可验证

**原则2：针对性**
- 对标JD核心需求
- 突出最匹配的优势
- 预设客户关注点

**原则3：说服力**
- 用数据说话
- 用案例证明
- 用逻辑串联

## Features-基础信息

### 三层信息结构

#### 第一层：硬性条件

**基本信息**：
```
- 姓名：xxx
- 年龄：xx岁
- 学历：本科/硕士/博士 + 院校 + 专业
- 工作年限：xx年
- 现居住地：xxx
- 期望薪资：xxx
```

**呈现要点**：
- 学历标注院校档次（如"985"、"双一流"）
- 工作年限强调相关性（如"8年互联网开发经验"）
- 期望薪资注明弹性（如"30-35k，可谈"）

#### 第二层：核心标签

**现职信息**：
```
- 现任职公司：xxx（注明公司地位，如"BAT"、"独角兽"）
- 现任职位：xxx
- 核心业务：xxx
- 团队规模：xx人（如相关）
```

**对标技巧**：
- 公司对标：与客户公司同级别或更高
- 职位对标：与目标岗位同级或略高
- 业务对标：与客户业务相关或相通

**示例**：
```
[否] 差的表述："王某现任某互联网公司技术经理"
[是] 好的表述："王某现任字节跳动抖音技术经理，负责推荐系统核心模块，
            带领15人团队，日活用户亿级"
```

#### 第三层：隐藏价值

**附加资源**：
```
- 行业人脉：关键人物关系、行业资源网络
- 技术专利：专利数量、技术影响力
- 竞品经验：对客户竞争对手的深度了解
- 特殊经历：关键项目、行业大事参与经历
```

**呈现方式**：
```
【隐藏价值】
- 曾深度参与阿里双十一大促系统架构设计，积累的高并发流量应对经验
  可直接复用至贵司618流量洪峰预案，缩短项目筹备周期
- 在支付领域拥有3项核心专利，可帮助团队规避技术专利风险
- 曾主导竞品XX公司的核心系统重构，深入了解其技术架构和业务逻辑
```

## Achievements-关键成就

### STAR法则结构化呈现

#### S (Situation) - 背景

**描述要点**：
- 业务规模：用户量、交易额、数据量
- 技术难点：性能瓶颈、复杂度、约束条件
- 团队情况：团队规模、角色定位

**示例**：
```
背景：负责某电商平台订单系统，日订单量500万+，
     大促期间峰值QPS达10万+，系统稳定性要求99.99%
```

#### T (Task) - 任务

**描述要点**：
- 核心职责：主要任务是什么
- 目标指标：量化的目标
- 时间约束：项目周期

**示例**：
```
任务：优化订单系统性能，将平均响应时间从500ms降至100ms以内，
     支撑大促期间流量洪峰，确保系统零故障
```

#### A (Action) - 行动

**描述要点**：
- 技术方案：采用了什么技术、架构
- 实施步骤：如何推进、关键决策
- 创新亮点：有什么独特之处

**示例**：
```
行动：
1. 引入Redis缓存集群，实现热点数据缓存
2. 优化数据库索引和分库分表策略
3. 引入消息队列削峰填谷
4. 实现灰度发布和全链路监控
```

#### R (Result) - 结果

**描述要点**：
- 量化成果：具体数据提升
- 业务价值：对业务的影响
- 个人贡献：候选人的关键作用

**示例**：
```
结果：
- 平均响应时间从500ms降至80ms，提升84%
- 系统QPS从5k提升至12k，支撑流量增长140%
- 大促期间零故障，系统稳定性100%
- 节省服务器成本40%，年节约成本约200万
```

### 成就描述避坑指南

#### 对比示例

**[否] 模糊表述**：
```
"熟悉Python编程语言"
```

**[是] 量化呈现**：
```
"通过Python实现点击率预估模型，将AUC指标提升15%，日均处理数据量10TB+"
```

**[否] 空泛评价**：
```
"具备较强的学习能力"
```

**[是] 实例证明**：
```
"曾在3个月内从0搭建ELK日志分析系统，为团队问题排查节省50%工时，
 全流程自动化监控覆盖率达95%"
```

**[否] 无效描述**：
```
"显著提升了系统性能"
```

**[是] 数据佐证**：
```
"将系统QPS从5k优化至12k，同时降低服务器成本40%"
```

## Benefits-客户价值

### 价值对标方法

#### 方法1：需求逐条匹配

**操作步骤**：
1. 提取JD核心需求（5-8条）
2. 逐条标注候选人的匹配点
3. 量化匹配程度（完全匹配/部分匹配/潜力匹配）

**输出格式**：
```markdown
【需求匹配度】

| JD需求 | 候选人匹配点 | 匹配程度 | 价值说明 |
|--------|-------------|---------|---------|
| 3-5年Java经验 | 5年Java开发经验 | [匹配] 完全匹配 | 可快速上手，无需培训 |
| 高并发经验 | 双十一大促系统架构 | [匹配] 完全匹配 | 可复用经验至618大促 |
| 分布式架构 | 微服务架构实践 | ^ 部分匹配 | 有基础，可快速深化 |
```

#### 方法2：行业数据佐证

**薪资对标**：
```
候选人期望薪资：30k-35k
市场同级别薪资：32k-38k
客户预算范围：28k-35k
结论：期望薪资合理，略低于市场水平，具备性价比优势
```

**职级对标**：
```
候选人现职级：P7（阿里职级）
目标岗位职级：高级工程师
对标：P7对应高级工程师或技术专家，职级匹配或略高
```

#### 方法3：预设推荐伏笔

**技巧**：
- 强调候选人的稀缺性
- 提及候选人的其他机会（制造紧迫感）
- 标注候选人的特殊价值

**示例**：
```
【推荐理由】
候选人当前已获得2家头部互联网公司的offer，但更倾向于贵司的业务方向
和技术挑战。建议尽快安排面试，候选人可在2周内做出决策。

【风险评估】
候选人的主要顾虑是职业发展空间，建议面试时重点介绍团队的成长路径
和技术规划，增强吸引力。
```

## Motivation-跳槽动机

### 动机构建原则

**原则1：真实性**
- 基于候选人真实想法
- 不编造或夸大动机
- 可在面试中验证

**原则2：合理性**
- 符合职业发展逻辑
- 与候选人现状匹配
- 无明显矛盾点

**原则3：吸引力**
- 强调客户公司的优势
- 对标候选人需求
- 展示未来发展空间

### 动机分类

#### 内在驱动

**职业发展**：
```
- 技术瓶颈突破：当前公司技术栈固化，寻求技术成长空间
- 业务成长空间：希望参与更大规模业务，承担更多责任
- 管理能力提升：寻求团队管理机会，锻炼领导力
- 行业转型：从传统行业转向互联网，或细分领域转换
```

**示例**：
```
【跳槽动机 - 内在驱动】
技术瓶颈：候选人当前所在公司业务相对成熟，技术架构稳定，
         缺乏新技术探索和突破的机会。希望能加入贵司，
         参与xxx项目的技术攻关，实现技术能力的跨越式提升。

职业发展：候选人希望在3年内成长为技术专家，
         贵司的技术团队和业务规模为其提供了理想的发展平台。
```

#### 外在吸引

**公司优势**：
```
- 业务前景：业务增长快、市场地位领先
- 技术氛围：技术团队强、技术氛围好
- 发展空间：晋升通道清晰、成长空间大
- 薪酬福利：薪资竞争力强、福利待遇好
- 品牌价值：公司品牌知名度高、职业背书强
```

**示例**：
```
【跳槽动机 - 外在吸引】
业务吸引力：贵司在xxx领域的市场地位和业务增长速度，
           为候选人提供了参与从0到1建设的机会，
           这正是其职业发展中渴望的经历。

技术吸引力：贵司的技术团队在行业内的技术深度和影响力，
           以及对前沿技术的探索精神，与候选人的技术追求高度契合。
```

### 动机呈现技巧

**技巧1：串联逻辑**
```
现状痛点 -> 客户优势 -> 价值匹配

示例：
候选人在现公司遇到技术瓶颈（现状痛点）
-> 贵司在xxx领域的技术领先地位（客户优势）
-> 为其提供了技术突破的理想平台（价值匹配）
```

**技巧2：数据支撑**
```
候选人当前薪资：25k
期望薪资：30-35k
贵司薪资范围：28-35k
结论：薪资期望在合理范围内，具备谈判空间
```

**技巧3：风险预判**
```
候选人顾虑：职业发展空间是否足够
应对建议：面试时重点介绍团队的晋升机制和技术规划
```

## 避坑指南

### 常见错误类型

#### 错误1：信息堆砌无重点

**[否] 错误示例**：
```
候选人王某某，男，32岁，本科毕业于某大学计算机专业，
工作8年，现任某公司技术经理，熟悉Java、Python、Go等多种语言，
做过电商系统、支付系统、推荐系统等多个项目...
```

**[是] 正确示例**：
```
候选人王某某，32岁，8年互联网技术经验，
现任字节跳动抖音技术经理，负责推荐系统核心模块。
核心优势：高并发架构设计经验丰富，曾主导双十一大促系统，
         将QPS从5k优化至12k，具备直接复用价值。
```

#### 错误2：成就描述无数据

**[否] 错误示例**：
```
候选人具备丰富的系统优化经验，显著提升了系统性能，
得到了团队和领导的高度认可。
```

**[是] 正确示例**：
```
候选人主导系统优化项目，将平均响应时间从500ms降至80ms，
提升84%；系统QPS从5k提升至12k，支撑流量增长140%；
大促期间零故障，系统稳定性100%；节省服务器成本40%，
年节约成本约200万。
```

#### 错误3：动机描述不充分

**[否] 错误示例**：
```
候选人希望寻找新的发展机会。
```

**[是] 正确示例**：
```
候选人跳槽动机明确且合理：
1. 技术瓶颈：当前公司业务成熟，技术架构稳定，
   缺乏新技术探索机会，希望加入贵司参与xxx项目技术攻关
2. 职业发展：希望在3年内成长为技术专家，
   贵司的技术团队和业务规模提供了理想平台
3. 业务吸引力：贵司在xxx领域的市场地位和增长速度，
   提供了参与从0到1建设的机会
```

#### 错误4：缺乏客户视角

**[否] 错误示例**：
```
候选人是一个非常优秀的技术人员，
技术能力很强，学习能力也很好。
```

**[是] 正确示例**：
```
候选人与贵司需求的匹配点：
1. 高并发经验完全匹配：曾主导双十一大促系统，
   可直接复用至贵司618流量洪峰预案
2. 技术栈高度一致：Java/Spring/MySQL/Redis，
   可快速上手，无需额外培训
3. 团队管理经验：带领15人团队，与贵司目标团队规模匹配
```

### 质量检查清单

**F层检查**：
- [ ] 基本信息完整准确
- [ ] 核心标签与JD对标
- [ ] 隐藏价值有具体收益

**A层检查**：
- [ ] 成就描述使用STAR结构
- [ ] 结果有量化数据
- [ ] 至少展示2-3个核心成就

**B层检查**：
- [ ] 需求逐条匹配
- [ ] 有市场对标数据
- [ ] 有推荐建议和风险提示

**M层检查**：
- [ ] 动机真实合理
- [ ] 内外在因素结合
- [ ] 有风险预判和应对

## 完整示例

### 示例：技术岗位推荐报告

```markdown
# FABM推荐报告

## 基本信息

**候选人**：李某（化名）
**年龄**：32岁
**学历**：硕士，浙江大学计算机专业（985院校）
**工作年限**：8年
**现任职**：字节跳动，抖音技术专家（P7）
**期望薪资**：40k-50k/月
**到岗时间**：1个月内

---

## F - Features（基础信息）

### 核心标签
- **公司背景**：字节跳动，抖音核心业务，日活用户亿级
- **职位对标**：技术专家（P7），与贵司高级架构师职级匹配
- **业务相关**：推荐系统核心模块负责人，与贵司推荐引擎业务高度契合

### 隐藏价值
- 曾深度参与抖音推荐系统从0到1的建设，积累了完整的推荐系统搭建经验，
  可直接复用至贵司推荐引擎项目，缩短研发周期3-6个月
- 在推荐算法领域拥有2项核心专利，可帮助团队规避技术专利风险
- 曾主导竞品XX公司推荐系统的技术调研，深入了解其算法策略和业务逻辑

---

## A - Achievements（关键成就）

### 成就1：抖音推荐系统优化

**背景**：负责抖音推荐系统核心模块，日活用户亿级，
         日均推荐请求千亿级，对推荐准确性和响应速度要求极高

**任务**：优化推荐算法和系统架构，将点击率提升10%以上，
```
