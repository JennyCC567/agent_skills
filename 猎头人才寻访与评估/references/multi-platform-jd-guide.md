## 各平台特点分析

### Boss直聘

**平台特点**：
- 职位描述通常较为简洁，强调与候选人直接沟通
- JD中常包含"急招"、"弹性工作"等时效性标签
- 薪资范围通常标注为"面议"或较小区间

**解析要点**：
- 重点提取「岗位亮点」和「福利标签」
- 注意识别「紧急程度」标记
- 关注「团队规模」和「领导风格」描述

**示例JD特征**：
```
岗位亮点：弹性工作、氛围轻松、成长空间大
薪资：15-25K
标签：#急招 #不加班 #扁平管理
```

---

### 智联招聘

**平台特点**：
- JD结构规范，包含职位描述、任职要求、发展前景
- 通常有完整的「岗位职责」和「任职资格」分块
- 企业介绍较为完整

**解析要点**：
- 严格按照「岗位职责」和「任职要求」分块提取
- 注意识别「优先条件」和「加分项」
- 关注「工作地址」和「上班时间」信息

**示例JD特征**：
```
【岗位职责】
1. 负责XXX产品设计
2. 参与XXX项目
...

【任职要求】
1. 本科及以上学历
2. 3年以上相关经验
...
```

---

### 前程无忧

**平台特点**：
- JD格式高度标准化
- 薪资通常标注具体范围（含税前税后说明）
- 福利标签较为齐全

**解析要点**：
- 标准化的「职位描述」和「职位要求」结构
- 注意提取「福利信息」和「上班时间」
- 关注「招聘人数」和「汇报对象」

**示例JD特征**：
```
职位名称：Java高级工程师
工作地点：上海-浦东新区
薪资范围：20-35K - 13薪
福利：五险一金、年底双薪、年度旅游
```

---

### 拉勾网

**平台特点**：
- 互联网垂直领域，JD专业度高
- 技术栈描述详细，包含具体框架版本
- 常标注「技术栈要求」和「项目经验」

**解析要点**：
- 重点提取「技术栈」和「工具要求」
- 注意识别「发展阶段」（A/B/C轮/上市公司）
- 关注「团队技术氛围」描述

**示例JD特征**：
```
技术栈要求：
- 精通Java/Spring生态
- 熟悉MySQL/Redis
- 有微服务架构经验
...
公司阶段：已上市（D轮）
```

---

### 猎聘

**平台特点**：
- 高端人才招聘平台
- JD要求明确具体，门槛较高
- 薪资范围较大，通常为年薪制

**解析要点**：
- 重点提取「硬性要求」和「软性要求」
- 注意识别「稀缺性」和「不可替代性」
- 关注「汇报层级」和「团队规模」

**示例JD特征**：
```
年薪范围：60-100W
硬性要求：985/211本科，10年以上经验
汇报对象：VP
团队规模：10-20人
```

---

### 主流招聘平台

**平台特点**：
- 专注猎头服务的撮合平台
- JD精准匹配，猎头定制
- 候选人画像要求明确

**解析要点**：
- 严格按照猎头推荐标准提取
- 注意识别「客户偏好」和「红线要求」
- 关注「面试流程」和「决策周期」

**示例JD特征**：
```
客户偏好：985/211背景，大厂背景优先
红线要求：不能有频繁跳槽记录
决策周期：2周内完成面试
```

---

### 鱼泡网

**平台特点**：
- 蓝领工人招聘平台
- JD简单直接，以工种和待遇为主
- 技能要求以实操经验为主

**解析要点**：
- 重点提取「工种」「工期」「待遇」
- 注意识别「工作环境」和「安全要求」
- 关注「包吃住」「日结」等福利信息

**示例JD特征**：
```
工种：木工/焊工/钢筋工
工期：长期项目
日薪：300-500元/天
福利：包吃住、日结
```

## JD解析标准化流程

### Step 1：平台识别与预处理

```
输入：原始JD文本（可能包含平台特有格式）
   v
平台识别：根据文本特征判断来源平台
   v
格式标准化：将平台特有格式转换为统一内部格式
   v
输出：标准化JD文本
```

### Step 2：核心信息提取

| 信息类别 | 提取内容 | 适用平台 |
|---------|---------|---------|
| **基础信息** | 职位名称、工作地点、薪资范围 | 全部平台 |
| **职责信息** | 岗位职责、核心任务、项目类型 | 全部平台 |
| **要求信息** | 学历、工作年限、技术栈、证书 | 全部平台 |
| **福利信息** | 五险一金、年终奖、股权、补贴 | 全部平台 |
| **附加信息** | 团队规模、汇报对象、发展空间 | 猎聘、主流招聘平台 |
| **蓝领信息** | 工种、工期、日薪、包吃住 | 鱼泡网 |

### Step 3：技能矩阵生成

```
标准化JD -> 技能关键词提取 -> 技能分类（硬技能/软技能）
   v                                        v
核心技能（必须） <- 权重分配 <- 加分技能（非必须）
```

### Step 4：画像标签生成

| 标签类型 | 示例标签 | 来源字段 |
|---------|---------|---------|
| 技术标签 | Java、Spring、MySQL | 技术栈字段 |
| 行业标签 | 互联网、金融、医疗 | 公司行业 |
| 职级标签 | 初级、中级、高级、专家 | 工作年限+职责 |
| 软技能 | 沟通、协作、领导力 | 任职要求 |
| 特殊标签 | 急招、985优先、有大厂经验 | 附加要求 |

### Step 5：输出格式化

```
提取的信息 -> 结构化JSON -> 统一JD画像
                   v
            用于后续人才匹配
```

## 平台差异化处理

### 薪资格式统一

| 平台原始格式 | 统一格式 | 说明 |
|-------------|---------|------|
| 15-25K - 13薪 | 年薪195-325K | 转换为年薪 |
| 60-100W/年 | 年薪600-1000K | W转换为K |
| 面议 | 待定 | 保留待定标记 |
| 日薪300-500元/天 | 日薪300-500元 | 统一单位 |
| 8-15K | 月薪8-15K | 保持原样 |

### 经验要求统一

| 平台原始格式 | 统一格式 | 说明 |
|-------------|---------|------|
| 3-5年相关经验 | 3-5年 | 提取数字范围 |
| 不限 | 0年+ | 转换为0年+ |
| 应届毕业生 | 0-1年 | 转换为0-1年 |
| 10年以上 | 10年+ | 统一格式 |

### 学历要求统一

| 平台原始格式 | 统一格式 | 说明 |
|-------------|---------|------|
| 本科及以上 | 本科+ | 标准化 |
| 大专以上 | 大专+ | 标准化 |
| 985/211优先 | 本科+（985/211优先） | 保留优先级 |
| 不限 | 学历不限 | 保持原样 |

## 使用说明

### 触发场景

- 用户上传或粘贴来自任意招聘平台的JD文本
- 用户要求解析特定平台的JD
- 用户需要将多个平台的JD统一格式输出

### 使用流程

1. **输入**：用户提供原始JD文本（可包含平台特有格式）
2. **识别**：AI自动识别来源平台（如无法识别，默认按标准格式处理）
3. **解析**：按平台特点进行差异化解析
4. **统一输出**：生成标准化的JD画像（JSON + HTML）

### 注意事项

- 所有输出遵循脱敏处理规范
- 日期字段必须使用真实系统时间
- 遵循报告交付技术安全标准（禁止CDN、内嵌图片等）
