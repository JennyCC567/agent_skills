# 校园招聘智能引擎

## 技能定位
支撑年招1000人体量的系统化校招平台，覆盖从院校选择到校友回流的全生命周期管理。

## 触发判断

当用户意图匹配以下场景时触发：
- 校园招聘（秋招/春招/提前批/补录）的整体规划与执行
- 院校选择、院校分级、目标院校清单
- 专业与岗位匹配（"制冷专业对应哪些岗位？"）
- 校招日历编排、宣讲会策划、Open Day方案
- 校招笔试题库、面试题库生成
- Offer竞争力分析、毁约预警、转化追踪
- 实习转正评估与管理
- 校友网络建设、离职校友回流

关键词：校招、校园招聘、秋招、春招、提前批、院校、专业匹配、宣讲会、校招题库、Offer管理、实习转正、校友回流

## 核心模块

### M1 院校智能画像与分级

**输入**：产业/岗位需求清单

**流程**：
1. 调用 `references/data/university_profile.md` 获取院校基础数据
2. 按四维评估模型打分：
   - 学科匹配度（40%）：目标专业学科评估等级
   - 历史录用率（25%）：近3年录用/投递比
   - 地域匹配度（20%）：与海尔产业所在地距离
   - 生源充足度（15%）：相关专业毕业生规模
3. 输出S/A/B/C四级院校清单

**分级标准**：
| 级别 | 标准 | 投入策略 |
|------|------|---------|
| S级 | 学科A+/A + 录用率高 + 地缘匹配 | 深度绑定：实验室合作+冠名奖学金+定向培养 |
| A级 | 学科A/A- + 录用率较高 | 重点投入：专场宣讲+双选会+Open Day |
| B级 | 学科B+ + 有一定基础 | 适度投入：双选会+线上宣讲 |
| C级 | 补充院校 | 轻量参与：线上双选会 |

**输出**：目标院校清单（含理由）+ 各校优势专业 + 对口岗位 + 预计生源量

---

### M2 专业-岗位智能匹配

**输入**：岗位JD清单

**流程**：
1. JD解析 → 提取技能要求关键词
2. 调用 `references/data/major_role_mapping.md` 专业-岗位映射表
3. 匹配度打分（专业对口度×技能覆盖率×学历匹配度）
4. 输出三维匹配矩阵：岗位×院校×匹配度

**输出**：每个岗位的目标专业 + 目标院校 + 匹配度评分 + 优先级排序

---

### M3 校招日历与活动策划

**标准时间线**：
| 阶段 | 时间 | 核心动作 |
|------|------|---------|
| 春招提前批 | 3-5月 | 暑期实习招聘+提前批Offer |
| 暑期实习 | 6-8月 | 实习培养+转正评估 |
| 秋招正式批 | 9-11月 | 大规模宣讲+笔试+面试 |
| 秋招补录 | 12月 | 补招+毁约补充 |
| 实习转正 | 次年3-6月 | 春招实习→转正 |

**活动策划**：根据院校级别自动匹配活动方案
| 活动类型 | 目标院校 | 预算 | 预期产出 |
|---------|---------|------|---------|
| 专场宣讲会 | S级 | 8K-15K | 到场100+，简历50+ |
| 双选会展位 | A/B级 | 3K-5K | 简历30+ |
| Open Day | S级 | 20K-30K | 深度交流20-30人 |
| 实验室合作 | S级全年 | 50K-100K | 定向培养5-10人 |

**输出**：校招日历（甘特图）+ 各校活动方案 + 团队分工 + 预算分配

### M4 笔面试题库管理

按岗位类别生成差异化题库：

| 岗位类别 | 专业笔试题 | 行为面试题(STAR) | 技术深挖题 | 案例题 |
|---------|-----------|----------------|-----------|--------|
| 制冷研发 | 制冷循环计算/换热器设计 | 项目攻坚/技术选型 | 系统仿真/CFD | 噪音振动诊断 |
| 嵌入式软件 | C/RTOS/中断处理 | 紧急bug修复 | 驱动开发/通信协议 | 资源受限优化 |
| AI算法 | 机器学习/深度学习 | 模型上线经验 | 模型压缩/边缘部署 | 家电AI应用 |
| 工业设计 | 设计思维/手绘快题 | 从0到1设计 | CMF/人机工程 | 白电趋势判断 |
| 产品经理 | 市场分析/用户研究 | 需求管理/跨部门协作 | 产品规划方法论 | 新品策划全案 |

**输出**：题库Excel + 评分表（参考要点+加分项+减分项）+ 面试官指引

### M5 Offer管理与转化追踪

**Offer竞争力分析**（5维度）：
- 薪酬竞争力：vs竞品同级Offer（调用⑬薪酬对标）
- 品牌吸引力：学生对海尔/卡萨帝品牌认知
- 发展路径：晋升速度、培养体系
- 地域因素：城市对比
- 团队/导师：直属领导风格

**毁约风险预警**：
| 风险等级 | 判断标准 | 应对策略 |
|---------|---------|---------|
| 高 | 接Offer后30天未报到/持有竞品Offer/薪资低于竞品>15% | 主动沟通+加薪/加速入职 |
| 中 | 犹豫期延长/多次询问细节 | 定期触达+增强吸引力 |
| 低 | 积极互动/主动询问入职准备 | 保持联系 |

**转化漏斗**：意向→投递→笔试→面试→Offer→接受→到岗，各环节对比行业基准

**输出**：Offer转化看板 + 高危预警名单 + 竞品薪酬对标 + 提升建议

---

### M6 实习转正管道管理

| 环节 | 关键动作 | 评估标准 |
|------|---------|---------|
| 实习培养 | 导师带教+项目实战 | 项目完成度、学习能力、团队融入 |
| 转正评估 | 综合表现+部门评价 | 绩效≥B+，无重大失误 |
| 双向匹配 | 岗位需求↔能力意向 | 匹配度≥70% |
| 转正Offer | 薪酬方案 | 市场P50+内部公平性 |

**输出**：转正名单 + 淘汰建议 + 留存分析

---

### M7 校友网络与人才回流

| 功能 | 说明 |
|------|------|
| 动态追踪 | 离职员工去向（竞品/创业/跨行业） |
| 回流窗口 | 离职1-2年 + 新环境不满 + 海尔新机会 |
| 触达策略 | 基于关系维护的柔性触达 |
| 回流分析 | 回流率/原因/绩效追踪 |

**输出**：校友通讯录 + 回流机会清单 + 触达话术

## 输出规范

- 院校清单/匹配矩阵/题库 → Excel格式
- 校招方案/活动策划 → Word格式
- 日历/甘特图 → 结构化表格或Markdown
- 所有数据标注来源与日期

## 注意事项

- 院校数据优先使用 `references/data/` 中的基准数据，不足时search_web补充
- 薪酬对标必须引用⑬的数据，不自行估算
- 校招日历需考虑实际节假日和高校校历
- Offer竞争力分析需同时考虑显性（薪资）和隐性（发展/城市）因素
