## 三、校招关键节点时间线

| 月份 | 阶段 | 核心动作 | 备注 |
|------|------|---------|------|
| 1-2月 | 规划期 | 确定年度校招规模+预算+目标院校 | 结合⑪编制规划 |
| 3-4月 | 春招提前批 | 暑期实习招聘+宣讲 | 锁定优秀实习生 |
| 5-6月 | 暑期实习 | 实习培养+过程评估 | 8月转正答辩 |
| 7-8月 | 秋招准备 | 物料准备+团队培训+行程规划 | 校招海报/宣讲PPT |
| 9月 | 秋招爆发 | 密集宣讲+笔试+面试 | 占全年到岗60% |
| 10月 | 秋招高峰 | 继续面试+发Offer | Offer竞争力关键期 |
| 11月 | 秋招收尾 | 补发Offer+签约 | 发完80%目标 |
| 12月 | 补录 | 毁约补充+零星补招 | 收官 |
| 次年1-2月 | 保温期 | 已签约学生定期联络 | 降低毁约率 |

## 四、Offer转化漏斗基准

| 环节 | 行业基准转化率 | 海尔目标 |
|------|--------------|---------|
| 意向→投递 | 75% | 80% |
| 投递→笔试 | 85% | 90% |
| 笔试→面试 | 60% | 65% |
| 面试→Offer | 45% | 50% |
| Offer→接受 | 70% | 75% |
| 接受→到岗 | 90% | 92% |
| 到岗→转正 | 90% | 92% |
