## 阶段1：启动 - 战略解码与差距分析

### 阶段目标
- 明确企业战略目标和核心诉求
- 识别战略执行中的关键差距
- 获得高层支持和资源承诺
- 界定OD项目的范围和边界

### 核心任务
1. **战略解码**
   - 理解公司级战略关键词
   - 分解战略目标到组织能力要求
   - 识别战略执行的关键成功要素

2. **差距分析**
   - 评估当前组织能力与战略要求的差距
   - 识别最紧迫的改善点
   - 分析差距的根本原因

3. **利益相关者对齐**
   - 获得高层支持和赞助
   - 识别关键利益相关者
   - 建立变革指导联盟

4. **项目界定**
   - 明确项目范围和边界
   - 设定项目目标和成功标准
   - 制定初步时间计划

### 关键交付物
- 战略解码报告
- 组织能力差距分析报告
- 项目章程
- 变革指导联盟名单

### 智能体引导要点
1. 询问用户："请描述今年公司级战略的核心关键词和主要目标？"
2. 深入追问："在战略执行过程中，遇到的主要痛点是什么？"
3. 引导思考："这些痛点背后的根本原因可能是什么？"
4. 基于BLM模型，提供差距分析框架指导

### 参考模型
- BLM业务领先模型（市场洞察→战略意图→业务设计）
- 五力分析（评估外部环境）
- SWOT分析（内部优势劣势分析）

## 阶段2：诊断 - 组织健康度评估

### 阶段目标
- 全面评估组织当前健康状况
- 识别组织优势和薄弱环节
- 量化组织能力水平
- 为方案设计提供数据支撑

### 核心任务
1. **多维度诊断**
   - 基于麦肯锡7S模型进行综合评估
   - 聚焦关键问题领域（如人才、流程、文化等）
   - 收集定量和定性数据

2. **数据收集**
   - 员工问卷调查
   - 关键访谈（高层、中层、一线）
   - 文档分析（制度、流程、报表等）

3. **数据分析**
   - 生成组织健康度雷达图
   - 识别高绩效和低绩效领域
   - 进行差距对比（行业标杆、历史数据）

4. **根因分析**
   - 使用鱼骨图、5Why等方法
   - 区分表象问题和根本原因
   - 建立问题与战略目标的关联

### 关键交付物
- 组织健康度诊断报告
- 7S模型雷达图
- 关键问题清单
- 根因分析矩阵

### 智能体引导要点
1. 引导用户基于7S模型进行自评："请对以下6个维度进行1-10分评分..."
2. 基于评分结果调用脚本生成雷达图
3. 分析图表："从雷达图可以看出，战略和共同价值观维度表现较强，但技能和制度维度有待提升"
4. 提供改进建议："针对制度薄弱环节，建议优先完善绩效管理和激励机制"

### 参考模型
- 麦肯锡7S模型
- 组织健康度问卷
- 鱼骨图
- 5Why分析法

## 阶段3：设计 - 变革方案设计

### 阶段目标
- 设计针对性的变革解决方案
- 明确变革的目标和范围
- 制定详细的实施计划
- 预估资源需求和风险

### 核心任务
1. **问题聚焦**
   - 从诊断结果中筛选最紧迫的问题
   - 确定变革优先级
   - 界定变革边界和范围

2. **解决方案设计**
   - 基于杨三角、ADKAR等模型设计方案
   - 明确变革目标、措施、责任人、时间线
   - 设计配套机制（激励、培训、沟通等）

3. **可行性分析**
   - 评估资源需求（人力、财力、技术）
   - 识别潜在风险和阻力
   - 制定风险应对策略

4. **方案评审与对齐**
   - 与高层评审方案
   - 获得关键利益相关者认可
   - 修订和完善方案

### 关键交付物
- 变革方案文档
- 实施路线图
- 资源需求清单
- 风险评估矩阵

### 智能体引导要点
1. 引导用户聚焦痛点："在所有诊断结果中，哪个问题最紧迫、影响最大？"
2. 提供框架："针对协作流程问题，建议从杨三角三个维度入手..."
3. 智能体撰写方案大纲：
   - 一、变革目标
   - 二、核心措施
   - 三、实施步骤
   - 四、责任分工
   - 五、资源需求
   - 六、风险应对
4. 可选：调用力场分析脚本，识别驱动力和阻力

### 参考模型
- 杨三角组织能力模型
- ADKAR变革管理模型
- Kotter变革八步法
- 力场分析模型

## 阶段4：试点 - 小范围验证

### 阶段目标
- 在小范围内验证变革方案
- 发现和解决潜在问题
- 积累成功经验和最佳实践
- 为全面推广做好准备

### 核心任务
1. **试点选择**
   - 选择试点部门或业务单元
   - 评估试点代表性
   - 获得试点负责人的支持

2. **试点准备**
   - 制定试点详细计划
   - 培训试点团队
   - 准备所需资源
   - 设定成功指标

3. **试点执行**
   - 按计划推进变革措施
   - 监控关键指标
   - 收集反馈和数据
   - 及时调整和优化

4. **效果评估**
   - 对比试点前后指标
   - 总结成功经验
   - 识别待改进点
   - 形成试点报告

### 关键交付物
- 试点计划
- 试点执行监控表
- 试点效果评估报告
- 推广准备清单

### 智能体引导要点
1. 引导选择试点："建议选择变革意愿强、代表性好的部门作为试点"
2. 提供试点执行清单："试点期间，建议每周监控以下关键指标..."
3. 智能体撰写试点启动沟通话术
4. 基于试点结果，智能体提供优化建议

### 参考工具
- 试点项目甘特图（调用脚本生成）
- 关键指标监控表
- PDCA循环

## 阶段5：推广 - 全面落地推广

### 阶段目标
- 将变革方案推广到全公司
- 确保变革的一致性和完整性
- 克服推广过程中的阻力
- 快速取得成果并巩固信心

### 核心任务
1. **推广准备**
   - 基于试点经验完善方案
   - 制定全面推广计划
   - 培训推广团队
   - 准备推广资源

2. **沟通宣导**
   - 撰写全员沟通邮件
   - 举办启动会
   - 建立沟通渠道
   - 及时回应疑问

3. **分层推进**
   - 按部门/区域分批实施
   - 提供针对性支持
   - 监控推广进度
   - 收集反馈和调整

4. **快速胜利**
   - 设置阶段性里程碑
   - 快速取得可见成果
   - 宣传成功案例
   - 增强变革信心

### 关键交付物
- 全面推广计划
- 沟通材料（邮件、PPT、手册）
- 推广进度监控表
- 成功案例集

### 智能体引导要点
1. 智能体基于Kotter变革八步法撰写沟通邮件：
   - 说明变革必要性（建立紧迫感）
   - 描绘美好愿景（沟通愿景）
   - 消除员工疑虑（赋能支持）
2. 提供培训计划框架："建议针对不同角色设计差异化培训内容..."
3. 智能体生成推广风险预警："推广过程中可能遇到的典型阻力及应对策略..."

### 参考模型
- Kotter变革八步法
- ADKAR变革管理模型
- 沟通矩阵

## 阶段6：固化 - 机制与文化建设

### 阶段目标
- 将变革成果固化为制度和文化
- 建立持续改进机制
- 防止变革回退
- 形成组织长期竞争优势

### 核心任务
1. **制度固化**
   - 修订和完善相关制度
   - 调整绩效考核指标
   - 优化激励机制
   - 嵌入IT系统

2. **文化塑造**
   - 强化核心价值观
   - 树立标杆人物
   - 传播成功故事
   - 营造支持变革的文化氛围

3. **能力建设**
   - 建立人才发展体系
   - 完善培训机制
   - 搭建知识管理平台
   - 持续提升组织能力

4. **持续改进**
   - 建立复盘机制
   - 定期评估变革效果
   - 收集反馈和优化
   - 推动持续改进

### 关键交付物
- 制度修订清单
- 文化建设方案
- 人才发展体系
- 复盘评估报告

### 智能体引导要点
1. 智能体提供固化措施建议："为了确保变革成果不回退，建议从以下几个方面固化..."
2. 撰写复盘议程："建议1个月后召开变革复盘会，议程如下..."
3. 智能体生成持续改进机制框架
4. 提醒用户关注关键指标："建议每季度评估以下指标，确保变革效果持续..."

### 参考工具
- PDCA循环
- OKR目标管理
- 人才盘点与继任计划
- 知识管理平台

## 各阶段关键衔接点

### 阶段1 → 阶段2
- 战略解码成果作为诊断的输入
- 高层支持确保诊断的顺利开展

### 阶段2 → 阶段3
- 诊断结果指导方案设计方向
- 根因分析确保方案针对性

### 阶段3 → 阶段4
- 方案评审通过后进入试点
- 试点计划基于方案设计

### 阶段4 → 阶段5
- 试点经验完善推广方案
- 成功案例增强推广信心

### 阶段5 → 阶段6
- 推广完成后立即固化
- 持续监控防止回退

## 常见误区与注意事项

### 常见误区
1. **跳过诊断直接设计**：缺乏数据支撑，方案针对性不足
2. **忽视高层支持**：缺乏资源和权力支持，变革难以推进
3. **试点范围过大**：风险难以控制，失败成本过高
4. **沟通不足**：员工不理解变革，阻力增大
5. **急于求成**：期望一次性解决所有问题，缺乏耐心
6. **忽视固化**：变革成果未能制度化，容易回退

### 注意事项
1. **高层支持是关键**：确保C-level sponsor深度参与
2. **数据驱动决策**：基于客观数据而非主观判断
3. **分步推进**：采用"试点-优化-推广"的渐进式路径
4. **沟通先行**：在变革前充分沟通，消除疑虑
5. **快速胜利**：尽早取得可见成果，增强信心
6. **持续跟进**：变革不是一次性项目，而是持续改进的过程
