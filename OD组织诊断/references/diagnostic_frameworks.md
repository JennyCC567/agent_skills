## 组织健康度诊断框架

### 诊断维度

#### 1. 战略层面
- 战略清晰度：战略目标是否清晰、可理解
- 战略一致性：各部门是否对战略有统一理解
- 战略执行力：战略是否有效落地执行
- 战略灵活性：战略能否适应环境变化

#### 2. 组织层面
- 组织架构：架构是否支持战略执行
- 权责划分：权责是否清晰、匹配
- 协作效率：跨部门协作是否顺畅
- 决策效率：决策速度和质量如何

#### 3. 人员层面
- 人才结构：人才配置是否合理
- 能力匹配：员工能力是否满足岗位要求
- 人才梯队：关键岗位是否有继任计划
- 员工敬业度：员工是否有激情和归属感

#### 4. 文化层面
- 价值观认同：员工是否认同核心价值观
- 文化一致性：言行是否一致
- 文化支撑：文化是否支撑战略执行
- 文化包容性：文化是否鼓励创新和改进

#### 5. 机制层面
- 绩效管理：绩效体系是否科学有效
- 激励机制：激励是否与绩效挂钩
- 培训发展：培训体系是否完善
- 沟通机制：沟通渠道是否畅通

### 诊断方法
1. **问卷调查**：大规模收集定量数据
2. **深度访谈**：关键人员访谈获取定性信息
3. **文档分析**：制度、流程、报表分析
4. **现场观察**：实地观察工作场景和协作模式
5. **数据挖掘**：HR数据、业务数据分析

## 7S模型诊断问题清单

### Strategy（战略）
1. 公司的战略目标是什么？是否清晰、可衡量？
2. 战略是否与市场环境和竞争态势匹配？
3. 各部门是否理解战略？是否与部门目标对齐？
4. 战略执行过程中遇到的主要挑战是什么？

### Structure（结构）
1. 当前的组织架构是什么？是否支持战略执行？
2. 汇报关系是否清晰？是否存在多头管理？
3. 部门间的协作是否顺畅？是否存在部门墙？
4. 决策权限是否清晰？决策流程是否高效？

### Systems（制度/系统）
1. 主要的管理制度有哪些？是否完善？
2. 绩效管理体系是否公平、有效？
3. 激励机制是否能激发员工积极性？
4. IT系统是否支持业务高效运转？

### Shared Values（共同价值观）
1. 公司的核心价值观是什么？
2. 员工是否理解和认同核心价值观？
3. 员工的日常行为是否体现价值观？
4. 价值观是否支撑战略执行？

### Skills（技能）
1. 组织的核心竞争力是什么？
2. 员工的技能是否满足岗位要求？
3. 组织是否有持续的技能提升计划？
4. 技能短板在哪里？如何弥补？

### Staff（人员）
1. 人才结构是否合理？（年龄、层级、专业）
2. 关键岗位是否有合适的人才？
3. 是否有完善的人才梯队和继任计划？
4. 员工敬业度如何？离职率是否可控？

### Style（风格）
1. 领导层的领导风格是什么？
2. 管理方式是否与组织文化匹配？
3. 是否鼓励创新和试错？
4. 上下级沟通是否顺畅？

## 杨三角诊断框架

### 员工能力（能不能？）
#### 诊断问题
1. 员工是否具备完成战略所需的知识和技能？
2. 关键岗位的能力缺口在哪里？
3. 组织是否有系统的能力提升计划？
4. 培训体系是否有效？培训效果如何？

#### 诊断方法
- 能力模型对标
- 技能测评
- 培训需求调研
- 培训效果评估

### 员工思维（愿不愿意？）
#### 诊断问题
1. 员工是否理解并认同战略目标？
2. 员工是否有变革意愿？
3. 员工的价值观与组织价值观是否一致？
4. 员工是否有足够的动力和激情？

#### 诊断方法
- 员工敬业度调研
- 价值观认同度调研
- 变革意愿调研
- 员工访谈

### 员工治理（允不允许？）
#### 诊断问题
1. 组织架构是否支持战略执行？
2. 制度流程是否高效？是否存在冗余流程？
3. 资源配置是否合理？
4. 激励机制是否与战略目标对齐？

#### 诊断方法
- 组织架构分析
- 流程效率分析
- 资源配置分析
- 激励机制评估

## 人才盘点诊断框架

### 盘点维度
1. **绩效维度**：过往业绩表现
2. **潜力维度**：未来发展潜力
3. **能力维度**：当前能力水平
4. **价值观维度**：文化匹配度

### 盘点工具
- 人才九宫格：基于绩效-潜力双维度分类
- 能力素质模型：评估核心能力
- 360度评估：多视角反馈
- 继任计划表：关键岗位后备人才

### 盘点流程
1. 定义盘点范围和标准
2. 收集绩效和潜力数据
3. 进行多维度评估
4. 生成人才九宫格
5. 制定人才发展计划

### 诊断输出
- 人才九宫格分布图
- 高潜人才名单
- 关键人才流失风险预警
- 人才发展建议

## 变革阻力诊断框架

### 阻力来源
1. **个人层面**
   - 利益受损
   - 能力不足
   - 习惯势力
   - 缺乏信任

2. **组织层面**
   - 资源不足
   - 制度障碍
   - 文化冲突
   - 权力博弈

3. **环境层面**
   - 市场变化
   - 政策法规
   - 技术冲击
   - 竞争压力

### 诊断方法
- 力场分析：识别驱动力和阻力
- 利益相关者分析：识别关键影响者
- 问卷调查：收集员工对变革的态度
- 访谈调研：深入了解阻力原因

### 对策框架
1. **认知层面**：加强沟通，说明变革必要性
2. **意愿层面**：激励支持，消除疑虑
3. **能力层面**：培训赋能，提升技能
4. **环境层面**：优化制度，创造条件

## 根因分析工具

### 1. 5Why分析法
**方法**：连续问"为什么"，直到找到根本原因
**应用场景**：问题深度分析
**示例**：
- 问题：员工离职率高
- Why1：因为薪资竞争力不足
- Why2：因为薪酬体系未市场化
- Why3：因为薪酬策略保守
- Why4：因为公司战略定位保守
- Why5：因为高层对市场变化敏感度不足
- 根本原因：高层对市场变化敏感度不足

### 2. 鱼骨图（石川图）
**方法**：将问题分解为多个可能的原因类别
**应用场景**：复杂问题的多维度分析
**分类**：
- 人员
- 方法
- 机器
- 材料
- 环境
- 管理

### 3. 问题树分析法
**方法**：将问题层层分解，找到关键影响因素
**应用场景**：系统化的问题分析
**步骤**：
1. 定义核心问题
2. 分解为一级子问题
3. 继续分解为二级、三级子问题
4. 识别最关键的分支

### 4. 假设验证法
**方法**：提出假设，收集数据验证
**应用场景**：数据驱动的问题诊断
**步骤**：
1. 提出多个可能的假设
2. 设计验证方案
3. 收集数据
4. 验证或推翻假设
