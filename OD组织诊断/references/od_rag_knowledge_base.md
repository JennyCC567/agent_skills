# OD专业RAG知识库

## 概述
本知识库为组织发展（Organization Development）专业实践提供结构化的案例和干预方案支持，适用于AI智能体进行专业问答、案例推荐、方案设计等场景。

## 一、组织诊断案例库（60+案例）

### 1.1 战略与结构类（15例）

**案例S001：某互联网公司战略解码失败**
- **背景**：某中型互联网公司（500人）进行战略解码，但部门目标与公司战略脱节
- **症状**：部门各自为政，资源重复投入，用户体验不一致
- **诊断方法**：7S模型分析
- **根因**：Structure与Strategy不一致，缺少横向协同机制
- **干预方案**：重构组织架构，建立敏捷项目组，强化PMO横向协调
- **结果**：3个月后部门协同效率提升40%

**案例S002：制造业集团总部管控过强**
- **背景**：某制造业集团（3000人）总部对子公司管控过细
- **症状**：决策周期长，市场响应慢，子公司积极性低
- **诊断方法**：权责梳理+力场分析
- **根因**：集权文化根深蒂固，缺少授权机制
- **干预方案**：
  1. 战略解码明确总部与子公司权责边界
  2. 建立子公司KPI自主设定机制
  3. 试点阿米巴经营模式
- **结果**：决策周期缩短60%，子公司满意度提升

**案例S003：初创公司战略模糊**
- **背景**：某A轮创业公司（50人）方向频繁调整
- **症状**：员工迷茫，核心人员流失
- **诊断方法**：BLM模型
- **根因**：领导层对战略愿景未达成共识
- **干预方案**：
  1. 高管战略共创工作坊
  2. 绘制战略地图
  3. OKR全员对齐
- **结果**：战略清晰度提升，核心留存率100%

### 1.2 人才与文化类（20例）

**案例T001：关键人才流失危机**
- **背景**：某科技公司（200人）半年内流失3名核心架构师
- **症状**：技术债务堆积，项目延期
- **诊断方法**：ADKAR模型+员工满意度调研
- **根因**：
  - Awareness：员工不了解公司发展规划
  - Desire：缺少职业发展路径
  - Knowledge：能力提升支持不足
  - Reinforcement：激励与认可缺失
- **干预方案**：
  1. 建立技术人才发展通道
  2. 实施关键技术岗位继任计划
  3. 引入项目跟投机制
- **结果**：核心人才稳定性显著提升

**案例T002：企业文化稀释**
- **背景**：某公司快速扩张（50人→300人）后文化稀释
- **症状**：新员工认同度低，老员工抱怨
- **诊断方法**：文化审计+价值观行为化
- **根因**：文化未系统传承，招聘标准未对齐
- **干预方案**：
  1. 编写《企业文化手册》并培训
  2. 将文化纳入绩效考核
  3. 设立文化大使机制
- **结果**：文化一致性从45%提升至85%

**案例T003：新生代员工管理冲突**
- **背景**：某公司95后员工占比超60%，管理冲突频发
- **症状**：离职率高，沟通困难
- **诊断方法**：代际差异分析
- **根因**：管理层用70/80后方式管理95后
- **干预方案**：
  1. 管理者代际沟通培训
  2. 建立开放、平等的工作环境
  3. 引入弹性工作制
- **结果**：95后离职率下降50%

### 1.3 流程与效能类（15例）

**案例P001：跨部门协作壁垒**
- **背景**：某公司产品研发与市场销售脱节
- **症状**：产品不符合市场需求，库存积压
- **诊断方法**：SIPOC分析+价值流图
- **根因**：部门KPI冲突，缺少沟通机制
- **干预方案**：
  1. 建立产品-市场联席会议
  2. 实施L2C（从线索到现金）流程优化
  3. 设立客户成功团队
- **结果**：产品上市成功率提升35%

**案例P002：会议效率低下**
- **背景**：某公司会议过多（每周人均15小时）
- **症状**：员工抱怨没时间工作
- **诊断方法**：会议审计
- **根因**：会议无明确目的，参会人员过多
- **干预方案**：
  1. 推行"会议法则"（明确目的、议程、决策者）
  2. 设立无会议日
  3. 会议纪要模板标准化
- **结果**：会议时间减少40%

**案例P003：变革阻力分析**
- **背景**：某公司推行数字化转型，阻力重重
- **症状**：员工消极配合，项目延期
- **诊断方法**：力场分析+Kotter八步法评估
- **根因**：变革紧迫感不足，员工参与度低
- **干预方案**：
  1. 危机可视化，展示竞争对手动态
  2. 建立变革骨干网络
  3. 设立快速胜利（Quick Wins）
- **结果**：变革支持度从30%提升至75%

## 四、OD工具与模型应用指南

### 4.1 模型选择矩阵

| 场景 | 推荐模型 |
|------|----------|
| 战略解码 | BLM、平衡计分卡 |
| 组织诊断 | 7S模型、杨三角 |
| 变革推动 | Kotter八步法、ADKAR |
| 人才盘点 | 九宫格、能力素质模型 |
| 问题分析 | 力场分析、鱼骨图 |
| 流程优化 | 价值流图、SIPOC |

### 4.2 模型组合应用

**组合1：战略到执行**
- BLM（战略）→ 平衡计分卡（目标）→ OKR（执行）→ 7S（组织保障）

**组合2：变革管理**
- Kotter（变革）→ ADKAR（个人）→ 力场分析（问题）

**组合3：人才发展**
- 九宫格（盘点）→ 能力素质模型（标准）→ IDP（发展）

## 六、使用建议

1. **案例检索**：根据行业+场景+问题类型检索相似案例
2. **方案设计**：参考干预方案库，结合企业实际情况调整
3. **模型应用**：根据诊断结论选择合适的OD模型
4. **效果评估**：参考案例中的衡量指标设定目标
