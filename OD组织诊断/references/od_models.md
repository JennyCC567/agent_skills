## 麦肯锡7S模型

### 概览
麦肯锡7S模型（McKinsey 7S Framework）是由麦肯锡咨询公司提出的组织分析框架，用于评估和设计组织的整体效能。该模型认为组织效能取决于7个相互关联的要素。

### 核心要素
分为"硬要素"和"软要素"两大类：

**硬要素（易于识别和调整）**：
1. **Strategy（战略）**：企业为实现长期目标而制定的总体计划和竞争策略
2. **Structure（结构）**：组织架构、汇报关系、权责划分
3. **Systems（制度/系统）**：业务流程、管理制度、IT系统、激励机制

**软要素（难以识别和调整，但影响深远）**：
4. **Shared Values（共同价值观）**：企业文化、核心价值观、使命愿景
5. **Skills（技能）**：组织整体能力、核心竞争力
6. **Staff（人员）**：人才结构、员工能力、人才梯队
7. **Style（风格）**：领导风格、管理方式、决策模式

### 应用场景
- 组织诊断与效能评估
- 组织架构设计与优化
- 变革管理前后的状态分析
- 并购整合

### 评分标准（1-10分制）
- **9-10分**：优秀，行业标杆水平
- **7-8分**：良好，具备较强竞争力
- **5-6分**：中等，存在明显改进空间
- **3-4分**：较差，严重影响组织效能
- **1-2分**：极差，急需重点改善

### 输入格式（用于雷达图生成）
```json
{
  "strategy": 7,
  "structure": 5,
  "systems": 6,
  "shared_values": 8,
  "skills": 4,
  "staff": 6,
  "style": 7,
  "output_path": "./radar_chart.png"
}
```

**字段说明**：
- `strategy`：战略维度评分（1-10）
- `structure`：结构维度评分（1-10）
- `systems`：制度维度评分（1-10）
- `shared_values`：共同价值观维度评分（1-10）
- `skills`：技能维度评分（1-10）
- `staff`：人员维度评分（1-10）
- `style`：风格维度评分（1-10）
- `output_path`：输出图片路径

## 杨三角组织能力模型

### 概览
由中欧国际工商学院杨国安教授提出，认为"企业持续成功 = 战略 × 组织能力"，组织能力由三个支柱支撑。

### 核心要素
1. **员工能力（能不能？）**：员工是否具备执行战略所需的知识、技能和素质
2. **员工思维（愿不愿意？）**：员工是否愿意展现所需的行为和价值观
3. **员工治理（允不允许？）**：组织是否提供有效的管理机制和资源支持

### 应用场景
- 战略解码到组织能力
- 人才体系建设
- 激励机制设计
- 变革阻力分析

## ADKAR变革管理模型

### 概览
由Prosci公司提出，聚焦于个人层面的变革，确保变革在个体层面成功落地。

### 核心要素
1. **Awareness（认知）**：理解为什么需要变革
2. **Desire（意愿）**：愿意参与和支持变革
3. **Knowledge（知识）**：知道如何变革
4. **Ability（能力）**：具备实施变革所需技能
5. **Reinforcement（强化）**：巩固变革成果，防止回退

### 应用场景
- 变革沟通策略设计
- 员工培训计划制定
- 变革阻力管理

## BLM业务领先模型

### 概览
IBM提出的战略规划与执行框架，连接战略制定与战略执行。

### 核心要素
**战略制定（右脑）**：
- 市场洞察
- 战略意图
- 创新焦点
- 业务设计

**战略执行（左脑）**：
- 关键任务
- 正式组织
- 人才
- 氛围与文化

**领导力**：贯穿始终的推动力

**价值观**：底层基础

### 应用场景
- 战略解码
- 组织能力规划
- 差距分析

## Kotter变革八步法

### 概览
哈佛商学院John Kotter教授提出，是经典的变革管理方法论。

### 八个步骤
1. **建立紧迫感**：说明变革的必要性和紧迫性
2. **构建指导联盟**：组建有影响力的变革领导小组
3. **制定愿景和战略**：明确变革方向和实施路径
4. **沟通愿景**：广泛宣传变革愿景
5. **授权赋能**：清除变革障碍，赋予员工行动权
6. **创造短期胜利**：设置里程碑，快速取得成果
7. **巩固成果**：深化变革，防止回退
8. **深化变革**：将变革融入企业文化

### 应用场景
- 变革项目规划
- 沟通策略设计
- 变革节奏控制

## 人才九宫格模型

### 概览
基于绩效和潜力双维度的人才盘点工具，帮助企业识别和分类人才。

### 九个象限
**高潜力高绩效（明星人才）**：
- Q1（9-10绩效，9-10潜力）：超级明星
- Q2（7-8绩效，9-10潜力）：明日之星

**中等潜力高绩效**：
- Q3（9-10绩效，7-8潜力）：中坚力量

**低潜力高绩效**：
- Q4（9-10绩效，1-6潜力）：金牛人才

**高潜力中等绩效**：
- Q5（7-8绩效，7-8潜力）：潜力人才

**中等潜力中等绩效**：
- Q6（5-6绩效，7-8潜力）：可培养人才
- Q7（7-8绩效，5-6潜力）：稳定人才
- Q8（5-6绩效，5-6潜力）：基础人才

**低潜力低绩效**：
- Q9（1-4绩效，1-6潜力）：待优化人才

### 应用场景
- 人才盘点与盘点
- 继任者计划
- 人才发展路径设计
- 薪酬激励调整

### 输入格式（用于九宫格生成）
```json
[
  {"name": "张三", "performance": 8, "potential": 9},
  {"name": "李四", "performance": 6, "potential": 5},
  {"name": "王五", "performance": 9, "potential": 7}

```

**字段说明**：
- `name`：员工姓名（字符串）
- `performance`：绩效分数（1-10）
- `potential`：潜力分数（1-10）

## 力场分析模型

### 概览
由社会心理学家Kurt Lewin提出，用于分析变革中的推动力和阻力，寻找平衡策略。

### 核心概念
- **驱动力（Driving Forces）**：推动变革向目标方向发展的因素
- **阻力（Restraining Forces）**：阻碍变革的因素
- **平衡状态（Equilibrium）**：驱动力与阻力的平衡点

### 应用步骤
1. 识别所有驱动力和阻力
2. 对各因素进行评分（1-10分，分数越大影响越大）
3. 生成力场分析图
4. 制定策略：增强驱动力、减弱阻力、引入新驱动力

### 应用场景
- 变革阻力分析
- 利益相关者分析
- 问题根因分析

### 输入格式（用于力场分析图生成）
```json
{
  "driving_forces": [
    {"name": "市场竞争压力", "score": 8},
    {"name": "高层支持", "score": 7}
  ],
  "restraining_forces": [
    {"name": "员工抵触", "score": 6},
    {"name": "资源不足", "score": 5}
  ],
  "output_path": "./force_field.png"
}
```

**字段说明**：
- `driving_forces`：驱动力列表
  - `name`：驱动力名称（字符串）
  - `score`：影响分数（1-10）
- `restraining_forces`：阻力列表
  - `name`：阻力名称（字符串）
  - `score`：影响分数（1-10）
- `output_path`：输出图片路径

## 验证规则

所有输入数据必须满足以下验证规则：

### 7S模型雷达图
- 所有维度评分必须在1-10之间
- 必须包含全部7个维度
- output_path必须以.png或.jpg结尾

### 人才九宫格
- performance和potential必须在1-10之间
- name字段不能为空
- 至少包含1条数据

### 力场分析
- 驱动力和阻力列表至少各包含1个因素
- 所有分数必须在1-10之间
- 因素名称不能为空

### 错误处理
当输入数据不符合验证规则时，脚本应返回清晰的错误信息，指明具体错误原因。
