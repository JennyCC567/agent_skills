# 岗位类型简历模块结构指南

## 概述

本手册定义了5种岗位类型的简历模块结构差异，包括模块优先级、篇幅分配和关键词策略。不同岗位类型对简历内容的侧重和组织方式有显著差异，智能体应根据目标岗位类型调整简历结构。

---

## 一、技术岗

### 适用岗位
开发工程师、测试工程师、架构师、算法工程师、运维工程师、DBA、安全工程师、嵌入式工程师、数据工程师、技术经理/总监等

### 模块优先级与篇幅分配

| 模块 | 优先级 | 篇幅占比 | 说明 |
|------|--------|----------|------|
| 专业技能 | 最高 | 20%-25% | 按类别分组（语言/框架/数据库/工具/云），标注熟练程度 |
| 工作经历 | 最高 | 25%-30% | 突出技术挑战、解决方案、性能指标 |
| 项目经验 | 高 | 20%-25% | 技术架构、技术选型、核心难点、量化性能提升 |
| 教育背景 | 中 | 8%-12% | CS相关专业优先展示，突出竞赛成绩 |
| 开源贡献/技术博客 | 低 | 5%-10% | GitHub项目、技术文章、StackOverflow |
| 证书与荣誉 | 最低 | 3%-7% | 技术认证（AWS/阿里云等）、竞赛排名 |

### 内容要求细则

**专业技能模块：**
- 按技术类别分组：编程语言、框架与库、数据库、中间件、开发工具、云平台
- 标注熟练程度：精通 / 熟练 / 掌握 / 了解（仅写掌握以上级别的）
- 包含具体版本号（如 Java 17、Spring Boot 3.x、React 18）
- 技术栈与JD要求对齐，确保ATS关键词命中率

**工作经历模块：**
- 每条要点遵循：技术挑战 + 解决方案 + 量化成果
- 量化指标：QPS提升、延迟降低、可用性百分比、故障率下降、代码覆盖率提升
- 体现技术深度：架构设计、性能优化、疑难问题排查

**项目经验模块：**
- 每个项目包含：项目背景、技术架构、个人职责、核心难点、解决方案、量化成果
- 突出技术选型理由（为什么选X而不是Y）
- 展示系统规模和复杂度（用户量、数据量、并发量）

### 关键词策略
- 精确匹配JD中的技术栈关键词
- 包含框架名称和版本号
- 使用行业标准术语（不造词）
- 技术动词：设计、重构、优化、搭建、迁移、部署

### 技术岗特殊要求
1. GitHub/开源项目链接（高星项目优先展示）
2. 技术博客/专栏链接
3. LeetCode/竞赛排名（应届生适用）
4. 技术专利（如有）
5. 系统规模数据（用户量/并发量/数据量）

## 二、管理岗

### 适用岗位
部门经理、总监、VP、总经理、CEO、COO、项目负责人、业务线负责人等

### 模块优先级与篇幅分配

| 模块 | 优先级 | 篇幅占比 | 说明 |
|------|--------|----------|------|
| 职业概述/高管概述 | 最高 | 12%-15% | 3-4句话概括管理幅度、行业经验、核心成就 |
| 工作经历 | 最高 | 30%-35% | 每段经历突出管理幅度和经营成果 |
| 核心业绩 | 高 | 20%-25% | 用数据展示业务增长、成本优化、组织效率提升 |
| 管理能力 | 中 | 12%-18% | 团队搭建、制度建设、人才培养、跨部门协作 |
| 教育背景 | 低 | 5%-10% | MBA/EMBA等管理学位可适当展开 |
| 行业资源与认证 | 最低 | 5%-8% | 行业协会职务、高端管理认证 |

### 内容要求细则

**职业概述模块：**
- 3-4句话精炼概括
- 必须包含：管理年限、管理幅度（团队规模）、核心行业、标志性成果
- 示例结构："X年行业经验，X年管理经验，曾管理X人团队，负责X亿级业务，主导XX实现XX成果"

**工作经历模块：**
- 每段经历必须标注：汇报关系、团队规模、预算规模
- 业绩用数据说话：营收增长、利润改善、成本下降、市场份额变化
- 展示管理跨度：直接管理几层、跨几个部门

**核心业绩模块：**
- 选择3-5个最具代表性的业绩
- 每个业绩包含：背景挑战、决策过程、执行结果（量化）
- 涵盖不同维度：业务增长、组织建设、流程优化、风险管控

### 关键词策略
- 管理层级关键词：团队管理、战略规划、预算管控、组织建设、变革管理
- 业务成果关键词：营收增长、利润改善、成本优化、市场份额、ROI
- 决策类动词：决策、规划、统筹、推动、主导、搭建、变革

### 管理岗特殊要求
1. 明确标注管理团队规模（人数、层级）
2. 展示P&L责任范围（管理预算金额）
3. 制度建设与流程优化成果
4. MBA/EMBA等管理学位加分
5. 减少执行层细节，增加战略层表述

## 三、销售岗

### 适用岗位
销售代表、客户经理、大客户经理、商务经理、BD、渠道经理、区域销售经理、销售总监等

### 模块优先级与篇幅分配

| 模块 | 优先级 | 篇幅占比 | 说明 |
|------|--------|----------|------|
| 工作经历 | 最高 | 25%-30% | 突出客户开发、签约金额、回款率 |
| 核心业绩 | 最高 | 20%-25% | 业绩达成率、排名、增长率（必须有具体数字） |
| 客户资源 | 高 | 12%-18% | 行业客户资源、渠道网络、合作伙伴 |
| 专业技能 | 中 | 8%-12% | CRM工具、销售方法论、行业知识 |
| 教育背景 | 低 | 5%-10% | 精简展示 |
| 证书与荣誉 | 最低 | 5%-8% | 销售竞赛获奖、行业认证 |

### 内容要求细则

**工作经历模块：**
- 每段经历标注：负责区域/行业、客户数量、年销售额
- 量化指标：签约金额、回款率、客户续约率、新客户开发数
- 展示客户层级：头部客户/大客户/中小客户

**核心业绩模块：**
- 业绩数据必须有具体数字：120%达成率、Top 3排名、同比增长50%
- 展示业绩增长趋势（逐年数据对比）
- 重大签约案例（脱敏处理）

**客户资源模块：**
- 行业客户覆盖范围
- 渠道合作伙伴网络
- 客户转化率、留存率数据

### 关键词策略
- 业绩数据关键词：完成率、增长率、排名、签约额、回款
- 行业客户关键词：目标行业、客户层级、KA大客户
- 方法论关键词：SPIN、Challenger Sale、顾问式销售、解决方案销售

### 销售岗特殊要求
1. 业绩达成率必须有具体数字
2. 客户案例展示（脱敏处理）
3. 行业人脉与渠道资源说明
4. 销售竞赛/表彰记录
5. 严禁虚构业绩数据

## 四、运营岗

### 适用岗位
用户运营、内容运营、活动运营、新媒体运营、电商运营、增长运营、社区运营、品牌运营、市场运营等

### 模块优先级与篇幅分配

| 模块 | 优先级 | 篇幅占比 | 说明 |
|------|--------|----------|------|
| 工作经历 | 最高 | 25%-30% | 突出运营渠道、用户规模、增长数据 |
| 项目经验 | 高 | 20%-25% | 完整运营项目闭环：目标-策略-执行-复盘-成果 |
| 核心数据 | 高 | 15%-20% | 用户增长、活跃度、转化率、GMV、ROI |
| 专业技能 | 中 | 8%-12% | 数据分析工具、内容创作、活动策划、平台运营 |
| 教育背景 | 低 | 5%-10% | 精简展示 |
| 证书与荣誉 | 最低 | 3%-5% | 平台认证、营销认证 |

### 内容要求细则

**工作经历模块：**
- 标注负责的渠道/平台、用户规模、核心指标
- 量化指标：DAU/MAU增长、转化率提升、GMV增长、ROI改善
- 展示运营方法论：从数据发现问题 -> 制定策略 -> 执行落地 -> 复盘优化

**项目经验模块：**
- 完整闭环展示：项目背景 -> 目标设定 -> 策略制定 -> 执行过程 -> 数据复盘
- 体现运营思维：用户分层、精细化运营、A/B测试、漏斗优化
- 展示SOP沉淀能力

**核心数据模块：**
- 运营指标可视化呈现（可考虑表格形式）
- 对比数据：优化前vs优化后
- 趋势数据：月度/季度增长曲线

### 关键词策略
- 运营指标关键词：DAU、MAU、转化率、留存率、GMV、ROI、ARPU
- 平台名称关键词：抖音、小红书、微信、淘宝、京东等
- 工具关键词：神策数据、GrowingIO、剪映、秀米等
- 方法论关键词：用户增长、AARRR、A/B测试、漏斗分析、精细化运营

### 运营岗特殊要求
1. 运营数据必须量化
2. 展示完整运营方法论和SOP
3. 平台运营经验需具体到平台名称
4. 活动策划需展示完整案例
5. 严禁虚构运营数据

## 五、职能岗

### 适用岗位
财务、会计、HR、人力资源、招聘、薪酬绩效、法务、合规、审计、采购、行政、秘书、翻译等

### 模块优先级与篇幅分配

| 模块 | 优先级 | 篇幅占比 | 说明 |
|------|--------|----------|------|
| 工作经历 | 最高 | 30%-35% | 突出流程优化、制度建设、风险管控 |
| 专业技能 | 高 | 15%-20% | 专业工具、法规政策、行业认证 |
| 项目经验 | 中 | 12%-18% | 制度搭建、系统上线、流程改造项目 |
| 证书与资质 | 高 | 12%-15% | CPA/CFA/人力资源管理师/法律职业资格等 |
| 教育背景 | 低 | 8%-12% | 相关专业背景 |
| 荣誉与奖项 | 最低 | 3%-5% | 内部表彰、行业荣誉 |

### 内容要求细则

**工作经历模块：**
- 突出流程优化成果：效率提升百分比、成本节约金额
- 展示制度建设：制定/修订了哪些制度、流程、规范
- 体现风险管控：合规审查、审计整改、风险预防

**专业技能模块：**
- 专业工具：ERP（SAP/Oracle/用友/金蝶）、OA系统、财务软件
- 法规政策：熟悉劳动法/税法/会计准则等
- 行业知识：所在职能领域的专业术语和最佳实践

**证书与资质模块：**
- 列出所有相关资质证书（含取得年份）
- 按含金量排序
- 专业资质证书是硬门槛，必须醒目标注

### 关键词策略
- 专业术语关键词：与具体职能领域对齐（财务：会计准则/税务筹划；HR：六大模块/劳动法）
- 工具名称关键词：ERP/OA/财务软件/招聘系统
- 法规政策关键词：劳动法/税法/会计准则/合规
- 认证关键词：CPA/CFA/人力资源管理师/法律职业资格

### 职能岗特殊要求
1. 专业资质证书是硬门槛，必须突出展示
2. 展示制度建设和流程优化成果
3. 合规与风险管控经验
4. 跨部门协作与服务意识
5. 工作内容描述需体现规范性和严谨性

## 使用指引

### 智能体调用流程
1. 调用 `scripts/career_profile_analyzer.py` 获取 `job_category` 字段
2. 根据岗位类型定位到对应类型的结构指南
3. 结合 `career_stage` 字段参考职业阶段策略（见 `career_stage_resume_strategy.md`）
4. 按照岗位类型的模块优先级和篇幅分配重组简历结构

### 组合应用示例
| 用户画像 | 职业阶段策略 | 岗位结构 |
|----------|-------------|----------|
| 应届生 + 技术岗 | 教育背景优先 + 项目驱动 | 专业技能置顶 + 技术栈详细展示 |
| 3-5年 + 管理岗 | 独立操盘 + 方法论 | 职业概述 + 管理幅度标注 |
| 5-10年 + 销售岗 | 管理经验 + 体系建设 | 核心业绩前置 + 客户资源展示 |
| 10年+ + 运营岗 | 战略视野 + 行业影响 | 高管概述 + 核心数据板块 |
| 1-3年 + 职能岗 | 技能成长 + 项目成果 | 证书资质突出 + 流程优化展示 |

### 注意事项
- 岗位类型为自动检测结果时，可在输出中提示用户确认或手动指定
- 当用户同时具有多种岗位特征时，以JD要求的岗位类型为准
- 篇幅分配为建议值，可根据个人经历丰富程度适当调整（上下浮动5%）
