## 数据上传流程

### 流程概览

```
用户上传文件
    ↓
文件格式验证
    ↓
文件安全性检查
    ↓
内容读取
    ↓
敏感信息识别
    ↓
自动脱敏处理
    ↓
数据结构化存储
    ↓
清理原始文件
```

### 步骤1：文件接收与验证

#### 验证规则
1. **文件格式验证**
```
支持的格式：
- PDF（.pdf）
- Word文档（.doc, .docx）
- 文本文件（.txt）
- Markdown（.md）
- 图片（.jpg, .png, .jpeg）- 可选，需OCR处理

限制条件：
- 文件大小：≤ 10MB
- 文件数量：单次上传1个文件
- 文件类型：必须为支持的格式之一
```

2. **文件安全性检查**
```
安全检查项：
□ 文件是否包含恶意代码
□ 文件是否为加密文件（如密码保护的PDF）
□ 文件是否包含可执行脚本
□ 文件来源是否可信
```

#### AI提示词：文件验证
```

检查项目：
1. 文件格式是否支持（PDF/Word/Text/Markdown）

3. 文件是否可以正常打开和读取
4. 文件是否包含明显的恶意内容

输出格式：

- 如果文件不通过验证，给出具体原因
- 建议用户如何修复问题
```

### 步骤2：内容读取

#### 读取策略

```
读取方法：

- 提取文本内容
- 保留基本格式（段落、列表）
- 注意：可能丢失复杂的格式和图片
```

**Word文档**：
```
读取方法：
```

```
读取方法：
```

### 步骤3：敏感信息识别

#### 识别规则

**个人身份信息（PII）**：
```
识别对象：
- 姓名：中文名（2-4个汉字）、英文名
- 身份证号：中国大陆18位身份证号
- 手机号：中国大陆手机号（1[3-9]开头的11位数字）
- 邮箱：电子邮箱地址
- 家庭住址：详细地址信息
- 出生日期：完整的出生日期

识别方法：
- 正则表达式匹配
- 关键词识别
- 上下文分析
```

**职业信息**：
```
识别对象：
- 工资收入：当前薪资、期望薪资
- 银行卡号：16-19位银行卡号
- 社保账号：社保号码
- 公积金账号：公积金号码

识别方法：
- 正则表达式匹配
- 金额识别
- 账号识别
```

**其他敏感信息**：
```
识别对象：
- 紧急联系人：联系人姓名、电话、关系
- 家庭成员：姓名、职业、联系方式
- 健康信息：健康状况、病史
- 其他个人隐私信息

识别方法：
- 关键词匹配
- 上下文分析
- 语义识别
```

## 脱敏处理策略

### 脱敏原则

#### 原则1：最小化暴露
```
原则：尽可能少地暴露敏感信息
应用：
- 保留最少必要的信息用于验证和展示
- 其他信息全部隐藏
- 在不同场景下采用不同程度的脱敏
```

#### 原则2：可验证性
```
原则：脱敏后的信息仍可验证其真实性
应用：
- 保留部分关键信息（如手机号前3位和后4位）
- 用户可以通过部分信息确认是否是自己的数据
- 便于后续的数据匹配和关联
```

#### 原则3：一致性
```
原则：同类敏感信息采用一致的脱敏方式
应用：
- 所有手机号都采用"138****5678"格式
- 所有邮箱都采用"zhan***@example.com"格式
- 所有身份证号都采用"110101********1234"格式
```

#### 原则4：安全性
```
原则：脱敏后的信息无法被还原
应用：
- 隐藏的部分足够多，无法推断出完整信息
- 不使用可逆的加密方式
- 隐藏部分使用固定的"****"或"***"标记
```

### 脱敏规则

#### 规则1：手机号脱敏
```
规则：保留前3位和后4位，中间4位隐藏
格式：138****5678

示例：
- 原文：13812345678
- 脱敏：138****5678

实现代码：
def desensitize_phone(phone):
    if re.match(r'^1[3-9]\d{9}$', phone):
        return phone[:3] + '****' + phone[7:]
    return phone
```

#### 规则2：邮箱脱敏
```
规则：保留前3位字符，中间用"***"替代，保留域名
格式：zhan***@example.com

示例：
- 原文：zhangsan@example.com
- 脱敏：zhan***@example.com

实现代码：
def desensitize_email(email):
    if '@' in email:
        username, domain = email.split('@')
        if len(username) > 3:
            username = username[:3] + '***'
        else:
            username = username[0] + '***'
        return username + '@' + domain
    return email
```

#### 规则3：身份证号脱敏
```
规则：保留前6位和后4位，中间8位隐藏
格式：110101********1234

示例：
- 原文：110101199001011234
- 脱敏：110101********1234

实现代码：
def desensitize_id_card(id_card):
    if re.match(r'^[1-9]\d{17}[0-9Xx]$', id_card):
        return id_card[:6] + '********' + id_card[-4:]
    return id_card
```

#### 规则4：银行卡号脱敏
```
规则：完全隐藏，不保留任何信息
格式：[银行卡号已隐藏]

示例：
- 原文：6222021234567890123
- 脱敏：[银行卡号已隐藏]

实现代码：
def desensitize_bank_card(card_number):
    if re.match(r'^\d{16,19}$', card_number):
        return '[银行卡号已隐藏]'
    return card_number
```

#### 规则5：家庭住址脱敏
```
规则：完全隐藏，不保留任何信息
格式：[地址已隐藏]

示例：
- 原文：北京市朝阳区XX路XX号XX小区XX室
- 脱敏：[地址已隐藏]

实现代码：
def desensitize_address(address):
    if len(address) > 10:
        return '[地址已隐藏]'
    return address
```

#### 规则6：姓名脱敏
```
规则：保留姓氏，隐藏名字
格式：张**、李***

示例：
- 原文：张三
- 脱敏：张**

实现代码：
def desensitize_name(name):
    if len(name) >= 2:
        return name[0] + '*' * (len(name) - 1)
    return name
```

### 不同场景的脱敏策略

#### 场景1：内部处理
```
用途：AI系统内部处理简历数据
脱敏级别：轻度脱敏
策略：
- 保留更多原始信息用于准确分析
- 敏感信息做部分隐藏
- 关键信息保留以便验证

示例：
- 手机号：138****5678
- 邮箱：zhan***@example.com
- 身份证：110101********1234
```

#### 场景2：输出展示
```
用途：向用户展示处理结果
脱敏级别：中度脱敏
策略：
- 脱敏所有敏感信息
- 保留部分信息用于确认
- 不暴露任何完整信息

示例：
- 手机号：138****5678
- 邮箱：zhan***@example.com
- 地址：[地址已隐藏]
```

#### 场景3：日志记录
```
用途：系统日志和审计记录
脱敏级别：重度脱敏
策略：
- 所有敏感信息完全隐藏
- 只记录脱敏后的信息
- 不记录任何原始敏感信息

示例：
- 手机号：[已脱敏]
- 邮箱：[已脱敏]
- 地址：[已脱敏]
```

## 脱敏实现方法

### Python实现

#### 完整脱敏工具类
```python
import re

class DataDesensitizer:
    """数据脱敏工具类"""
    
    @staticmethod
    def desensitize_name(name):
        """姓名脱敏：保留姓氏，隐藏名字"""
        if not name or len(name) < 2:
            return name
        return name[0] + '*' * (len(name) - 1)
    
    @staticmethod
    def desensitize_phone(phone):
        """手机号脱敏：保留前3位和后4位"""
        if not phone:
            return phone
        pattern = r'^1[3-9]\d{9}$'
        if re.match(pattern, phone):
            return phone[:3] + '****' + phone[7:]
        return phone
    
    @staticmethod
    def desensitize_email(email):
        """邮箱脱敏：保留前3位字符"""
        if not email or '@' not in email:
            return email
        username, domain = email.split('@')
        if len(username) > 3:
            username = username[:3] + '***'
        else:
            username = username[0] + '***'
        return username + '@' + domain
    
    @staticmethod
    def desensitize_id_card(id_card):
        """身份证号脱敏：保留前6位和后4位"""
        if not id_card:
            return id_card
        pattern = r'^[1-9]\d{17}[0-9Xx]$'
        if re.match(pattern, id_card):
            return id_card[:6] + '********' + id_card[-4:]
        return id_card
    
    @staticmethod
    def desensitize_bank_card(card_number):
        """银行卡号脱敏：完全隐藏"""
        if not card_number:
            return card_number
        pattern = r'^\d{16,19}$'
        if re.match(pattern, card_number):
            return '[银行卡号已隐藏]'
        return card_number
    
    @staticmethod
    def desensitize_address(address):
        """地址脱敏：完全隐藏"""
        if not address or len(address) < 10:
            return address
        return '[地址已隐藏]'
    
    @staticmethod
    def desensitize_salary(salary):
        """薪资脱敏：保留范围"""
        if not salary:
            return salary
        # 提取数字
        numbers = re.findall(r'\d+', str(salary))
        if numbers:
            avg = sum(int(n) for n in numbers) // len(numbers)
            # 保留千位
            return f'{avg//1000}000+'
        return '[薪资已隐藏]'
    
    @classmethod
    def desensitize_all(cls, data):
        """对所有敏感信息进行脱敏"""
        if isinstance(data, dict):
            return {k: cls.desensitize_all(v) for k, v in data.items()}
        elif isinstance(data, list):
            return [cls.desensitize_all(item) for item in data]
        elif isinstance(data, str):
            # 按优先级处理
            data = cls.desensitize_bank_card(data)
            data = cls.desensitize_id_card(data)
            data = cls.desensitize_phone(data)
            data = cls.desensitize_email(data)
            data = cls.desensitize_address(data)
            data = cls.desensitize_salary(data)
            return data
        else:
            return data

# 使用示例
if __name__ == '__main__':
    # 测试脱敏功能
    data = {
        'name': '张三',
        'phone': '13812345678',
        'email': 'zhangsan@example.com',
        'id_card': '110101199001011234',
        'bank_card': '6222021234567890123',
        'address': '北京市朝阳区XX路XX号XX小区XX室',
        'salary': '30000-50000'
    }
    
    desensitized_data = DataDesensitizer.desensitize_all(data)
    print(desensitized_data)
    
    # 输出：
    # {
    #     'name': '张**',
    #     'phone': '138****5678',
    #     'email': 'zhan***@example.com',
    #     'id_card': '110101********1234',
    #     'bank_card': '[银行卡号已隐藏]',
    #     'address': '[地址已隐藏]',
    #     'salary': '40000+'
    # }
```

## 异常处理

### 常见异常情况

#### 情况1：文件无法读取
```
现象：
- 文件格式不支持
- 文件损坏
- 文件加密

处理方式：
1. 提示用户文件格式不支持
2. 建议用户转换为支持的格式
3. 如果文件损坏，建议用户重新上传
4. 如果文件加密，建议用户解密后再上传
```

#### 情况2：敏感信息识别失败
```
现象：
- 识别不完整
- 识别错误
- 误识别

处理方式：
1. 进行二次识别
2. 使用多种识别方法
3. 人工审核识别结果
4. 对于不确定的内容，保守处理（进行脱敏）
```

#### 情况3：脱敏失败
```
现象：
- 脱敏格式错误
- 脱敏不完整
- 误脱敏

处理方式：
1. 检查脱敏规则是否正确
2. 重新执行脱敏
3. 验证脱敏结果
4. 如果仍有问题，手动修正
```

### 异常处理流程

```
发现异常
    ↓
记录异常信息
    ↓
分析异常原因
    ↓
尝试自动修复
    ↓
验证修复结果
    ↓
通知用户
```

## 总结

### 核心要点

1. **数据上传**：
   - 文件格式验证
   - 文件安全性检查
   - 内容读取和解析

2. **敏感信息识别**：
   - 个人身份信息（PII）
   - 职业信息
   - 其他敏感信息

3. **脱敏处理**：
   - 最小化暴露
   - 可验证性
   - 一致性
   - 安全性

4. **数据验证**：
   - 脱敏后验证
   - 完整性检查
   - 格式正确性检查

5. **异常处理**：
   - 文件无法读取
   - 敏感信息识别失败
   - 脱敏失败

### 最佳实践

- [正确] 严格遵循脱敏规则
- [正确] 进行二次验证
- [正确] 记录处理日志
- [正确] 及时清理原始文件
- [正确] 定期审查脱敏策略
- [禁止] 不要跳过脱敏步骤
- [禁止] 不要在日志中记录敏感信息
- [禁止] 不要使用可逆的脱敏方式
- [禁止] 不要在输出中暴露敏感信息
